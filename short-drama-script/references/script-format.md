# 竖屏剧本格式规范（元素说明 + 示例）——懒加载参考

> 本文件由 `short-drama-script` 的 SKILL.md §二 懒加载引用。定义竖屏短剧剧本的格式与全部元素。

## 一、格式总则

- 竖屏 9:16，观众单手刷手机，字幕区集中在画面中下安全区
- 单集 60-180 秒，**每行信息必须一眼看懂**，禁止长句、长段落
- 推荐**逐镜头表格**（每行 = 一个镜头），下游 short-drama-storyboard 逐镜转分镜、逐镜出图/出视频

## 二、元素说明

### 1. 场景标题
格式：`{内/外}·{地点}·{时间}`，如 `内·总裁办公室·夜`。
时间只写（晨/日/黄昏/夜），不写具体钟点；换场即新标题。

### 2. 景别提示
| 景别 | 用途 |
|---|---|
| 特写 | 表情/道具/卡点句，情绪最重处 |
| 近景 | 对白主力景别，竖屏短剧占比最高 |
| 中景 | 两人关系/动作 |
| 全景 | 交代场景、身份反差 |
| 远景 | 极少用（竖屏视野窄），仅氛围镜头 |

竖屏构图规则：主体居中偏上（留出字幕区）；避免横向构图（两人并排改为前后站位）。

### 3. 角色动作
- 动词优先：`她把合同摔在桌上`，不写 `她看起来很生气`
- 不写内心独白（内心戏归 OS）
- 动作要能演出来、能拍出来，不写心理描写

### 4. 对白
格式：`角色名：台词`。示例：
```
沈总：你被开除了。
林夏：开除我？你问问你爸同不同意。
```

### 5. OS / VO 画外音
- **OS（内心独白）**：角色心里想的话，写 `OS-角色名：`
- **VO（旁白）**：第三方叙述/时间跳跃说明，写 `VO：`
- 大段内心戏必须拆成 OS 短句，配合画面（表情/动作/空镜）推进，禁止 3 句以上连续 OS

### 6. 字幕卡点文字
格式：`字幕：{文字}`。用于：
- 结尾卡点句（本集最后一行）
- 关键信息句（证据/真相/倒计时）
- 平台信息（第 N 集/追更提示，由剪辑阶段处理，不写进剧本）

示例：
```
字幕：他手机的屏保，是十年前的我。
```

### 7. 音效提示
括注在镜头行尾：`（雷声）` `（短信提示音）` `（高跟鞋声由远及近）`。
只写关键音效，不写 BGM（BGM 由 audio-forge 按情绪匹配）。

### 8. 情绪提示
每场标题下标注：`情绪基调：紧张 / 甜 / 虐 / 爽 / 悬疑`。
整集情绪走向在头部标注（如：压迫→反击→小胜）。

### 9. 预计时长
每场标注 `预计 XX 秒`，全集各场之和 60-180 秒；单镜头 3-10 秒。

## 三、单集三幕结构（总纲 §二 2.1 落地）

| 幕 | 时间占比 | 任务 | 硬指标 |
|---|---|---|---|
| 开场钩子 | 0-5 秒 | 冲突/异常/结果预告直接砸出来 | 第一句台词或第一个画面即钩子 |
| 冲突推进 | 5 秒-结尾前 10 秒 | 主角行动→受阻→变化 | 至少一次小反转或信息增量 |
| 结尾卡点 | 最后 5-10 秒 | 悬念/危机/反转/选择/关系突变 | 戛然而止，追更动力拉满 |

## 四、完整示例（单场 5 镜头）

```
## 场景一
### 内·医院走廊·夜（预计 35 秒）
情绪基调：悬疑

| 镜头 | 景别 | 画面与动作 | 对白 / OS / VO | 音效 | 字幕 |
|---|---|---|---|---|---|
| 1 | 全景 | 林夏冲进走廊，护士拦住她 | 护士：家属不能进去 | （急促脚步声） | |
| 2 | 近景 | 林夏抬头，手术灯亮着 | 林夏：谁签的字？ | （心电监护音） | |
| 3 | 特写 | 病床上的男人手背，有一枚旧戒指 | | （寂静） | 字幕：戒指内侧刻着另一个名字 |
| 4 | 近景 | 林夏盯着戒指，脸色骤变 | OS-林夏：这枚戒指，三年前就丢了 | | |
| 5 | 特写 | 手机屏幕亮起，备注"他"来电 | | （短信提示音） | 字幕：你知道的，都是假的 |
```

> 示例要点：每镜头 3-10 秒可拍；对白全为短句；OS 只一句；字幕卡点承载关键信息；镜头 5 的来电即"危机型卡点"入口。

## 五、禁止事项

- 禁止写出剧本元素之外的内容（如"这里插入回忆蒙太奇"——应写成具体镜头）
- 禁止对白中写内心想法（内心戏必须 OS）
- 禁止一个镜头塞两段对白、两个动作
- 禁止横向构图描述（竖屏只有高画幅）
