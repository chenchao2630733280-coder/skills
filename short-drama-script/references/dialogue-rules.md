# 对白规则（短句 / 口语化 / 信息密度 / 情绪推进）——懒加载参考

> 本文件由 `short-drama-script` 的 SKILL.md §三 懒加载引用。

## 一、七条硬规则

1. **短句**：单句 ≤20 字；一次发言 ≤2 句；禁止连环追问式长对白
2. **口语化**：台词是"说出来的"，不是"写出来的"；删除书面语（"然而""因此""是否"）
3. **信息密度高**：每句至少传递一个有效信息（事实/态度/威胁/承诺/秘密）
4. **情绪推进**：每句对白必须推动剧情 / 关系 / 情绪至少一项，三不沾即删
5. **禁无信息量寒暄**："在吗""吃了没""好久不见"（除非这句话本身是计谋/试探）
6. **禁大段独白**：内心戏拆成 OS 短句配画面；一个人连续讲超过 3 句即违规
7. **口吻一致**：同一角色跨集用词、句式、口头禅稳定（对照 STORY_SPEC 人物卡）

## 二、好 / 坏例对照

| 坏例 | 问题 | 好例 |
|---|---|---|
| 你今天来这里是有什么特别的事情需要处理吗？ | 长句、书面语、无情绪 | 你来干什么？ |
| 我很生气，非常生气，你怎么能做出这种事情来呢？ | 重复、无信息增量 | 你还有脸来？ |
| 在吗？有空吗？想跟你聊聊 | 无信息量寒暄 | 那笔钱，你动了？ |
| 其实我早就知道了，我只是一直没有说出口，因为我害怕你难过 | 大段独白 | OS-主角：原来我才是最后一个知道的 |
| 他这个人吧，怎么说呢，就是那种……你懂的 | 含糊、无信息 | 他骗了所有人。 |

## 四、OS / VO 使用规则

- **OS 内心独白**：1-2 句内讲清；必须配合画面（表情/动作/空镜），不重复画面已表达的信息
- **VO 旁白**：用于时间跳跃、开场背景交代、终局总结；每集 ≤1 处、≤2 句
- 禁止：3 句以上连续 OS；OS 与对白内容重复；用 OS 替观众解说"他没想到…"

## 五、情绪推进对白模板（高频场景）

| 场景 | 套路 | 示例 |
|---|---|---|
| 压迫 | 对手短句施压，主角沉默或反弹 | 对手：三天。三天查不清，你走人。 |
| 反击 | 主角用信息/规则反将一军 | 主角：你忘了吗，合同是你签的。 |
| 小胜 | 一句点破 + 对方脸色变化 | 主角：我等的就是你这句话。 |
| 关系升温 | 一个让步 + 一个试探 | A：这次，我信你。B：为什么？A：没有为什么。 |
| 背叛 | 背叛者用旧情包装新立场 | 背叛者：我没办法，我也有要护的人。 |
| 绝境 | 主角承认失败 + 留一口气 | 主角：我认输。但你别忘了—— |

## 六、字数自检

- 台词量 300-600 字/集（约等于 90-180 秒语速 3.3 字/秒）
- 对白行数 25-45 行/集；单集对白占比 40-60%，其余为动作/画面/字幕承载
- 超 600 字 → 优先删寒暄与重复信息；不足 300 字 → 补充行动中的信息交换
