# 对白规则（短句 / 口语化 / 信息密度 / 情绪推进）——懒加载参考

> 本文件由 `short-drama-script` 的 SKILL.md §三 懒加载引用。

## 一、七条硬规则

1. **短句**：单句 ≤20 字；一次发言 ≤2 句；禁止连环追问式长对白
2. **口语化**：台词是"说出来的"，不是"写出来的"；删除书面语（"然而""因此""是否"）
3. **信息密度高**：每句至少传递一个有效信息（事实/态度/威胁/承诺/秘密）
4. **情绪推进**：每句对白必须推动剧情 / 关系 / 情绪至少一项，三不沾即删
5. **禁无信息量寒暄**："在吗""吃了没""好久不见"（除非这句话本身是计谋/试探）
6. **禁大段独白**：内心戏拆成 OS 短句配画面；一个人连续讲超过 3 句即违规
7. **口吻一致**：同一角色跨集用词、句式、口头禅稳定（对照 STORY_SPEC 人物卡）

## 四、OS / VO 使用规则

- **OS 内心独白**：1-2 句内讲清；必须配合画面（表情/动作/空镜），不重复画面已表达的信息
- **VO 旁白**：用于时间跳跃、开场背景交代、终局总结；每集 ≤1 处、≤2 句
- 禁止：3 句以上连续 OS；OS 与对白内容重复；用 OS 替观众解说"他没想到…"

## 五、情绪推进对白模板（高频场景）

| 场景 | 套路 | 示例 |
|---|---|---|
| 压迫 | 对手短句施压，主角沉默或反弹 | 对手：三天。三天查不清，你走人。 |
| 反击 | 主角用信息/规则反将一军 | 主角：你忘了吗，合同是你签的。 |
| 小胜 | 一句点破 + 对方脸色变化 | 主角：我等的就是你这句话。 |
| 关系升温 | 一个让步 + 一个试探 | A：这次，我信你。B：为什么？A：没有为什么。 |
| 背叛 | 背叛者用旧情包装新立场 | 背叛者：我没办法，我也有要护的人。 |
| 绝境 | 主角承认失败 + 留一口气 | 主角：我认输。但你别忘了—— |

## 六、字数自检

- 台词量 300-600 字/集（约等于 90-180 秒语速 3.3 字/秒）
- 对白行数 25-45 行/集；单集对白占比 40-60%，其余为动作/画面/字幕承载
- 超 600 字 → 优先删寒暄与重复信息；不足 300 字 → 补充行动中的信息交换

## 七、台词医生（AI 塑料味过滤）

> 七条硬规则挡"书面语/寒暄/长对白"，但挡不住"聪明、工整、像在说主题"的 AI 味。写完对白后用下面 5 刀过一遍。

1. **删直接表情绪/主题的句子**："我很痛苦""人生就是这样""我们都渴望被理解"——这类话情绪说破、主题点破，一律删
2. **每句都要有说话者当下的目的**：这句是为了施压/试探/示弱/隐瞒/要一个东西？无目的即删
3. **至少加入一个打断或沉默**：真实对话有抢话、有顿住；过于一递一句地工整，一定是 AI 味
4. **用具体动作/物件代替情绪描述**：递遥控器 ≠ 说"我爱你"；掐灭烟 ≠ 说"我很焦虑"
5. **让两人听起来像真实生活会说的人话**，而非编剧写的"成败金句"

### 好 / 坏例对照（AI 工整句 → 口语生活句）

| 坏例（AI 味/说教） | 问题 | 好例（口语+动作） |
|---|---|---|
| 我知道，你从来不轻易原谅任何人，但这次，我会等。 | 直接表主题/工整抒情 | 主角停在门口，又折回来：我明天还来。 |
| 人生本就是一场聚散，我们又何必执着。 | 直接说主题/正确废话 | 她低头，把合照翻面扣在桌上。 |
| 我以为我们会一直走下去，可是我们都变了。 | 直接表情绪/无当下目的 | 她没抬头：车票，两张，退了。 |
| 我这一生，最后悔的就是遇见你。 | 金句化/过满 | 他笑了笑，把打火机留在了她桌上。 |

## 八、温度四则（人性化写作 · 让角色活在生活里）

> 台词医生挡"工整"，温度四则添"人味"。核心不是加煽情戏，而是**把人物当人、把观众当朋友**——用不体面、不完美、不合逻辑、没说出口的真实瞬间，代替形容词和说教。观众合上剧本后心里那点说不清的酸软，就是温度。

1. **具体代替形容词**：找出剧本里所有表达情感的形容词（温柔 / 愤怒 / 孤独 / 关心 / 难过），全部删掉，换成一件具体小事。判断标准：写得出"他很难过"不算过，写得出他"把遥控器留在桌上、那天再没开车过来"才算。

2. **克制，不要解释**：写完一段情绪戏后，删掉所有解释人物动机的句子（"她之所以这样，是因为从小缺爱"）。只留动作、对白和沉默，让观众自己想通。

3. **感官细节唤醒共同记忆**：每个主要场景加**一个**与情绪无关的感官细节（空调外机滴水声 / 消毒水味 / 旧沙发弹簧响 / 指甲缝里的面粉），只写一个、不贪多，让观众觉得"我见过这个"。

4. **不完美的善意**：允许一次善意"不顺利"——想帮忙帮了倒忙、想安慰说了错话、想给钱却给了张太新的钱。善意在不顺里才显得真。

> **与 §七 的分工**：§七 删 AI 的"正确"（说教 / 金句 / 塑料感）；本节添加 AI 给不出的"温度"（具体 / 留白 / 笨拙）。两套一起用：先过 5 刀去掉工整，再上 4 则注入人味。

| 坏例（形容词·解释·说教） | 问题 | 好例（具体·留白·笨拙） |
|---|---|---|
| 他很爱父亲。 | 直接说爱 | 母亲总把鱼肚子夹给女儿，自己吃鱼尾；女儿故意说"鱼尾好吃"后，她每次也把鱼尾夹给女儿——她其实根本不爱吃鱼尾。 |
