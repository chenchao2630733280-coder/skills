# 真实数据驱动事件卡 · 批量生产流水线(通用版)

> 配套 `short-drama-game-adapt` 的"真实数据/历史驱动事件卡"场景(如重生经济模拟、历史战略、名人传记游戏)。解决"如何**可溯源地批量产出事件卡**":模板管结构,**信息采集管真实性**,真实性自检管质量。复制 §4 的 Prompt 给 LLM / 子代理即可投产。

---

## 1. 生产四阶段(总览)
| 阶段 | 目标 | 关键动作 |
|---|---|---|
| **A 信息采集** | 史实可溯源 | 用搜索核实每年真实大事件 + 资产/数值拐点,记录日期/方向/受影响对象/来源 URL |
| **B 数据映射** | 选择→真实动作 | 宏观卡关联真实序列测得的方向;个人卡每个选项映射"真实存在且当时可获得"的对象 @ 真实日期 |
| **C 模板填充** | 题材 voice | 套用模板,情绪化包装,写 fogHint(不剧透幅度) |
| **D 真实性自检** | 质量门禁 | 逐卡打勾红绿灯规则,不达标重写或删 |

> **核心原则**:价格/数值以"已烘焙的真实序列"为唯一真相。宏观卡是对真实已发生变动的**叙事包装**,不要手填 shock 倍数;个人卡的选择映射到真实可结算的动作,不手填回报。

---

## 2. 信息采集清单(按维度)
**宏观事件(每年必查)**
- 关键词:`"<年> <领域> 大事件"`、`"<年> <核心标的> 牛/熊/崩"`、`"<年> <政策/危机>"`。
- 必记字段:真实日期、事件名、影响对象(标的 id 列表)、方向(涨/跌/震荡)、持续约天数(从真实序列测得)、来源 URL。

**个人剧情事件(按年代挑"有真实机会抓手"的节点)**
- 抓"熟人/机会/诱惑"型场景:新兴对象刚冒头、政策风口、危机抉择。
- 每个选项须能落到**真实存在且当时可获得**的对象与日期;收益由真实序列结算。

**大众记忆点筛查(入选第一关,先于真实性)** —— 见 `short-drama-game-adapt` §四
- 候选先过"记忆点"关:不刷专业资讯、只刷短视频的普通人,看到标题会不会"哦我懂"?
- 三档来源优先选:① 题材/社交刷屏梗 ② 全民热议事件 ③ 身边可感知数值。
- 直接淘汰:冷门标的、晦涩衍生品、纯专业术语、仅业内人士懂的数据事件。
- 每张卡产 `memoryStrength`(1-5):**仅 ≥3 进库,≥4 优先进 MVP。**

**真实性来源优先级(从高到低)**
1. 官方/权威:统计部门、监管、交易所公告、行业权威数据源。
2. 主流媒体史料的历史稿。
3. 共识性公开资料(百科的"X年X事件"条目)。
4. 无法核实 → 标 `[传闻]` 或删除,**严禁编造精确数字**。

---

## 3. 真实性红绿灯规则(自检用)
| 灯 | 判定 | 处理 |
|---|---|---|
| 🟢 绿 | 日期/方向/受影响对象有可核查来源,选择映射真实动作 | 通过 |
| 🟡 黄 | 事件真实但精确幅度/具体日期模糊(如"约年中") | 保留,幅度用区间描述,不写死 |
| 🔴 红 | 无法核实 / 与真实序列矛盾 / 选择映射虚构对象 / **memoryStrength<3(大众无记忆)** | 删除或重写 |

**迷雾纪律**:fogHint 只给"方向感/情绪"(如"你记得那年有场大崩溃,但忘了跌多少"),**绝不**写具体倍数、具体顶/底日期、具体哪天该买卖。

---

## 4. 可直接粘贴的生产 Prompt
```
你是《{游戏名}》的"事件卡史料生产员"。为指定起点年区间,批量产出【史实可溯源】的宏观事件卡 + 个人剧情事件卡,严格对齐下方 JSON Schema,并用题材 voice 包装。

# 硬性约束
1. 真实优先:所有日期、涨跌方向、受影响对象必须来自可公开核查的史料/数据,严禁编造具体数字。无法核实的内容标 [传闻] 或删除。
2. 价格真相:宏观卡是对"已烘焙真实序列"中真实变动的叙事包装——只标注影响对象 + 方向 + 持续约 N 天(基于真实序列测得),不要手填 shock 倍数。
3. 个人卡:每个选项必须映射"真实存在且当时可获得"的对象 @ 真实日期,其收益由真实序列结算,不手填回报。
4. 未来迷雾:fogHint 给方向感/情绪,不剧透精确幅度、不写具体顶/底日期。
5. 大众记忆点优先(最高优先级):所有候选先过"记忆点"关——一个不刷专业资讯、只刷短视频的普通人,看到标题会不会"哦我懂"?优先选题材梗/全民事件/身边数值;直接淘汰冷门标的、衍生品、纯术语。每张卡必须产出 memoryStrength(1-5),仅 ≥3 进库,≥4 优先进 MVP。

# 生产四阶段
A 信息采集:对区间内每一年,用搜索工具核实真实大事件与数值拐点,记录 日期/事件/影响对象/方向/持续/来源URL;并就每个候选先打 memoryStrength(1-5),凡 <3 直接放弃,不进入后续阶段。
B 数据映射:宏观卡 affects + 从真实序列测得的方向与持续;个人卡每个选项写 effect(买/卖 真实对象@真实日期 / 建锚对象),确保历史上可结算。
C 模板填充:
   宏观模板=【memoryStrength】+【日期】+【一句话史实(大众语言)】+【对持仓意味】+【可选战术抉择】。
   个人模板=【memoryStrength】+【日期】+【题材式场景(熟人/机会/诱惑)】+【两难 A/B,各映射真实动作】+【模糊 hint】。
   voice:bold、情绪化、爽点/痛点,用大众词,禁 ticker/术语。
D 真实性自检:逐卡打勾——
   [ ] 大众记忆点过关(memoryStrength≥3,普通人看到标题"哦我懂")?  [ ] 日期/事件有可核查来源?
   [ ] 选择映射真实动作(非虚构)?  [ ] 未剧透精确幅度/顶底日期?
   [ ] 数量达标(区间 8-12 张,宏观+个人混合,且≥4 的占多数)?
   [ ] 与已写卡无重复/矛盾?  任一未过 → 重写或删。

# JSON Schema(严格对齐)
宏观卡:
{
 "id","type":"macro","date","memoryStrength":(1-5),"title","narrative",
 "affects":[对象id...],"shock":{"<对象id>":方向系数,"durationDays":N},
 "fogHint","reaction?":{prompt,options:[{label,effect,risk?,requiresPermit?}]}
}
个人卡:
{
 "id","type":"personal","date","memoryStrength":(1-5),"title","narrative",
 "choices":[{label,effect:{action:"buy|sell|none",asset,amount?,at}}],
 "fogHint"
}

# 输出顺序
1) 采集摘要:每条事件一行 = 事件 | 日期 | memoryStrength(1-5) | 来源URL | 灯色(🟢/🟡/🔴)。
2) 卡片数组(JSON,严格对齐 Schema,含 memoryStrength 字段)。

# 本次输入变量(调用方填写)
- 起点年:__
- 可用对象:__
- 目标张数:__
- 重点年代:__
- 记忆点门槛:默认 memoryStrength≥3 进库,≥4 优先进 MVP
```

---

## 5. 输入/输出契约
- **输入**:起点年、可用对象清单(含 era-gating/年代可得性)、目标张数、重点年代、记忆点门槛。
- **输出**:① 采集摘要(来源 + 灯色)② 合规 JSON 数组。两者都进版本库,采集摘要供人工抽检史料真实性。

---

## 6. 生产示例(含信息采集过程)
**宏观卡 — 2015 股灾**(记忆强度 ★★★★★)
- 采集:搜索"2015 A股 股灾 日期" → 上证 2015-06-12 见顶 5178,6 月起连续千股跌停,监管清理配资;来源:监管公告/权威媒体。灯色 🟢。
- 填充:
```json
{
 "id":"macro_2015_crash","type":"macro","date":"2015-06-12","memoryStrength":5,
 "title":"股灾来了","narrative":"监管清理配资,大盘连续千股跌停。你满仓的词像悬在头顶。",
 "affects":["CSI300","CYB"],"shock":{"CSI300":-0.5,"CYB":-0.55,"durationDays":90},
 "fogHint":"你隐约记得 2015 有场大崩溃,但忘了具体跌多少、哪天到底。",
 "reaction":{"prompt":"满仓被套,怎么办?",
   "options":[{"label":"死扛","effect":"holding"},{"label":"割肉","effect":"force_sell_all"},{"label":"加杠杆博反弹","effect":"add_leverage","risk":"high","requiresPermit":"leverage"}]}
}
```
**个人卡 — 某新兴资产诞生年**(记忆强度 ★★★★★)
- 采集:搜索"<资产> 诞生 早期价格" → 创世日期、早期近乎免费、后来数万倍;来源:权威数据源/史料。灯色 🟢(诞生属实,倍数用"后来离谱"不写死)。
- 填充:
```json
{
 "id":"event_asset_genesis","type":"personal","date":"<创世日>","memoryStrength":5,
 "title":"朋友劝你买种'新东西'",
 "narrative":"极客朋友神秘兮兮:有种叫 X 的东西,一块钱一个,要不要来点?你当他是骗子。",
 "choices":[{"label":"买 1 万块试试","effect":{"action":"buy","asset":"X","amount":10000,"at":"<创世日>"}},
            {"label":"不当冤种","effect":{"action":"none"}}],
 "fogHint":"你只觉得这玩意儿离谱,不确定它后来到底多疯。"
}
```

> 每次生产后,采集摘要交人工抽检;红/黄灯条目需复核来源后再合并进全局事件库。
