# 短剧 / IP 游戏化改编方法论

> **单一来源说明**:本 skill 的通用设计原则(大众记忆点 / 广告双价值 / 不可逆阀门 / 提取设定做机制)已提炼沉淀至 game-blueprint 的 `references/design-principles-narrative-adaptation.md`,生成蓝图时由 game-blueprint 自动加载。本 skill 专注**改编 workflow** 与 **6 角度框架(原则 2)**,其余原则以引用为主,不重复定义。

把"短剧/影视/小说/社会热点"的设定变成**可玩机制**,而不是把剧情搬进游戏。本 skill 提供一套经过实战验证的转化框架与设计铁律,可直接喂给 game-blueprint / game-spec 产出蓝图与技术设计。

---

## 一、何时调用

- 用户说:"把 XX 短剧改成游戏""XX 题材能不能做小游戏""这个 IP/热点怎么游戏化""从短剧找灵感做个游戏"。
- **与 game-topic-brainstorm 的分工**:game-topic-brainstorm 是"从 0 到 1 脑暴选题";本 skill 是"**已有题材 → 机制**"的改编方法论。已有明确题材(某短剧/某 IP/某社会梗)时优先本 skill。
- 输出建议:把下面框架跑一遍,产出一个"机制骨架 + 大众记忆点清单 + 广告/风险模型",再交 game-blueprint 出蓝图。

---

## 二、核心铁律:提取设定做机制,不搬剧情

把短剧的"爽点/设定"做成玩法机制,而不是把剧情搬进游戏。

- **前者 = 游戏(留存好)**;**后者 = 互动视频(速朽)**。反面教材:《别崩人设啊》冲抖音 TOP2 却两月跌出 TOP100,病根是"玩法单一 + 无 meta 长线"。
- **破内卷公式**:`成熟休闲玩法做骨 + 短剧叙事做皮 +(可选)AI 赋能`。已验证跑通:《大店小二》(短剧开场+经营)、《甜甜旅行》(合成+AI 素材)。
- 一句话检验:"如果删掉所有剧情文本,这个玩法还成立吗?"成立 = 真游戏;不成立 = 互动视频。

---

## 三、6 角度转化框架

从"短剧设定"到"游戏机制"的通用映射,挑 1-2 个做主玩法,其余做 meta/支线:

| 角度 | 提取的短剧设定 | 游戏机制 | 代表题材 |
|---|---|---|---|
| ① 数值成长 | 隐藏身份/实力(战神/赘婿/神豪) | 解锁身份→战力/数值飙升 | 点击显露"我才是战神" |
| ② 分支选择 | 重生/复仇的关键抉择 | 节点选项→多结局 | 选错即 BE,看广告改命 |
| ③ 收集图鉴 | 群像/萌宝/甜宠角色 | 角色/结局图鉴收集 | 集齐 N 种隐藏结局 |
| ④ 经营模拟 | 总裁/豪门/开店 | 经营公司店铺赚钱升级 | 穿越经营逆袭 |
| ⑤ 打脸关卡 | 逆袭打脸反派 | 每关=一个反派,割草/塔防 | 肉鸽割草推进剧情 |
| ⑥ 赌·捡漏 | 鉴宝/捡漏/重生逆袭 | 逐步揭示价值,卖出套利 | 原石开窗赌绿 |

> 实践:本作"重生经济模拟器"即 ②分支选择(重生选年)+ ⑥赌·捡漏(用真实数据赌拐点)的融合。

## 四、大众记忆点优先原则(大众向游戏入选铁律 · 详见 game-blueprint narrative-adaptation 原则 3)

普通大众(刷短视频/看短剧的人)的共鸣来自"集体记忆",**不是专业深度**。一切面向大众的内容(标的/事件卡/关卡主题/广告钩子)先过这一关。

- **记忆点三来源**:
  1. **短剧/社交刷屏梗**(霸总/神豪/豪门/房价暴涨/比特币暴富/直播带货/拆迁暴富)
  2. **全民热议社会事件**(疫情/教培双减/恒大暴雷/股灾/奥运/蚂蚁暂缓)
  3. **身边可感知价格**(房价/油价/菜价/黄金/茅台/猪肉猪周期)
- **memoryStrength(1-5)评分**:5=全民梗张口就来,4=强情绪标签,3=看新闻联想到"那件事",2=仅业内人士懂,1=无认知。**MVP 仅收 ≥3,≥4 优先进包**。
- **评分独立于数据真实性**:一个标的可以数据完美(如冷门个股),但 memoryStrength=1 → **直接砍**。记忆点优先于数据完备度。
- **文案纪律**:用大众语言,禁止 ticker/术语(用"大盘""房子""币"),保证短剧用户看得懂、有共鸣。
- **自检一句话**:"一个不刷财经新闻、只刷短视频的人,看到这个标题会不会'哦我懂'?"答否 → 重写或换题。

## 五、广告双价值模型(IAA 小游戏变现锚 · 详见 game-blueprint narrative-adaptation 原则 6)

激励视频不只"去烦/跳过",可卖两种**真实价值**,让广告长在核心循环上:

1. **信息优势**:知道未来/高收益点。例:手动跳日是"迷雾下盲跳"(不知次日涨跌),看广告则"定位下一个高收益日"(告诉你高收益点在哪)——买卖的是"重生外挂=知道未来"。
2. **风险对冲**:放大收益/兜底失败。例:看广告开杠杆放大单笔收益;破产后看广告重生回滚到上一次操作前。

- **平衡**:免费路径(操作/盲跳)与付费路径(信息/对冲)并存 → 玩家用操作换免费、用广告换省事/保命,**广告数自然可控**,不强迫插屏。
- **频次规则**:均主动触发,同位每天 ≤1 次,定位类整局硬上限;破产重生不限次(本身是变现点)但回滚吞掉后续成果 = 软性自限。
- **陷阱**:别说"看广告=省事/跳过无聊",低估了广告价值。广告买的是**优势/兜底**,不是时间。

---

## 六、不可逆操作 + 唯一付费安全阀门(详见 game-blueprint narrative-adaptation 原则 5)

- 常规操作**不可回退**(决策有代价)→ 制造张力与"眼光=技能"。
- 仅设**一个付费安全阀门**作为例外(如破产看广告重生、回滚到上一次操作前),代价 = 吞掉该操作之后的全部成果 + 权限不退还(重生后再用须重看广告)→ 软性自限,**不破坏不可逆原则**。
- 这套模式把"贪婪陷阱"从文案层**机制化**:放大收益也放大翻车,翻车有兜底但代价真实。

## 七、与 game-* 流水线衔接

1. 用本 skill 把短剧/IP 拆成 **机制骨架 + 大众记忆点清单 + 广告/风险模型**(产出自用文档,如 `docs/ADAPT_NOTES.md`)。
2. 调 **game-blueprint** 出蓝图——本原则的 memoryStrength / 广告双价值 / 不可逆阀门可直接作为设计约束写入 §4-§7。
3. 调 **game-spec** 定技术设计——重点:状态快照/回滚(付费安全阀门的技术依赖)、数据层契约。
4. 若涉及**真实历史/数据驱动事件卡**,读 `references/event-card-production.md`(批量生产流水线:信息采集+真实性红绿灯+模板+Prompt,含 memoryStrength 门禁)。

## 八、质量检查清单

- [ ] 玩法脱离剧情文本仍成立(非互动视频)
- [ ] 主玩法来自 6 角度框架的 1-2 个,其余作 meta
- [ ] 所有大众向内容过 memoryStrength 筛选(MVP ≥3)
- [ ] 广告位长在核心循环上,卖"信息优势/风险对冲"而非纯跳过
- [ ] 免费路径与付费路径并存,广告数可自然收敛
- [ ] 存在"不可逆 + 单一付费安全阀门"张力设计
- [ ] 数据/史料类内容有明确来源与免责声明(非投资建议)
