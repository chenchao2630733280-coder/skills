# 观看动力变量库与四时间尺度模板

本文件是 short-drama-topic-brainstorm 的懒加载细则，Step 2（观看动力引擎）时读取。

## 一、观看动力变量库

观看动力 = 观众持续追更的心理引擎。每个选题必须标注 **1 个主动力 + 1-2 个辅助动力**。

| 观看动力类型 | 定义 | 典型触发 | 示例选题 |
|---|---|---|---|
| 爽感 | 即时情绪释放（打脸/逆袭/复仇） | 反派被当众揭穿 | 赘婿身份曝光打脸 |
| 悬念 | 信息差驱动的追更（秘密/真相） | 每集结尾抛谜题 | 失踪的妻子每天回家 |
| 情感 | 关系变化驱动的共情（虐/甜/团宠） | 误会、牺牲、守护 | 失忆后他仍记得我 |
| 逆袭 | 底层翻身的过程性满足 | 从谷底到巅峰的阶梯 | 三年前被退婚，三年后她封后 |
| 共鸣 | 现实情绪投射（职场/家庭/中年） | 说出观众的心声 | 加班妈妈的深夜独白 |
| 猎奇 | 异世界/异常设定的新鲜感 | 陌生规则/身份 | 穿成恶毒女配后摆烂 |
| 成长 | 主角能力/心性升级线 | 集集变强可见 | 废柴嫡女修炼逆袭 |
| 复仇 | 因果报应的延迟满足 | 仇人付出代价 | 全家被害后她回来了 |
| 甜宠 | 高浓度亲密关系糖点 | 撒糖名场面 | 霸总的花式宠妻 |
| 守护 | 保护所爱引发共情 | 危机中护人 | 战神归来守护妻女 |

**选择规则**：
- 一个选题只能有 1 个主动力（决定主线与卡点类型），避免多动力分散
- 辅助动力最多 2 个，且必须服务主动力（如"爽感"主动力 + "情感"辅助 = 打脸后撒糖）

## 二、四时间尺度模板

对每个候选，用以下模板填空完成观看动力验证（Step 2 必填）。

### 1. 第一集（决定点开率：3 秒钩子 + 首集卡点）

| 追问 | 验收标准 |
|---|---|
| 前 3 秒画面/冲突是什么？ | 3 秒内有冲突/悬念/强情绪，无铺垫 |
| 主角的处境有多糟/多特别？ | 处境极端，观众立刻站队 |
| 第一集结尾卡点是什么？ | 结尾留悬念/反转/身份待揭 |

**小满足**：第一集结尾观众获得一次完整情绪释放（打脸/揭秘/糖点），同时被新悬念钩住。

### 2. 前十集（决定留存率：卡点密度）

| 追问 | 验收标准 |
|---|---|
| 每集是否有结尾卡点？ | 60-100 集 × 每集 1 个强卡点 |
| 卡点类型是否轮换？ | 悬念/冲突/情感/爽点轮换，避免单一 |
| 前十集是否完成"首钩-升级-小高潮"节奏？ | 第 3 集小反转、第 7 集关系突破 |

**小满足**：观众在前十集内至少经历 2 次"想弃剧被卡点拉回"。

### 3. 中段（决定弃剧率：新变量注入）

| 追问 | 验收标准 |
|---|---|
| 主线是否可能疲劳？ | 同质冲突连续 >10 集即疲劳 |
| 是否有新变量注入点？ | 新角色/新地点/秘密揭晓/阵营反转 |
| 新变量是否不破坏原动力？ | 新变量服务原观看动力，不偏离主线 |

**小满足**：中段每 10-15 集注入一次新变量，主线冲突升维。

### 4. 终局（决定完播与口碑：结局兑现）

| 追问 | 验收标准 |
|---|---|
| 核心谜底/目标是否兑现？ | 追剧承诺必须兑现 |
| 情绪是否释放？ | 主线情绪在终局得到完整释放 |
| 是否烂尾风险？ | 开放式结局需可控，不挖坑不填 |

**小满足**：终局 5-10 集回收全部埋点，主线情绪释放，留有 IP 延展口（可续季/衍生）。

## 三、短剧语境强制约束

- 竖屏 1080x1920；单集 1-3 分钟；总集数 60-100
- 每集 1 个强卡点；前 3 秒必须抓住观众
- 竖屏叙事：少远景、多近景/特写；对白密集；情绪外化（BGM/字幕辅助）

## 四、卡点类型速查

| 卡点类型 | 位置建议 | 示例 |
|---|---|---|
| 悬念卡 | 结尾 | 门开了，里面站着死去的人 |
| 反转卡 | 结尾/开场 | 原来他才是幕后黑手 |
| 情绪卡 | 结尾 | 她转身时哭了 |
| 冲突卡 | 结尾/中场 | 反派当众掌掴主角 |
| 信息卡 | 结尾 | 他手机上跳出妻子的定位 |

**轮换建议**：连续 3 集内卡点类型不重复，防止套路疲劳。
