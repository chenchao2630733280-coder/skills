# 工具调用配方(文生图 / 图生视频)

> 本文件对应 short-drama-forge-master §3.2 工具链。按蓝图 toolchain 加载对应小节。统一原则:每次工具调用失败重试 ≤3 次(含自动退避),仍失败走 SKILL.md §六 降级链。

---

## A. 文生图工具

### A1. 即梦(默认推荐)

- 输入参数:prompt(六要素模板)+ 画幅 9:16 + 参考图(角色图)+ 种子(如支持)
- 注意事项:角色一致性用"参考图+风格关键词";支持中文 prompt
- 失败重试:≤3 次;仍失败 → 切备选或占位图

### A2. Midjourney

- 输入参数:`/imagine {prompt} --ar 9:16 --seed {seed} --style raw`
- 注意事项:角色一致性用垫图(image prompt)+ seed;参考图 URL 需可访问
- 失败重试:≤3 次(超时/审核失败)

### A3. SD(ComfyUI)

- 输入参数:positive/negative prompt + reference(ControlNet/Image2Image)+ seed + 分辨率 1080x1920
- 注意事项:本地部署,注意显存与出图时间;角色一致性最佳(ControlNet + LoRA)
- 失败重试:≤3 次(显存/队列错误)

### A4. Flux

- 输入参数:prompt + aspect 9:16 + seed + reference(如 API 支持)
- 注意事项:文本还原强,适合字幕/道具文字场景
- 失败重试:≤3 次

---

## B. 图生视频工具

### B1. 可灵(Kling)(默认推荐)

- 输入参数:起始图 + prompt(运动描述+镜头运动)+ 时长 5s/10s + 画幅 9:16
- 注意事项:中文生态好、成本低;单镜头建议 5-10s;运动幅度过大会扭曲,控制幅度
- 失败重试:≤3 次

### B2. 即梦

- 输入参数:起始图 + prompt + 时长 + 画幅
- 注意事项:与可灵同生态,作为首选备选
- 失败重试:≤3 次

### B3. Runway

- 输入参数:起始图 + prompt + 时长(≤10s)+ motion scale
- 注意事项:画质高,运动控制项多(motion/strength);需英文 prompt
- 失败重试:≤3 次

### B4. Pika

- 输入参数:起始图 + prompt + 时长 + 参数(如 camera move)
- 注意事项:轻量快出;复杂运动需显式描述
- 失败重试:≤3 次

### B5. 海螺(MiniMax)

- 输入参数:起始图 + prompt + 时长 + 画幅
- 注意事项:中文友好,人物动态自然
- 失败重试:≤3 次

### B6. Sora

- 输入参数:起始图 + prompt + 时长 + 分辨率
- 注意事项:画质/物理最佳;成本与排队较高,按需使用
- 失败重试:≤3 次

---

## C. 通用注意

1. 参数模板:所有工具统一带 画幅 9:16 / 分辨率 1080x1920 / 时长 3-10s
2. 图生视频的起始图必须是质检通过的文生图(见 SKILL.md §二.1)
3. 每次调用记录(工具/耗时/结果)写回 manifest,便于 Gate 4 追溯
4. 工具切换优先级:默认工具 → 同生态备选 → 不同生态备选 → 降级链(见 failover-recipes.md)
