# 打击感时序配方（Juice Timing）

> 定位：`game-polish` §二 是**效果菜单**（能做什么，33 项），本文是**时序与幅度**（怎么排、给多大、什么时候不许给）。
> 代码形态见 SKILL §4.2–§4.4（粒子统一管理 / 挤压拉伸 / 镜头震动），此处只补参数与编排。

---

## 1. 事件分档与总时长预算

先给事件定档，再决定用几个通道。**档位由"这件事对玩家有多重要"决定，不由特效好不好看决定。**

| 档 | 事件举例 | 通道数 | 总时长预算 | 硬约束 |
|---|---|---|---|---|
| **P0** | 过关、失败、Boss 击破、连击里程碑 | 4~5 | ≤ 700ms | 结算 UI 弹出前留 ≥ 200ms 呼吸，不许被特效顶掉 |
| **P1** | 核心操作（跳跃/命中/消除/放置） | 3~4 | ≤ 250ms | 与操作同帧起效，延迟 > 1 帧玩家会感到"粘手" |
| **P2** | 次要反馈（按钮/拾取/飘字） | 1~2 | ≤ 150ms | 不占镜头，不打断 P0/P1 的动画 |

> 一次操作里若同时触发 P1 与 P2，P2 让位（延后或丢弃），不许排队叠加。

## 2. 五通道时序模板

一张表就是一次事件的编排。**delay 从事件发生的 tick 起算**。

### P1 核心操作（以"命中/消除"为例）

| 通道 | delay | duration | 幅度 | 备注 |
|---|---|---|---|---|
| 顿帧 hitstop | 0 | 40~60ms | 冻结**逻辑**时间 | 渲染继续跑补间，见 §3 反例③ |
| 挤压/缩放 | 0 | 100~140ms | scaleY 1.12~1.20 / scaleX 0.85~0.90 | yoyo 回正，`Quad.easeOut` |
| 粒子 | 40ms | 300~500ms | 4~8 个，初速 60~120 px/s | 向外扩散 + 衰减 |
| 飘字 | 60ms | 500~700ms | 上移 40~60px | 数字/文字，`Sine.easeOut` |
| 镜头震动 | 80ms | 120~200ms | intensity 0.006~0.012 | 只有"重"的操作才给 |

### P0 结果（过关/失败）

| 通道 | delay | duration | 幅度 |
|---|---|---|---|
| 顿帧 | 0 | 80~120ms | 冻结逻辑 |
| 缩放脉冲 | 0 | 300~400ms | zoom 1.05~1.08 后回 1 |
| 粒子 | 60ms | 600~900ms | 12~20 个，多方向 |
| 飘字/横幅 | 120ms | 700~900ms | 大字，停留 ≥ 500ms |
| 镜头 | 0 | 200~300ms | intensity 0.010~0.018 |

### P2 次要反馈

| 通道 | delay | duration | 幅度 |
|---|---|---|---|
| 缩放 | 0 | 80~100ms | 1.05，单次 |
| 飘字 | 0 | 400~600ms | 小号，上移 20~30px |
| 粒子 | — | — | 一般不给；给了也不超过 2 个 |

## 3. 三条反例（都踩过）

**① 五通道同时 `t=0` 开跑。** 结果不是"打击感强"，是"卡了一下然后花了"。玩家感知不到分层，只感到帧率掉了。→ 必须错峰，最早与最晚通道相差 60~120ms。

**② 幅度不随重要性衰减。** 捡一枚金币和过关一样炸屏 → 重要性梯度消失，P0 就不再是 P0。→ 同一通道在不同档位必须差 2~3 倍（如粒子 4~8 / 12~20 / ≤2）。

**③ 顿帧把渲染也冻住。** 那是掉帧，不是顿帧。→ 只冻结逻辑 tick，补间/粒子继续走；否则玩家看到的是"卡死"。

## 4. 归零开关（必做）

所有幅度乘以一个全局系数：

```typescript
const JUICE = 1;           // 0 = 全关；0.5 = 低配设备
sprite.scaleY = 1 + 0.2 * JUICE;
```

用途三个：截图基线比对（去动画噪声）、性能对比（特效开销占比）、低端机降级。**没有这个开关，效果层就没法被验证**——任何"截图不一致"都会先被怀疑是特效。

---

## 5. 验收（三条，缺一不可）

- [ ] **逻辑不变**：`JUICE=0` 与 `JUICE=1` 跑同一串操作，最终状态/得分/胜负逐项一致
- [ ] **无逐帧分配**：粒子走对象池，连续触发 60s 后对象数不增长
- [ ] **可叠加不雪崩**：同一事件 1 秒内连触 10 次，画面不糊、不卡、不排队
