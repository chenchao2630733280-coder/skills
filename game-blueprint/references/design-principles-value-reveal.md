# 价值揭示类 设计原则

> **核心驱动**:价值发现+造物,玩家主动驱动、连续可见、亲手塑造价值。
> **与其他原则的关系**:本原则是品类原则(第一层),指导核心循环设计。涉及变现时叠加 `monetization`,涉及数值时叠加 `economy`。
> **设计第一性原理**:价值感知应是"玩家主动驱动、连续可见、亲手塑造"的过程,而非"一次拉杆出一个数字"。

---

## 一、适用判定

| 判定信号 | 说明 |
|---|---|
| 玩家有"买入/获取未知价值物"的动作 | 购买盲盒/原石/二手货/古董/卡牌包 |
| 物品有"隐藏价值",需通过操作揭示 | 鉴定/开窗/检测/拆解/探索 |
| 揭示程度影响定价 | 露出越多估值越准 |
| 有"卖掉 vs 继续"的退出决策 | 中途可交易 |

**命中 ≥2 条 → 适用本原则**。

**典型题材**:赌石、开箱、古董鉴定、二手车交易、卡牌抽包、考古挖掘、盲盒经营。
**典型不适用**:纯跑酷、消除、塔防、竞技(核心循环不靠价值揭示)。

---

## 二、四条核心原则

### 原则 1:连续价值反馈(核心中的核心)

**原理**:把"一次性揭示价值"拆成几十个微反差,玩家每个操作都看到价值实时跳动。价值感知应是"玩家主动驱动、连续可见"的过程。

**反模式**:拉杆出数字、一键开奖、一次检测出全报告。价值反差只在"第一赌注炸一次",日常是平的。

**设计要求**:
- 揭示动作**细粒度可重复**(如"抹一刀"而非"一键拆解")
- 每次揭示后**价值实时更新并可视化**(数字跳动/颜色变化/进度条)
- 揭示**渐进**(操作N次比操作1次信息更多)
- 玩家**主动驱动**(点击/拖动/抹,非被动等待)

**检查项**:
- [ ] 核心交互是"细粒度揭示操作"而非"一键开奖"
- [ ] 每次揭示后有实时价值反馈(数值/视觉)
- [ ] 揭示有渐进性
- [ ] 玩家主动驱动,非被动观看

**正面案例**:赌石——每抹一刀,颜色/裂纹/种水面积多露一点,市场价实时跳动。
**反面案例**:一键拆解——买废品→一键拆解→出结果,价值一次性揭示。

---

### 原则 2:最优停止决策(连续赌注)

**原理**:每个揭示动作都是一次赌注,玩家持续面临"继续揭示(可能更值钱也可能更不值) vs 现在卖掉落袋为安"的张力。这是经典的"最优停止"问题,让玩家大脑一直在线。

**反模式**:单次赌注无中途退出,拉杆后只能等结果。

**设计要求**:
- 支持**中途退出并兑现**(按当前揭示程度定价)
- 继续 vs 退出的**预期收益有张力**(继续可能涨也可能跌,非单调递增)
- 退出决策点**高频存在**(每个揭示动作后都可退出)
- 已揭示信息**可被玩家用于推理**(眼光是技能,非纯运气)

**检查项**:
- [ ] 支持中途卖出/兑现,按当前揭示程度定价
- [ ] 继续揭示的预期收益非单调(有涨有跌)
- [ ] 每个揭示动作后都有退出决策点
- [ ] 已揭示信息可推理(非纯随机)

---

### 原则 3:造物飞轮(IKEA 效应)

**原理**:把"赌"变成"造",让玩家对揭示后的材料亲手塑形,生成"我的"成品。人会对亲手做的东西高估价值,成就感来自创造而非运气。

**反模式**:纯运气无产出,或产出与玩家操作无关。

**设计要求**:
- 揭示完成后有**玩家主导的造物步骤**(设计图案/选配/组合/定制)
- 造物结果**影响最终定价**(种类×大小×工艺 → 价格)
- 造物有**足够自由度**(默认图案多、可调方向大小)
- 造物产出**可收集/可展示**(成品库/图鉴),形成长期目标

**检查项**:
- [ ] 揭示后有玩家主导的造物/定制步骤
- [ ] 造物选择影响成品定价
- [ ] 造物有自由度(多图案/可调参数)
- [ ] 成品可收集展示,形成长期目标

---

### 原则 4:日经济节奏(压力与锚点)

**原理**:每日有随机市场需求 + 固定成本(房租)+ "下一天"推进,给玩家明确的日目标和节奏感。时间推进和固定成本是"今天必须搞到X"的抓地力。

> **单一来源**:日经济节奏的"产出消耗闭环"细节见 `design-principles-economy.md` 原则3。本原则聚焦"日节奏"对价值揭示体验的驱动作用。

**反模式**:无时间推进、无固定成本、无每日目标,玩家没有抓地力。

**设计要求**:
- 有**时间推进机制**("下一天"按钮/回合制)
- 有**固定成本压力**(每日房租/维护费/利息)
- 有**每日随机需求**(市场每天收购不同种类/数量的成品)
- 日目标**清晰可达**(赚够房租是明确小目标,完成有正反馈)

**检查项**:
- [ ] 有"下一天"/回合推进机制
- [ ] 有每日固定成本(房租/维护)
- [ ] 有每日随机市场需求
- [ ] 日目标清晰(赚够成本)且可达

## 三、协同关系

四原则构成**价值感知闭环**:

```
原则1(连续反馈)  ──让玩家看见价值变化──→  原则2(最优停止)
     ↑                                          │
     │                                          ↓
原则4(日经济)  ←──给造物以目标和压力──  原则3(造物飞轮)
```

- **原则1+2** 构成"揭示阶段"核心手感:看见变化 + 决策继续/退出
- **原则3** 把揭示结果转化为"我的成品",把赌徒变创造者
- **原则4** 给造物以经济目标和节奏压力,让成品有去处(卖掉付房租)
- 缺任何一环闭环断裂:缺1则平、缺2则等、缺3则空、缺4则散

## 四、生成蓝图时的应用流程

### Step 1:映射四原则到机制

| 原则 | 对应机制(必须存在) | 机制示例(赌石) |
|---|---|---|
| 连续价值反馈 | 细粒度揭示 + 实时变价 | 抹刀开窗 + 市场价跳动 |
| 最优停止 | 中途卖出 | 按当前揭示度定价卖出 |
| 造物飞轮 | 成品定制 | 化图案/调方向/生成翡翠 |
| 日经济节奏 | 日推进 + 房租 + 随机需求 | 下一天 + 房租 + 每日收购 |

### Step 2:填写核心玩法循环

```
每日循环:
  买入未知物 → [原则1]逐步揭示(每次实时变价) → [原则2]中途卖/继续开
  → [原则3]开完后造物定制 → 成品入库 → [原则4]卖成品回收资金
  → 付房租 → 下一天
```

### Step 3:质量自检

对照检查项,在"5. 核心机制清单"中确认四类机制都存在。任何一类缺失,在"9. 关键技术风险"中标注"缺{原则}机制,核心循环断裂"。

## 五、隐藏价值的设计要点(原则1的关键实现)

### 5.1 隐藏价值与外观的关系

| 关系 | 手感 | 适用场景 |
|---|---|---|
| **正相关**(好看=值钱) | 无脑买好看的,无眼光空间 | ❌ 不推荐,退化成看脸 |
| **负相关**(难看=可能值钱) | 捡漏感,眼光成技能 | ✅ 推荐,制造信息差 |
| **无关**(外观无信息) | 纯赌博,无推理空间 | ⚠️ 仅纯随机游戏适用 |

**推荐**:隐藏价值与外观**负相关或弱相关**,让"捡漏"成为可能,眼光变成可学习的技能。

### 5.2 揭示的信息维度

隐藏价值应由**多个维度**共同决定,揭示时逐步暴露:
- 颜色(绿/紫/墨/晴水...)
- 裂纹(无/少/多/贯穿...)
- 种水(干/糯/冰/玻...)
- 面积(露出的占比)

每个维度的揭示都应影响估值,玩家根据已揭示维度**推理**未揭示部分,形成"眼光"。

### 5.3 禁止剧透

**严禁**在买入前或揭示过程中显示最终价值/隐藏价值。玩家只能看到**已揭示部分**对应的当前市场价,最终价值在完全揭示或卖出时才确定。剧透会杀死"最优停止"的张力。
