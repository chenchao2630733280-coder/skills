# 叙事化改编设计原则

> 核心驱动:把"已有题材 / IP / 社会热点 / 真实数据"转化为**可玩机制**,而非把剧情搬进游戏。
> 与其他原则关系:本原则是 game-blueprint 原则体系的**前置 / 辅助层**——当需求是"把 XX 题材改成游戏"(已有题材,非从 0 脑暴)时,先走本原则做"题材 → 机制"转化,再接 overview 决策树定主品类(即时反馈 / 价值揭示 / 思考顿悟)。本原则指导"核心玩法循环"的选题与机制来源,与品类原则互补、不与变现 / 数值通用原则冲突。

---

## 一、适用判定

| 信号 | 命中 → 先走本原则 |
|---|---|
| 用户给明确题材("把 XX 短剧 / IP / 热点改成游戏") | 是 |
| 需求含"改编 / 游戏化 / 题材切入点" | 是 |
| 想用真实世界数据 / 历史人物 / 社会事件做玩法 | 是 |
| 纯粹从 0 脑暴玩法(无既定题材) | 否 → 走 game-topic-brainstorm,不读本原则 |

> 分工:本原则与 game-topic-brainstorm 不重叠——后者从 0 选题,本原则"已有题材 → 机制"。题材已存在时优先本原则。

---

## 二、核心原则

### 原则 1:提取设定做机制,不搬剧情(改造铁律)
- **原理**:把题材的"爽点 / 设定"做成玩法机制,而不是把剧情搬进游戏。前者 = 游戏(留存好),后者 = 互动视频(速朽)。
- **反模式**:《别崩人设啊》冲抖音 TOP2 却两月跌出 TOP100,病根是"玩法单一 + 无 meta 长线"。
- **设计要求**:破内卷公式 = `成熟休闲玩法做骨 + 题材叙事做皮 +(可选)AI 赋能`。已验证跑通:《大店小二》(短剧开场 + 经营)、《甜甜旅行》(合成 + AI 素材)。
- **检查项**:"删掉所有剧情文本,玩法还成立吗?"成立 = 真游戏;不成立 = 互动视频。

### 原则 2:题材 → 机制 6 角度转化框架
从题材设定到游戏机制的通用映射,挑 1-2 个做主玩法,其余做 meta / 支线:

| 角度 | 提取的题材设定 | 游戏机制 | 代表题材 |
|---|---|---|---|
| ① 数值成长 | 隐藏身份 / 实力(战神 / 赘婿 / 神豪) | 解锁身份→战力 / 数值飙升 | 点击显露"我才是战神" |
| ② 分支选择 | 重生 / 复仇的关键抉择 | 节点选项→多结局 | 选错即 BE,看广告改命 |
| ③ 收集图鉴 | 群像 / 萌宝 / 甜宠角色 | 角色 / 结局图鉴收集 | 集齐 N 种隐藏结局 |
| ④ 经营模拟 | 总裁 / 豪门 / 开店 | 经营公司店铺赚钱升级 | 穿越经营逆袭 |
| ⑤ 打脸关卡 | 逆袭打脸反派 | 每关 = 一个反派,割草 / 塔防 | 肉鸽割草推进剧情 |
| ⑥ 赌 · 捡漏 | 鉴宝 / 捡漏 / 重生逆袭 | 逐步揭示价值,卖出套利 | 原石开窗赌绿 |

> 完整映射表与实例在 `short-drama-game-adapt` skill(改编 workflow 专用)。本原则只定"必须提供题材 → 机制映射"这一要求。

### 原则 3:大众记忆点优先(memoryStrength 1-5)
- **原理**:普通大众(刷短视频 / 短剧的人)共鸣来自"集体记忆",**不是专业深度**。一切面向大众的内容(标的 / 事件卡 / 关卡主题 / 广告钩子)先过这一关。
- **记忆点三来源**:① 短剧 / 社交刷屏梗(房价暴涨 / 比特币暴富 / 直播带货 / 神豪);② 全民热议社会事件(疫情 / 教培双减 / 恒大 / 股灾);③ 身边可感知价格(房价 / 油价 / 黄金 / 茅台 / 猪肉)。
- **评分 memoryStrength(1-5)**:5= 全民梗张口就来,4= 强情绪标签,3= 联想到"那件事",2= 仅业内懂,1= 无认知。**MVP 仅收 ≥3,≥4 优先进包**。
- **反模式**:数据完美但记忆弱(如冷门个股)→ 直接砍。记忆点优先于数据完备度。
- **设计要求**:文案用大众语言,禁 ticker / 术语(用"大盘""房子""币")。
- **检查项**:"不刷财经新闻、只刷短视频的人,看到标题会不会'哦我懂'?"否 → 重写或换题。

### 原则 4:把叙事爽点翻译成可玩约束(设计价值观)
- **原理**:每次把"文案层好点子"推向"机制层真系统"。叙事爽点若只做文案提示(如"贪婪陷阱"警告),张力弱;做成可玩约束(如杠杆放大收益也放大翻车),张力实。
- **设计要求**:凡剧情给的"选择 / 风险 / 爽点",尽量落成"影响数值 / 状态 / 可操作"的约束,而非弹窗文本。
- **检查项**:每个重大剧情节点,是否对应一个可玩机制(而非纯文本)?

### 原则 5:不可逆操作 + 唯一付费安全阀门(机制张力)
- **原理**:常规操作**不可回退**(决策有代价)→ 制造"眼光 = 技能"张力;仅设**一个付费安全阀门**作例外(如破产看广告重生 / 回滚到上一次操作前)。
- **设计要求**:安全阀门代价 = 吞掉该操作后全部成果 + 权限不退还(再生用须重付费)→ 软性自限,不破坏不可逆原则。
- **反模式**:无限回退(决策无代价)、或全无兜底(劝退玩家)。
- **检查项**:是否存在"不可逆 + 单一付费阀门"张力?阀门是否软性自限?

### 原则 6:广告双价值(IAA,与 monetization 衔接)
- **原理**:激励视频不只"去烦 / 跳过",可卖两种真实价值,让广告长在核心循环上:① **信息优势**(知道未来 / 高收益点,如盲跳 vs 定位下一高收益日);② **风险对冲**(放大收益 / 兜底失败,如看广告开杠杆 / 破产后重生)。
- **设计要求**:免费路径(操作 / 盲跳)与付费路径(信息 / 对冲)并存 → 广告数自然可控,不强迫插屏。频次:均主动触发,同位每天 ≤1,定位类整局硬上限。
- **反模式**:说"看广告 = 省事 / 跳过无聊"——低估广告价值;广告买的是**优势 / 兜底**,不是时间。
- **衔接**:更完整的 IAA 档位 / 分层规则见 `design-principles-monetization.md`。

## 三、协同关系

```
题材 / IP / 热点(输入)
   │ 本原则(叙事化改编)
   ├─ 原则1 不搬剧情 → 保住"真游戏"属性
   ├─ 原则2 6角度 → 选主玩法机制
   ├─ 原则3 记忆点 → 筛标的 / 事件 / 主题
   ├─ 原则4 爽点机制化 → 强化核心循环
   └─ 原则5 + 6 张力 / 广告 → 接通用原则
        │
        ▼
overview 决策树(定主品类)
   ├─ 即时反馈类 → instant-feedback
   ├─ 价值揭示类 → value-reveal
   └─ 思考顿悟类 → puzzle
        │
        ▼
通用原则(变现 monetization / 数值 economy)叠加
```

## 四、生成蓝图时的应用流程

1. 判定需求是否"已有题材改编"(§一)。否 → 不读本原则。
2. 用**原则 1** 校验:玩法脱离剧情仍成立?不成立 → 退回 user 重定或转互动视频。
3. 用**原则 2**(6 角度)把题材拆成 1-2 主玩法 + meta,写入蓝图"4. 核心玩法循环""5. 核心机制清单"。
4. 用**原则 3**(memoryStrength)筛出大众向内容清单,作为"6. 范围边界"输入。
5. 用**原则 4** 把关键叙事爽点落成可玩约束,补进机制清单。
6. 用**原则 5 + 6** 设计"不可逆 + 付费阀门"与广告双价值,写入"7. 商业化"。
7. 接 overview 决策树定主品类,叠加 monetization / economy 通用原则。
8. 若涉及真实历史 / 数据驱动事件卡,读 `short-drama-game-adapt` 的 `references/event-card-production.md`(信息采集 + 真实性红绿灯 + 模板 + Prompt,含 memoryStrength 门禁)。
