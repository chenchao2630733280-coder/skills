# 即时反馈类 设计原则

> **核心驱动**:即时爽感+高频反馈,用短反馈和密集多巴胺驱动游玩。
> **与其他原则的关系**:本原则是品类原则(第一层),指导核心循环设计。涉及变现时叠加 `monetization`,涉及数值时叠加 `economy`。
> **包含两种模式**:超休闲模式(基础)和混合休闲模式(进阶)。

---

## 一、适用判定

| 判定信号 | 说明 |
|---|---|
| 单局时长 <5 分钟 | 短反馈,快速完成一局 |
| 操作极简(1-2 种手势) | 单手可玩,学习成本近零 |
| 目标用户为泛用户(非玩家) | 需在 30 秒内 hook 住非玩家 |
| 依赖社交/裂变传播 | 排行榜/分享/挑战好友 |
| 平台为微信/抖音小游戏或 H5 | 碎片化场景,即开即玩 |

**命中 ≥3 条 → 适用本原则**。

### 模式判定(适用本原则后进一步判定)

| 模式 | 判定信号(命中≥3条) |
|---|---|
| **超休闲模式**(基础) | 无深度 meta、单局独立、纯短反馈、IAA 变现为主 |
| **混合休闲模式**(进阶) | 有深度 meta(养成/收集/升级)、局间长线目标、IAA+IAP 混合变现、受众分层(泛用户+中度玩家) |

**默认走超休闲模式**,命中混合休闲信号时切换到进阶模式(§三)。

**典型题材**:消除/合成/点击/放置/肉鸽割草/寻宝挖矿/排序/方块/螺丝。

---

## 二、超休闲模式:六条核心原则

### 原则 1:30 秒内 hook + 零学习成本

**原理**:泛用户耐心极低,前 30 秒决定留存。必须"打开即会,一眼看懂",用首屏强反馈立刻 hook。

**反模式**:新手引导 5 步以上、需读文字、首屏无明确动作、首次操作无反馈。

**设计要求**:
- 零引导(无遮罩教程,视觉引导替代文字)
- 1-2 种手势(点击或点击+拖动)
- 首操作强反馈(数字飞出/满屏特效/震动)
- 目标一眼可见(首屏即知"要做什么")

**检查项**:
- [ ] 无文字教程(或 ≤1 步引导)
- [ ] 手势种类 ≤2 种
- [ ] 第一次操作后有强反馈
- [ ] 首屏目标无需思考即可识别

---

### 原则 2:单局短反馈 + 即时重试

**原理**:单局 1-5 分钟,失败后 1 秒重开,无结算动画/无加载。利用"再来一把"的极低门槛制造连续游玩。

**反模式**:单局 >10 分钟、长结算动画、重开需返回菜单、加载 >2 秒。

**设计要求**:
- 单局 ≤5 分钟(超休闲 <3 分钟)
- 失败即重开(结算 ≤2 秒,"再来一把"为默认焦点)
- 无惩罚重开(不扣资源/不降等级)
- 局间有 meta 进度承接(单局失败也有部分收益)

**检查项**:
- [ ] 单局 ≤5 分钟(超休闲 ≤3 分钟)
- [ ] 结算到重开 ≤2 秒
- [ ] 重开无惩罚
- [ ] 局间有 meta 进度承接

---

### 原则 3:心流难度曲线(易上手难精通)

**原理**:前几关极易建立信心,随后难度陡升制造挫败,但"差一点就过"驱动重试。曲线呈"缓升→陡升→plateau→再陡升"。

> **单一来源**:难度曲线概念在本原则定义。思考顿悟类引用本概念(见 `design-principles-puzzle.md`)。

**反模式**:线性平缓(无聊)、骤增无过渡(挫败放弃)、全程高难(无爽感期)。

**设计要求**:
- 前 3 局必赢(建立"我能玩"信心)
- 第 4-10 局陡升(制造"差一点"挫败)
- 失败时玩家能感知"接近成功"
- 有降难途径(道具/分享续命)

**检查项**:
- [ ] 前 3 局保证成功
- [ ] 难度有陡升节点(非纯线性)
- [ ] 失败时玩家感知"接近成功"
- [ ] 有降难途径

---

### 原则 4:社交裂变驱动(排行榜+分享+挑战)

**原理**:小游戏的爆发依赖社交传播。排行榜/分享续命/挑战好友让玩家成为传播节点,社交压力+比较比游戏本身好玩更重要。

**反模式**:纯单机无排行榜、分享无奖励、无好友对比。

**设计要求**:
- 多维排行榜(好友圈/省份/全服)
- 分享有实质奖励(续命/复活/解锁/双倍)
- 支持挑战/组队
- 好友进度可见(社交压力)

**检查项**:
- [ ] ≥2 维排行榜
- [ ] 分享有实质奖励
- [ ] 支持挑战/组队
- [ ] 好友进度可见

---

### 原则 5:正反馈密集(多巴胺节奏)

**原理**:"爽"来自高频正反馈。每次操作都有反馈(音效/粒子/数字/震动),每达成小目标有大反馈,形成密集多巴胺释放。反馈密度 > 反馈强度。

**反模式**:操作无反馈、反馈延迟、反馈单调、无连击/combo。

**设计要求**:
- 每操作有反馈(音/视/震三选一,间隔 <100ms)
- combo/连击机制(连续达成反馈递增)
- 大目标爆点(满屏特效+音效)
- 数值飙升感(后期数字快速变大)

**检查项**:
- [ ] 每次操作有即时反馈
- [ ] 有 combo/连击机制
- [ ] 大目标达成有爆点反馈
- [ ] 数值有飙升感

---

### 原则 6:meta 进度承接(局间长线目标)

**原理**:单局短但要有"留住的锚"。meta 进度把单局收益转化为长线成长,让"再来一把"有目标感。单局是短反馈,meta 是长留存。

> **单一来源**:meta 进度的完整定义在此。混合休闲进阶模式(§三)在此基础上深化为"肝爽飞轮"。

**反模式**:单局独立无延续、无解锁、无收集、每局从头开始。

**设计要求**:
- 局间收益(金币/经验/材料 → meta 升级)
- 解锁系统(角色/关卡/皮肤/道具)
- 图鉴/收集(完成度驱动留存)
- meta 反哺局内(升级 → 单局能力提升)

**检查项**:
- [ ] 单局有可延续收益
- [ ] 有解锁系统
- [ ] 有收集要素
- [ ] meta 升级反哺单局能力

## 三、混合休闲模式(进阶):五条核心原则

> 当 §一 模式判定命中混合休闲信号时,在超休闲六原则基础上,额外遵循以下五条进阶原则。
> 混合休闲 = 超休闲层(§二六原则) + 中核层 + 融合层。三层架构有机融合。

### 三层架构

```
┌─────────────────────────────────┐
│ 中核层(meta)  ← 留存引擎        │  养成/收集/赛季/社交/副玩法
├─────────────────────────────────┤
│ 融合层(bridge) ← 短长衔接       │  局间收益/meta反哺/任务/碎片
├─────────────────────────────────┤
│ 超休闲层(core) ← 获客引擎(§二)  │  30秒hook/短反馈/难度曲线
└─────────────────────────────────┘
```

### 原则 7(进阶):核心循环30秒,meta系统30小时

**原理**:超休闲层负责"30秒上手+前几局爽",中核层负责"30小时不腻"。两者时长差 3600 倍,但都不可或缺。

**反模式**:核心循环复杂(>3分钟)获客失败;meta系统浅(<5小时)留存差;核心与meta脱节。

**设计要求**:
- 核心循环 ≤3 分钟(复用 §二 原则1-2)
- meta 系统提供 ≥30 小时长线目标(养成+收集+赛季)
- 核心→meta 收益转化路径清晰
- meta→核心反哺路径清晰

**检查项**:
- [ ] 核心循环 ≤3 分钟且 30 秒可上手
- [ ] meta 系统提供 ≥30 小时长线目标
- [ ] 核心→meta 收益转化路径清晰
- [ ] meta→核心反哺路径清晰

---

### 原则 8(进阶):meta 反哺形成"肝-爽-肝"飞轮

**原理**:单局收益 → meta升级 → 单局能力提升 → 单局收益更高 → meta升级更快。飞轮是混合休闲的留存核心:为"更爽的单局"而肝 meta,肝 meta 又让单局更爽。

> **单一来源**:肝爽飞轮概念在此定义。这是 §二原则6(meta进度)的进阶形态——从"单向承接"升级为"双向飞轮"。

**反模式**:meta升级不影响单局(无动力);meta碾压单局(失去挑战);单局收益与meta无关(脱节)。

**设计要求**:
- meta升级提供可感知的单局变化(伤害/移速/新技能)
- 升级幅度可控(强化但不碾压,保留挑战)
- 飞轮有节奏感(每N局可感知一次提升)
- 飞轮有天花板(满级后转赛季/重置,避免数值无限膨胀)

**检查项**:
- [ ] meta 升级对单局有可感知影响
- [ ] 升级幅度保留单局挑战(非碾压)
- [ ] 每 N 局有可感知的 meta 提升
- [ ] 满级后有赛季重置/转生机制

---

### 原则 9(进阶):受众分层,难度分层满足不同玩家

**原理**:混合休闲受众跨度大(泛用户到中度玩家),单一难度无法满足。用难度分层让各层玩家各得其所。

**反模式**:单一难度(泛用户卡关或硬核无聊);难度不可选;高难度奖励不足。

**设计要求**:
- ≥3 层难度:主线(休闲)/挑战(中核)/深渊(硬核)
- 难度可自选,不强制线性推进
- 高难度有差异化奖励(稀有皮肤/专属成就/赛季积分)
- 难度切换无惩罚(可随时降难度,不扣进度)

**检查项**:
- [ ] ≥3 层难度
- [ ] 难度可自选且可切换
- [ ] 高难度有差异化奖励
- [ ] 难度切换无惩罚

---

### 原则 10(进阶):副玩法增加多样性,但不喧宾夺主

**原理**:核心循环再爽,玩几十小时也会腻。副玩法提供节奏切换,但必须不喧宾夺主——是补充不是替代。

**反模式**:无副玩法(后期单调);副玩法比主循环重(定位模糊);副玩法与主循环无关(割裂);强制(逼玩家玩不喜欢的)。

**设计要求**:
- 副玩法可选(不强制,不影响主线)
- 副玩法反哺主循环(产出主循环所需资源)
- 副玩法轻量(单次 ≤5 分钟)
- 数量适中(2-4 个)

**检查项**:
- [ ] 有 2-4 个副玩法
- [ ] 副玩法可选,不强制
- [ ] 副玩法反哺主循环
- [ ] 副玩法单次 ≤5 分钟

---

### 原则 11(进阶):混合变现与体验平衡

**原理**:混合休闲用 IAA 变现泛用户,IAP 变现付费用户。关键在广告不伤体验,内购不破坏平衡。

> **单一来源**:完整商业化设计见 `design-principles-monetization.md`。本原则仅强调混合休闲场景下的体验平衡要点。

**设计要求**:
- 广告以激励视频为主(玩家主动看),插屏频次受限(≤每3分钟1次)
- 激励视频奖励有价值(复活/双倍/稀有道具)
- 内购卖省时间+外观,不卖纯数值变强
- 付费档位分层(6/30/68/128/328元)

**检查项**:
- [ ] 广告以激励视频为主,插屏频次受限
- [ ] 激励视频奖励有实质价值
- [ ] 内购不破坏平衡(非P2W)
- [ ] 付费档位分层覆盖中小R和大R

## 四、协同关系

### 超休闲模式闭环

```
原则1(30秒hook) ──让玩家进来──→  原则2(短反馈重试) ──让玩家留下──→  原则5(正反馈密集)
                                        ↓                                    ↑
                                        ↓                                    ↑
原则6(meta进度)  ←──长线留存──  原则3(难度曲线)  ←──制造重试动力──┘
                                        ↓
                                  原则4(社交裂变) ──带来更多玩家──→ 回到原则1
```

### 混合休闲模式闭环(进阶)

```
超休闲六原则(获客) + 原则7(30秒+30小时架构)
                          ↓
              原则8(肝爽飞轮) ──驱动留存──→ 原则9(受众分层)+原则10(副玩法)
                          ↓
              原则11(混合变现) ──变现且不伤体验──→ 反哺飞轮
```

### 缺环诊断

**超休闲模式**:
- 缺1 → 进来就流失;缺2 → 玩一把就走;缺3 → 无聊或挫败
- 缺4 → 无法爆发;缺5 → 不爽;缺6 → 留不住

**混合休闲模式**(在超休闲基础上):
- 缺7 → 无架构(超休闲+中核脱节);缺8 → 无飞轮(肝meta无动力)
- 缺9 → 流失受众;缺10 → 后期单调;缺11 → 无法变现

**第一性原理**:
> 超休闲:30秒hook × 短反馈重试 × 密集正反馈 × 难度心流 × 社交裂变 × meta长线,六者相乘缺一不可。
> 混合休闲:在超休闲基础上,用肝爽飞轮把30秒核心与30小时meta焊死,用难度分层和副玩法覆盖受众跨度,用混合变现赚钱且不伤体验。

## 五、生成蓝图时的应用流程

### Step 1:模式判定

按 §一 判定为超休闲模式还是混合休闲模式。

### Step 2:映射原则到机制

**超休闲模式**:
| 原则 | 对应机制 |
|---|---|
| 30秒hook | 零引导+首操作强反馈 |
| 短反馈重试 | 单局<3分钟+1秒重开 |
| 难度曲线 | 前3局易+陡升节点 |
| 社交裂变 | 排行榜+分享奖励 |
| 正反馈密集 | 每操作反馈+combo |
| meta进度 | 局间收益+解锁 |

**混合休闲模式**(在超休闲基础上追加):
| 进阶原则 | 对应机制 |
|---|---|
| 30秒+30小时 | 核心循环+meta系统分层 |
| 肝爽飞轮 | meta反哺单局能力 |
| 受众分层 | ≥3层难度 |
| 副玩法 | 2-4个可选副玩法 |
| 混合变现 | IAA+IAP(详见 monetization) |

### Step 3:质量自检

对照检查项,在"5. 核心机制清单"中确认机制齐备。缺失项标注到"9. 关键技术风险"。

## 六、市场案例对照

| 游戏 | 模式 | 超休闲层 | 中核层 | 融合层 |
|---|---|---|---|---|
| 合成大西瓜 | 超休闲 | 水果碰撞合成 | 无 | 无 |
| 羊了个羊 | 超休闲 | 消除+陡升难度 | 无 | 分享续命 |
| 螺丝拧拧 | 混合休闲 | 拧螺丝(点击) | 关卡/星级/皮肤 | 星级解锁新关卡 |
| 排序水杯 | 混合休闲 | 倒水排序 | 关卡/每日/赛季 | 每日任务给赛季积分 |
| 肉鸽割草 | 混合休闲 | 移动射击 | 永久升级/角色/技能 | 每局金币升级永久属性 |
| 放置挖矿 | 混合休闲 | 挖矿(点击) | 矿工升级/矿层/图鉴 | 离线收益/升级反哺 |
