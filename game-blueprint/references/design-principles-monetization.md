# 商业化设计原则

> **核心驱动**:变现与体验平衡,让玩家"愿意付"而非"被逼付"。
> **与其他原则的关系**:本原则是通用原则(第二层),跨品类适用。与 `economy` 原则5(F2P平衡)互补:本原则管变现层,economy 管数值层。
> **单一来源**:混合变现(IAA+IAP)的完整定义在本文件。`instant-feedback` 进阶原则11引用本文件。

---

## 一、适用判定

| 判定信号 | 说明 |
|---|---|
| 游戏为 F2P(免费游玩)模式 | 需要变现覆盖成本 |
| 含广告位设计(激励视频/插屏) | IAA 变现 |
| 含内购设计(道具/皮肤/通行证) | IAP 变现 |
| 有 meta 系统(养成/赛季) | 变现锚点 |

**命中任意一条 → 适用本原则**。几乎所有小游戏/手游都适用,纯买断制单机除外。

---

## 二、变现模式分类与选择

| 模式 | 全称 | 适合品类 | 优势 | 劣势 |
|---|---|---|---|---|
| **IAA** | 广告变现 | 超休闲/休闲 | 覆盖免费用户,eCPM 稳定 | 体验易伤,依赖量 |
| **IAP** | 内购变现 | 中重度/经营 | ARPU 高,忠诚度变现 | 免费用户不贡献,设计复杂 |
| **混合** | IAA+IAP | 混合休闲/中核 | 双轮驱动,覆盖全用户 | 平衡设计难度高 |

**选择决策**:
```
游戏类型
├─ 超休闲(单局<3分钟,泛用户) → IAA 为主
├─ 混合休闲(超休闲+中核meta) → IAA+IAP 混合(主流)
├─ 中重度(RPG/策略/MMO) → IAP 为主 + 少量激励视频
└─ 纯买断单机 → 一次付费,无 IAA/IAP
```

## 三、六条核心原则

### 原则 1:激励视频为主,插屏为辅,banner 慎用

**原理**:激励视频是"玩家主动选择看广告换奖励",体验友好且 eCPM 高;插屏是"强制弹出",体验伤但触达广;banner 持续占用屏幕,eCPM 低且伤体验。

**反模式**:强制插屏每30秒一次;激励视频奖励无价值;banner 占据操作区。

**设计要求**:
- **激励视频为主**(占广告收入 70%+):玩家主动触发,奖励有价值
- **插屏为辅**(控制频次):关卡切换/自然停顿,频率 ≤每3分钟1次
- **banner 慎用**:仅在不影响操作的边角,或不使用

**激励视频高价值场景**(转化率高):
| 场景 | 奖励 | 为什么有效 |
|---|---|---|
| 失败续命 | 复活/重试 | 玩家情绪高,不愿放弃当前局 |
| 双倍收益 | 单局金币×2 | 边际成本低,玩家感觉赚 |
| 免费开箱 | 稀有道具/碎片 | 制造惊喜,驱动收集 |
| 加速完成 | 跳过等待 | 即时满足,省时间 |
| 额外次数 | 每日挑战+1 | 突破限制,驱动回流 |

**检查项**:
- [ ] 激励视频为主(占 70%+)
- [ ] 插屏频次 ≤每3分钟1次
- [ ] banner 不遮挡操作区
- [ ] 激励视频奖励有实质价值

---

### 原则 2:广告频次与玩家情绪匹配

**原理**:广告频次应与玩家情绪曲线匹配——在"愿意付出代价换收益"的时刻插入,而非任意打断。失败时愿意看广告续命,沉浸时插屏会激怒。

**反模式**:沉浸操作中插屏;同一场景连环弹;玩家无法预知广告时机。

**设计要求**:
- 广告插入点选在**自然停顿**(关卡结束/结算页/大厅)
- 沉浸操作中**绝不插屏**(消除中/战斗中/瞄准中)
- 同一场景**最多1次插屏**(不连环弹)
- 玩家可**预知广告时机**(通关后会有广告,心理预期降低反感)

**频次红线**:
| 广告类型 | 频次上限 | 超过后果 |
|---|---|---|
| 插屏 | ≤每3分钟1次 | 流失率显著上升 |
| 激励视频 | 无上限(玩家主动) | 单场景最多提供2-3个激励位 |
| banner | 持续但不遮挡 | 误触率高则移除 |

**检查项**:
- [ ] 广告在自然停顿插入
- [ ] 沉默操作中无插屏
- [ ] 同场景最多1次插屏
- [ ] 广告时机可预知

---

### 原则 3:卖"省时间+外观+便利",不卖"变强"

**原理**:健康的内购卖**省时间**(跳过肝)、**外观**(皮肤/特效)、**便利**(额外次数/自动),不卖**纯数值变强**(P2W)。P2W 短期收入高,但破坏平衡,导致免费玩家流失,生态崩坏。

> **单一来源**:F2P 平衡的数值层细节见 `design-principles-economy.md` 原则5。本原则聚焦变现层的"卖什么"。

**健康内购类型**:
| 类型 | 例子 | 为什么健康 |
|---|---|---|
| 外观 | 皮肤/特效/称号 | 不影响平衡,自我表达 |
| 省时间 | 经验加成/资源包 | 跳过肝,但不超越 |
| 便利 | 额外次数/自动战斗 | 减少重复操作 |
| 通行证 | 赛季奖励阶梯 | 长线绑定,性价比 |
| 去广告 | 一次性付费去广告 | 提升体验,高频用户愿付 |

**P2W 反模式**:充值直接加攻击力;稀有角色只能抽卡且数值碾压;付费专属强力道具。

**检查项**:
- [ ] 内购以外观/省时间/便利为主
- [ ] 无纯数值变强(P2W)
- [ ] 稀有道具免费也可获得(更慢)
- [ ] 付费不解锁独占玩法

---

### 原则 4:付费档位分层,覆盖中小R和大R

**原理**:玩家付费能力跨度大(0元到万元),单一档位无法覆盖。用分层档位让各层级玩家各得其所。

**标准档位结构**:
| 档位 | 定价 | 内容 | 目标用户 |
|---|---|---|---|
| 首充 | 6元 | 高价值首充礼包(永久) | 转化首次付费 |
| 月卡 | 30元 | 每日登录领资源(30天) | 培养登录习惯 |
| 礼包 | 68元 | 资源+道具组合 | 中R日常 |
| 通行证 | 128元 | 赛季奖励阶梯 | 长线绑定 |
| 大礼包 | 328元 | 稀有+大量资源 | 大R/鲸鱼 |

**设计要求**:
- **首充门槛低**(6元),首充奖励**超值**(转化首次付费心理)
- **月卡性价比高**(每日返利,30天总价值 > 礼包)
- **通行证有免费线+付费线**(免费线给基础,付费线给高级)
- **大礼包限时限量**(制造稀缺,刺激冲动)

**检查项**:
- [ ] 有6元首充档(超值)
- [ ] 有30元月卡(每日返利)
- [ ] 通行证有免费线+付费线
- [ ] 大礼包限时限量

---

### 原则 5:IAA 与 IAP 不互斥,分用户层

**原理**:IAA 变现免费用户,IAP 变现付费用户,两者不互斥。关键在**分用户层设计**:免费用户看广告换资源,付费用户花钱跳过广告买资源,各取所需。

**反模式**:广告强制(付费也无法去);付费解锁独占玩法(免费体验残缺);两条路径有一条卡死。

**设计要求**:
- 免费用户路径:看激励视频 → 获得资源 → 正常推进
- 付费用户路径:花钱买资源 / 去广告 → 更顺畅推进
- 两条路径**都能通关**(不付费不卡死)
- 付费优势是**效率/外观**,而非**能力门槛**

**平衡检查**:
| 检查项 | 标准 |
|---|---|
| 不付费能否通关主线 | ✓ 能 |
| 不付费能否体验所有玩法 | ✓ 能(更慢) |
| 付费是否解锁独占玩法 | ✗ 否(只解锁效率/外观) |
| 广告是否强制 | ✗ 否(激励视频为主) |

**检查项**:
- [ ] 免费用户能通关主线
- [ ] 免费用户能体验所有玩法(更慢)
- [ ] 付费不解锁独占玩法
- [ ] 广告非强制(激励视频为主)

---

### 原则 6:变现锚点与核心循环共生

**原理**:变现点位应**长在核心循环上**,而非外挂。玩家在自然游玩中触达变现点,而非被强行打断。变现是循环的一部分,不是循环外的负担。

**反模式**:变现点在核心循环外(强行弹商城);资源只能付费获得(无免费路径);广告与核心循环无关(看广告得无关奖励)。

**共生设计**:
```
核心循环(消除/跑酷/战斗)
  ↓
自然产出资源(金币/经验)
  ↓
资源不够时:
  ├─ 免费路径:看激励视频 ×2 资源
  ├─ 付费路径:买资源包
  └─ 肝路径:再玩N局攒
```

**检查项**:
- [ ] 变现锚点在核心循环上(非外挂)
- [ ] 资源有免费路径(看广告/肝)
- [ ] 广告奖励与核心循环相关
- [ ] 付费是效率提升(非能力门槛)

## 四、协同关系

```
原则1(激励视频为主) ──→ 原则2(频次匹配情绪) ──→ IAA层
                                                    ↓
原则6(锚点共生) ←── 原则5(IAA与IAP分层) ←── 融合
        ↑
        │
原则3(不卖变强) ──→ 原则4(档位分层) ──→ IAP层
```

- **IAA层(原则1+2)**:广告变现,体验友好
- **IAP层(原则3+4)**:内购变现,平衡不破
- **融合层(原则5+6)**:两套变现共生,分用户层,锚点长在循环上

**第一性原理**:
> 好的商业化是"玩家愿意付"而非"被逼付"。激励视频让免费用户用时间换收益,内购让付费用户用钱换效率/外观,两者都长在核心循环上,各取所需,生态健康。

## 五、生成蓝图时的应用流程

### Step 1:确定变现模式

按 §二 决策树选择 IAA/IAP/混合。

### Step 2:设计变现锚点

| 变现类型 | 锚点位置 | 奖励/内容 |
|---|---|---|
| 激励视频 | 失败续命/双倍/开箱/加速 | 按 §三 原则1高价值场景 |
| 插屏 | 关卡切换/结算 | 频次 ≤每3分钟1次 |
| 首充 | 大厅首充入口 | 6元超值礼包 |
| 月卡 | 商城 | 30元每日返利 |
| 通行证 | 赛季入口 | 128元阶梯奖励 |
| 礼包 | 商城/限时弹窗 | 68元/328元 |

### Step 3:平衡检查

对照 §三 原则5 的平衡检查表,验证免费用户能通关、付费不独占玩法。

### Step 4:质量自检

- [ ] 变现模式与游戏类型匹配
- [ ] 激励视频为主,插屏频次受限
- [ ] 激励视频奖励有价值
- [ ] 内购不卖纯数值变强
- [ ] 付费档位分层(6/30/68/128/328)
- [ ] 变现锚点长在核心循环上
- [ ] 不付费能通关,付费买效率/外观
