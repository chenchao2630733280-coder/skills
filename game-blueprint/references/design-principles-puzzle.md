# 思考顿悟类 设计原则

> **核心驱动**:Eureka Moment(啊哈时刻),玩家通过思考得出答案时的高度多巴胺释放。
> **与其他原则的关系**:本原则是品类原则(第一层),指导核心循环设计。难度曲线概念引用自 `instant-feedback` 原则3。
> **第一性原理**:解谜游戏是制造 Eureka Moment 的机器,每关都是一次"啊哈"。

---

## 一、适用判定

| 判定信号 | 说明 |
|---|---|
| 核心玩法是"思考得出答案" | 非反应/操作,而是逻辑/观察/推理 |
| 有明确的"谜题-答案"结构 | 每个关卡有唯一或有限解 |
| 答题正确有 Eureka 感 | 思考后的顿悟,而非试错 |
| 错误有反馈但无惩罚(或轻惩罚) | 鼓励尝试,非惩罚试错 |

**命中 ≥3 条 → 适用本原则**。

**典型题材**:空间解谜(纪念碑谷)、逻辑推理(数独/狼羊菜)、物理解谜(割绳子)、文字解谜(脑筋急转弯)、观察解谜(找茬/隐藏对象)。
**典型不适用**:消除(靠反应/策略非推理)、答题(考记忆而非逻辑推理)。

---

## 二、六条核心原则

### 原则 1:Eureka Moment 是核心爽点

**原理**:解谜的"爽"来自思考后得出答案的顿悟瞬间。心理学上,这会高度分泌多巴胺、提升记忆力、产生正向情绪。好的解谜游戏是"制造 Eureka 的机器"。

**反模式**:答案靠试错(暴力尝试);答案太明显(无需思考);答案太晦涩(无法推理);解谜后无反馈(浪费 Eureka 时机)。

**设计要求**:
- 每个谜题有**可推理的逻辑链**(玩家能"想出来",而非"试出来")
- 答案揭示时有**强反馈**(音效/动画/特效,放大 Eureka 感)
- 难度匹配"思考时间"(太短无顿悟,太长放弃)
- **避免纯知识题**(考记忆而非逻辑,无 Eureka)

**检查项**:
- [ ] 每个谜题有可推理逻辑链(非试错)
- [ ] 答案揭示有强反馈
- [ ] 难度匹配思考时间(不长不短)
- [ ] 无纯知识题(或知识题占比 <20%)

**正面案例**:纪念碑谷——通过视觉错觉推理路径,调整视角的瞬间是 Eureka。
**反面案例**:找隐藏对象——纯靠眼力扫描,无逻辑推理,无 Eureka。

---

### 原则 2:难度阶梯,每关只教一个新概念

**原理**:好的解谜是"渐进教学"——每关只引入一个新概念/机制,后续关卡组合已学概念。玩家在不知不觉中学会了复杂推理。

> **概念引用**:难度曲线的通用原理见 `design-principles-instant-feedback.md` 原则3(心流难度曲线)。解谜类的难度曲线是"阶梯式"(每关一概念),区别于即时反馈类的"缓升→陡升"。

**反模式**:一关引入多个新概念;难度跳跃;无教学关;重复同一难度无递进。

**设计要求**:
- **每关只教一个新概念**(或一个新组合)
- 前 N 关是"教学关"(简单到让玩家学会机制)
- 难度**阶梯递进**(非跳跃,非平缓)
- 后期关卡**组合早期概念**(1+1=2,非引入更多新概念)

**难度阶梯示例**:
```
关1:教"移动"(只移动)
关2:教"开关"(只按开关)
关3:组合"移动+开关"(先移动到开关,再按)
关4:教"计时"(在时间内完成)
关5:组合"移动+开关+计时"
关6:教"反向"(开关关而非开)
```

**检查项**:
- [ ] 每关只引入一个新概念
- [ ] 有教学关(前 N 关简单)
- [ ] 难度阶梯递进(非跳跃)
- [ ] 后期组合早期概念(非堆砌新概念)

---

### 原则 3:线索机制,卡关时有出路

**原理**:解谜最怕"卡死"。好的解谜提供**分级线索系统**,玩家可自主求助,而非卡死放弃或查攻略。

**反模式**:无线索系统;线索直接给答案(失去 Eureka);线索无层级;求助有重惩罚。

**设计要求**:
- **分级线索**(3级):
  - L1 提示方向(如"注意颜色")
  - L2 提示方法(如"颜色对应数字")
  - L3 接近答案(如"红=1,蓝=2,那绿=?")
- 线索**不直接给答案**(保留 Eureka 机会)
- 求助**轻惩罚或无惩罚**(如扣星级,不锁关)
- 可**跳过当前关**(累积跳过券或看广告)

**检查项**:
- [ ] 有 ≥3 级线索系统
- [ ] 线索不直接给答案
- [ ] 求助轻惩罚或无惩罚
- [ ] 可跳过(券/广告)

---

### 原则 4:多重解法,鼓励创造性

**原理**:单一解法是"找到唯一答案",多重解法是"找到你的答案"。多重解法鼓励创造性思考,让玩家有"我的解法"的归属感,提升重玩价值。

**反模式**:强制唯一解法;解法过于开放(任何答案都行);多重解法无差异反馈。

**设计要求**:
- 部分谜题支持**多重解法**(2-3 种合理解法)
- 不同解法有**差异化反馈**(如"最优解"3星,"普通解"1星)
- 有**奖励创造性**的机制(成就/隐藏关/特殊皮肤)
- 多重解法**可选**(非所有谜题都要多重,部分即可)

**检查项**:
- [ ] 部分谜题支持多重解法
- [ ] 不同解法有差异化反馈(星级)
- [ ] 有创造性奖励机制
- [ ] 多重解法是可选设计(非强制全部)

---

### 原则 5:机制深度,少规则多组合

**原理**:好的解谜用**少量基础规则**通过**组合**产生大量谜题。规则少则易学,组合多则耐玩。

**反模式**:规则过多(10+ 种机制)学习成本高;规则间无组合;每关都需要新规则(变题库)。

**设计要求**:
- **基础规则 ≤5 种**(易学)
- 规则间**可组合**(A+B, A+C, A+B+C 产生新谜题)
- 通过组合产生** ≥50 关**(规则少但耐玩)
- 后期复杂度来自**组合深度**,非规则数量

**机制深度示例**:
```
基础规则(3种):移动、开关、传送
组合产生的谜题:
- 移动+开关:走到开关按
- 移动+传送:通过传送到达
- 开关+传送:开关控制传送门
- 移动+开关+传送:复杂路径
→ 3规则产生几十关
```

**检查项**:
- [ ] 基础规则 ≤5 种
- [ ] 规则间可组合
- [ ] 组合产生 ≥50 关
- [ ] 复杂度来自组合深度

---

### 原则 6:元谜题,跨关卡的大设计

**原理**:超越单关的"元谜题"让解谜有长线深度——某关线索指向另一关,或多关答案组合成更大谜题。这制造跨关 Eureka,提升长线留存。

**反模式**:关卡完全独立(无关联);元谜题过于隐晦(发现不了);元谜题强制(必须解才能通关)。

**设计要求**:
- 有**可选的元谜题**(跨关线索/隐藏关)
- 元谜题是**加分项**(非强制,不影响主线通关)
- 元谜题的 Eureka **大于单关**(跨关顿悟更爽)
- 有**暗示引导**(让玩家有机会发现,非纯隐藏)

**检查项**:
- [ ] 有可选的元谜题(跨关/隐藏)
- [ ] 元谜题非强制
- [ ] 元谜题 Eureka 大于单关
- [ ] 有暗示引导(可发现)

## 三、协同关系

```
原则1(Eureka核心) ──定义爽点──→  原则2(难度阶梯) ──控制节奏──→
        ↓                                                    ↓
        ↓                                                    ↓
原则5(机制深度)  ←──少规则多组合──  原则4(多重解法)  ←──鼓励创造──  原则3(线索系统)
        ↓
        ↓
原则6(元谜题) ──长线深度──→ 跨关 Eureka
```

- **原则1** 是核心:Eureka 是解谜的灵魂
- **原则2** 是节奏:每关一概念,阶梯递进
- **原则3** 是兜底:卡关有出路
- **原则4** 是创造:多重解法鼓励表达
- **原则5** 是深度:少规则多组合
- **原则6** 是长线:元谜题跨关顿悟

**缺环诊断**:缺1无爽点、缺2无节奏、缺3卡死流失、缺4无创造、缺5无深度、缺6无长线。

## 四、生成蓝图时的应用流程

### Step 1:确定谜题类型

| 类型 | 核心机制 | 示例 |
|---|---|---|
| 空间解谜 | 视角/路径/几何 | 纪念碑谷 |
| 逻辑推理 | 规则推导 | 数独/狼羊菜 |
| 物理解谜 | 物理/时机 | 割绳子 |
| 观察解谜 | 细节观察 | 找茬/密室 |
| 文字解谜 | 文字游戏 | 脑筋急转弯 |

### Step 2:设计基础规则

列出 ≤5 种基础规则,验证可组合性。

### Step 3:规划关卡序列

```
教学关(1-5):每关教1个规则
组合关(6-20):2规则组合
进阶关(21-50):3+规则组合
元谜题(隐藏):跨关线索
```

### Step 4:设计线索系统

3级线索(L1方向/L2方法/L3接近答案),求助轻惩罚,可跳过。

### Step 5:质量自检

对照六原则检查项,确认机制齐备。
