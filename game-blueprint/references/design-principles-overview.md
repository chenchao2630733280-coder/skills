# 设计原则总览

> 本文件是 game-blueprint 所有设计原则的**总入口**。生成蓝图前先读取本文件,按决策树确定品类,再按叠加规则读取对应原则文件。
> 本文件不包含具体设计原则,只负责**分类、路由、叠加规则**。

---

## 一、两层分类体系

game-blueprint 的设计原则分两层:

```
┌─────────────────────────────────────────────────┐
│ 第一层:品类原则(指导核心循环设计)               │
│ 按核心驱动分类,互斥(一个游戏只属一个主品类)     │
├─────────────────────────────────────────────────┤
│ ① 即时反馈类  │ ② 价值揭示类                     │
│ ③ 思考顿悟类  │                                  │
├─────────────────────────────────────────────────┤
│ 第二层:通用原则(指导系统设计,跨品类)           │
│ 可与任意品类叠加                                │
├─────────────────────────────────────────────────┤
│ ④ 商业化设计  │ ⑤ 数值与经济                     │
└─────────────────────────────────────────────────┘
```

**品类原则**(第一层,互斥):指导"核心玩法循环"和"核心机制清单"设计。
**通用原则**(第二层,叠加):指导变现、数值等系统级设计,与品类无关。

---

## 二、品类决策树

按核心驱动选择**唯一主品类**:

```
用户需求
│
├─ 是"把已有题材/IP/热点/真实数据改成游戏"?(已有题材,非从0脑暴)
│  ├─ 是 → 先走 叙事化改编原则(见 design-principles-narrative-adaptation.md)
│  │        做"题材→机制"转化后,再回到本决策树定主品类
│  │
├─ 核心驱动是"即时爽感+高频反馈"?
│  ├─ 是 → ① 即时反馈类
│  │        (超休闲/小游戏/H5/碎片化/混合休闲)
│  │        读取 design-principles-instant-feedback.md
│  │
├─ 核心驱动是"价值发现+造物"?
│  ├─ 是 → ② 价值揭示类
│  │        (赌石/开箱/鉴定/考古/二手交易)
│  │        读取 design-principles-value-reveal.md
│  │
├─ 核心驱动是"思考顿悟"?
│  ├─ 是 → ③ 思考顿悟类
│  │        (解谜/逻辑推理/空间解谜)
│  │        读取 design-principles-puzzle.md
│  │
└─ 都不是 → 按常规玩法设计(无对应品类原则)
```

### 品类判定信号

| 品类 | 核心驱动 | 判定信号(命中≥2-3条) |
|---|---|---|
| ① 即时反馈类 | 即时爽感+高频反馈 | 单局<5分钟、操作极简(1-2手势)、泛用户、社交裂变、短反馈重试 |
| ② 价值揭示类 | 价值发现+造物 | 买入未知价值物、隐藏价值需揭示、揭示影响定价、可中途退出 |
| ③ 思考顿悟类 | Eureka Moment | 思考得出答案、谜题-答案结构、顿悟非试错、错误无惩罚 |

### 进阶模式

即时反馈类有**进阶模式**:
- **超休闲模式**:纯短反馈,无深度 meta(原"爆款小游戏")
- **混合休闲模式**:超休闲核心+中核 meta+混合变现(原"混合休闲")

判定为即时反馈类后,在文件内进一步判定走超休闲还是混合休闲模式。

## 三、通用原则(跨品类叠加)

无论何种品类,只要涉及以下系统,额外读取对应通用原则:

| 通用原则 | 触发条件 | 文件 |
|---|---|---|
| ④ 商业化设计 | 涉及 F2P/IAA/IAP/通行证/赛季 任意一项 | `design-principles-monetization.md` |
| ⑤ 数值与经济 | 涉及属性/资源/货币/成长曲线 任意一项 | `design-principles-economy.md` |

**通用原则与品类原则不冲突**:品类原则指导核心循环,通用原则指导系统设计,各管各的维度。

## 四、叠加规则

### 4.1 品类+通用(常见)

```
品类原则(指导核心循环)
  + 通用原则(指导变现/数值)
```

例:即时反馈类 + 商业化 + 数值经济
→ 读取 instant-feedback + monetization + economy

### 4.2 品类内进阶

```
即时反馈类(超休闲模式 → 混合休闲模式)
```

判定为即时反馈类后,若命中混合休闲信号(有深度meta/混合变现/受众分层),在文件内切换到混合休闲模式,读取进阶章节。

### 4.3 跨品类组合(少见但允许)

极少数游戏可能跨品类(如"解谜+价值揭示"),此时:
- 选**核心驱动更强**的品类为主
- 另一品类的原则作为**辅助参考**
- 在 overview 的"关键技术风险"中标注跨品类

### 4.4 叠加优先级

当多套原则同时适用时:
1. **品类原则**优先指导"4. 核心玩法循环"和"5. 核心机制清单"
2. **通用原则**指导"7. 商业化与外部依赖"和数值设计
3. **进阶模式**在品类原则内部处理,不跨文件

## 七、单一来源规则

为避免跨文件重复,以下概念**只在唯一文件定义**,其他文件引用:

| 概念 | 定义位置 | 其他文件引用方式 |
|---|---|---|
| meta 进度/肝爽飞轮 | instant-feedback §进阶 | "详见 instant-feedback 进阶模式" |
| 难度曲线(心流) | instant-feedback 原则3 | "详见 instant-feedback 原则3" |
| 混合变现(IAA+IAP) | monetization 全文 | "详见 monetization" |
| F2P 平衡 | economy 原则5 + monetization 原则3 | economy 管数值层,monetization 管变现层 |
| 产出消耗闭环 | economy 原则3 | "详见 economy 原则3" |
| 大众记忆点 / memoryStrength | narrative-adaptation 原则3 | "详见 narrative-adaptation 原则3" |
| 不可逆操作+付费阀门 | narrative-adaptation 原则5 | "详见 narrative-adaptation 原则5" |
| 广告双价值(信息/对冲) | narrative-adaptation 原则6(补充) | 完整 IAA 见 monetization |

**规则**:任何概念需要跨文件使用时,在**定义文件**写完整,在**引用文件**用一句话摘要+"详见 xxx"指向定义文件,不重复完整内容。
