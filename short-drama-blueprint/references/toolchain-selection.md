# 工具链选型表与决策依据

本文件是 short-drama-blueprint 的懒加载细则，填写"8. 工具链选型"前必读。规则源头：short-drama-forge-master §3.2。

## 一、工具链选型表

| 环节 | 默认推荐 | 备选 | 决策依据 |
|---|---|---|---|
| 文生图（角色/场景/道具） | 即梦/可画 | Midjourney、SD(ComfyUI)、Flux | 角色一致性要求高→即梦/SD 控图；出图快→即梦 |
| 图生视频 | 可灵(Kling) | 即梦、Runway、Pika、海螺(MiniMax)、Sora | 画质优先→Sora/Runway；中文生态+低成本→可灵/即梦；时长 5-10s/镜头 |
| 数字人/口播 | 即梦数字人、HeyGen | D-ID、剪映数字人 | 有口播台本且需要真人形象时 |
| TTS 配音 | 火山引擎、Edge TTS | 阿里 CosyVoice、微软 Azure、MiniMax 语音 | 情感戏多→火山/CosyVoice 情感音色；低成本→Edge TTS |
| 音乐/BGM | Suno | Udio、网易天音、平台曲库 | 需要原创 OST→Suno；版权曲库→平台曲库 |
| 音效 | 平台素材库 | AI 音效生成 | 可选 |
| 字幕 | 剪映/AutoSub 类 | 自研 ffmpeg 烧录 | 见 short-drama-edit |
| 剪辑合成 | FFmpeg（脚本化） | 剪映（人工）、Premiere（人工） | 流水线自动合成→FFmpeg 脚本；人工精剪→剪映 |

## 二、选型决策流程

1. 读取制作类型（蓝图"5"），确定需要的环节（见 production-type-decision.md §六）
2. 按"**预算 / 质量要求 / 风格 / 宿主能力**"四因素从选型表选默认推荐：
   - 预算低 → 即梦/可灵/Edge TTS/FFmpeg 组合
   - 质量要求高 → Sora/Runway/CosyVoice/Suno
   - 风格特殊（古风/国风）→ 对应风格工具与音色
   - 宿主能力：优先可脚本调用/可批量的工具（FFmpeg > 剪映人工）
3. 每环节标注备选（备选用于 degrade 切换）
4. 写入蓝图"8. 工具链选型"，格式：

```
制作类型:全 AI 生成
文生图:即梦
图生视频:可灵(Kling)
TTS:火山引擎
音乐:Suno
剪辑:FFmpeg 脚本化
理由:[一句话]
```

## 三、备选切换规则（degrade）

| 场景 | 切换动作 | 标注 |
|---|---|---|
| 图生视频接口不可用 | 切换备选（如可灵→即梦）；全部不可用 → 整剧降级图文短剧模式 | ASSET_ISSUES.md / 蓝图标注 |
| 文生图不可用 | 纯色 + 文字占位图，标注"待人工出图" | 蓝图标注 |
| TTS 不可用 | 切换备选 TTS；仍失败 → 静音占位 + 字幕保留 | 蓝图标注 |
| 音乐不可用 | 平台免费曲库 BGM 占位 | 蓝图标注 |
| 字幕烧录失败 | 输出独立 .srt，标注"未烧录，发布前需人工烧录" | 蓝图标注 |

## 四、宿主能力约束

- 流水线默认**不依赖可视化编辑器**，视频/音频由工具链脚本化生成（总纲 §九）
- 工具以可脚本调用/可批量执行为首选（FFmpeg > 剪映人工）
- 需要人工介入的工具（剪映精剪/Premiere）在蓝图中标注"人工环节"
- 工具可用性变更（接口下线/涨价）时按 §三 切换，并把变更写入 `docs/ASSET_ISSUES.md`
