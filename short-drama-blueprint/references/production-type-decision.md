# 制作类型判定细则

本文件是 short-drama-blueprint 的懒加载细则，填写"5. 制作类型"前必读。规则源头：short-drama-forge-master §3.1。

## 一、四种制作类型

| 类型 | 定义 | 特征信号 | 代表形态 |
|---|---|---|---|
| 真人实拍辅助 | 真人演员/实拍素材为主，AI 辅助剧本/分镜/剪辑 | 用户有实拍素材/演员/拍摄预算 | 实拍短剧 + AI 后期 |
| AI 数字人 | 数字人形象 + 口播/半身镜头 | 有口播台本、需真人形象但无演员 | 口播短剧、知识/带货类 |
| 全 AI 生成 | 文生图 + 图生视频生成完整剧情画面 | 需要完整剧情画面但无实拍 | 剧情短剧主流形态 |
| 图文短剧 | 图 + 卡点 + 字幕 + BGM | 低成本/快速验证 | 图文动态短剧 |

## 二、判定流程（自上而下）

```
用户需求
   ├─ 有真人演员/实拍素材 → 真人实拍辅助型
   ├─ 有真实人物肖像素材（短剧换脸/数字分身/口播台本）→ AI 数字人型
   ├─ 需要完整剧情画面但无实拍 → 全 AI 生成型
   ├─ 低成本/快速验证（选题未验证/预算有限）→ 图文短剧型
   └─ 用户明确指定类型 → 尊重用户选择（仍需按 §三 检查可行性）
```

## 三、可行性检查（判定后必做）

| 类型 | 检查项 | 不满足时的处理 |
|---|---|---|
| 全 AI 生成 | 文生图/图生视频工具可用（见 toolchain-selection.md） | 工具不可用 → 降级图文短剧 |
| AI 数字人 | TTS 与数字人工具可用；有口播台本 | 无数字人形象素材 → 降级口播图文 |
| 真人实拍辅助 | 用户能提供拍摄能力/素材 | 否则 → 改为全 AI 生成 |
| 图文短剧 | 无需视频生成，工具链要求最低 | 一般无不可行风险 |

## 四、降级规则（写进蓝图并标注）

| 场景 | 降级方案 | 标注 |
|---|---|---|
| 制作类型不可行（如用户选真人实拍但无实拍素材） | 降级为图文短剧或全 AI 生成方案 | 蓝图"5. 制作类型"注明"降级自：{原类型}，原因：{...}" |
| 用户坚持原类型但工具/素材不满足 | 保留原类型 + 标注"高风险，需人工准备素材/预算" | 风险写入"9. 复杂度评估"与"10. 阶段裁剪建议" |

## 五、类型对裁剪的影响（读总纲 §四）

| 类型 | 裁剪 |
|---|---|
| 口播/数字人 | 跳过 storyboard/video-forge，script→audio→edit |
| 图文短剧 | 跳过 video-forge，storyboard 只出图 prompt |
| 全 AI 生成 | 全流程 |
| 真人实拍辅助 | script/storyboard/edit 必走，其余裁剪 |

## 六、类型对工具链环节的影响

| 类型 | 需要的工具链环节 |
|---|---|
| 全 AI 生成 | 文生图 + 图生视频 + TTS + 音乐 + 剪辑 |
| 图文短剧 | 文生图 + TTS + 音乐 + 剪辑（无图生视频） |
| AI 数字人 | 数字人 + TTS + 音乐 + 剪辑 |
| 真人实拍辅助 | 剪辑 + 可选 TTS/音乐 |
