# 资产定妆技术规范与派生配方

> 本文件对应 short-drama-asset-forge SKILL.md §四，生成定妆图/变体/音色/风格卡前读取。

---

## 1. 定妆图技术规范（不达标不允许 lock）

| 维度 | 要求 | 检查方式 |
|---|---|---|
| 人物数量 | 恰好 1 人，无镜像/倒影人脸 | 目检 |
| 取景 | 正面或 3/4 侧脸，半身以上（含肩） | 目检 |
| 背景 | 纯色或浅景深极简背景 | 目检 + 边缘区域对比度采样 |
| 文字水印 | 无 | 目检（含水印/署名/UI 边框） |
| 分辨率 | 短边 ≥1024px | `identify` / PIL 读取 |
| 格式 | png | 文件头 |
| 面部可见度 | 五官清晰可辨，无遮挡（面具类设定须保留可辨特征） | 目检 |
| 色彩 | 与风格基线的 colorTendency 一致 | 目检 + 主色采样 |

**不合格常见原因**：模型自动加了画框/文字；多人同框；全身远景（脸太小，作 reference 时会被忽略）；背景复杂导致后续融合时环境跟着漂移。

---

## 2. 定妆图 prompt 配方（六要素 + 角色三件套）

```
{景别:半身/肖像} {画幅:9:16 或 1:1}, {角色名}
 (reference:{refImage}, seed:{seed}, {styleKeywords 逐项}),
 {外貌/服装/发型描述：来自 VISUAL_SPEC 角色卡},
 {极简背景描述}, {光线描述：取 lightMoodMap 的"基准"值}, 无文字, 无水印
负面词: {styleBaseline.negativeKeywords 逐项}
```

**变体派生**（非 default 变体）：把 `reference` 指向 `assets/char/{charId}/default.png`，并在外貌描述中只改**变化的那一项**（服装/发型/年龄感），其它描述逐字保持不变 —— 描述漂移是变体"不像同一个人"的主因。

---

## 3. 变体派生配方

| variantId | 改什么 | 不能改 |
|---|---|---|
| `student` / `young` | 年龄感、发型、服装（校服/学生装） | 脸型骨架、五官比例、瞳色 |
| `elder` | 年龄感（皱纹/白发）、体态 | 五官识别特征 |
| `disguise` / `uniform` | 服装、发型、配件 | 脸型、身高比例 |
| `injured` / `haggard` | 妆容（伤妆/苍白/凌乱）、服装完整度 | 脸型、五官 |
| `reveal` | 气质反转（发型全部放下/换正装/眼神变化）、服装 | 脸型骨架 |

**seed 分配**：`default` 用一个基准 seed（如 20241），变体依次用**相邻但互异**的整数（20242/20243…），便于人工排查；**严禁复用 default 的 seed**。

## 4. 音色映射细则（角色 → voiceId）

| VISUAL_SPEC 气质 | 音色方向 | 示例 TTS 音色 |
|---|---|---|
| 阳光少年/青年男 | 明亮青年男声 | Edge `zh-CN-YunxiNeural` / 火山青年音色 |
| 沉稳中年男 | 低沉中年男声 | Edge `zh-CN-YunyeNeural` |
| 甜美少女 | 甜美元气女声 | Edge `zh-CN-XiaoyiNeural` |
| 成熟御姐 | 低沉磁性女声（略降调） | Edge `zh-CN-XiaoxiaoNeural` + pitch 下调 |
| 沧桑老年 | 沙哑慢速 | 平台老年音色 |
| 阴险反派 | 压低 + 气声 + EQ | 火山/CosyVoice 情感音色 + 后期压低 |
| 旁白/画外音 | 中性磁性解说音（语速略慢） | 男/女解说音色 |

**试音句选取**：从该角色**首集**的台词中挑 2-3 句（覆盖基准情感 + 一种极端情感），若无则用模板句：「我不能就这样算了。」「你到底还瞒着我什么？」「对不起……我来晚了。」

**基准语速**：`speechRate` 取 1.0 为准；角色的情感语速偏移（愤怒 1.15x / 悲伤 0.85x）留给阶段 6 按 `emotionTags` 处理，**写进本资产的是基准值**，不在本资产内逐句调速。

---

## 5. 风格基线 token 规则

1. `keywords` 与 `negativeKeywords` 必须**逐项数组化**，不许写成一句话（阶段 5 需要逐项拼接与校验）
2. 全剧唯一：禁止出现 `style_main` / `style_flashback` 多套基线；回忆线等特殊段落的差异通过**镜头级情绪/光线描述**实现，不动基线
3. `lightMoodMap` 的 key 必须覆盖 STORYBOARD「情绪」列出现的全部取值；缺失的情绪由阶段 4 补齐（Gate 3.5 按覆盖率检查）
4. 基线变更 = 全剧重生成，属最高风险变更，必须走 §五 影响面流程并明确告知用户后果

## 6. 常见失败与修法（速查）

| 现象 | 根因 | 修法 |
|---|---|---|
| 定妆图带文字/画框 | 模型默认加了海报框 | prompt 加「无文字, 无水印, 无边框」+ negativeKeywords 加「文字/水印/边框」，重出 |
| 变体与 default 不像同一人 | 描述整体重写导致漂移 | 以 default 为 reference，只改 1-2 项描述，其余逐字复制 |
| 两个变体像同一个人 | seed 复用 | 强制重分配互异 seed |
| 场景图里有人脸 | 场景 prompt 描述了人物 | 场景图一律「无人/远景剪影」，人物只在镜头 prompt 里加 |
| reference 图效果不明显 | 定妆图是全身远景 | 重出半身像；reference 的权重吃面部与服装轮廓 |
| 音色与角色气质不符 | 直接从工具默认列表挑音 | 回到 VISUAL_SPEC 的年龄/性别/气质推导，按 §4 表选 |
