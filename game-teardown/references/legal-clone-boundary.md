# 复刻的合规边界（红线清单 + 合法替代手法）

> **本文件不是法律意见。** 它只是给 AI 拆解阶段一套"别踩雷"的作业纪律。商业发布前必须做专业法律咨询；不同司法辖区（中国大陆 / 美国 / 欧盟 / 日本）判定标准不同。

---

## 一、判断基线：思想 / 表达二分

多数法域的共同基线：

- **思想、方法、规则、玩法机制** → 通常不受版权保护（可学、可复刻）
- **具体表达**（代码、美术、音乐、文本、具体界面视觉、具体关卡排布） → 受保护（不可搬）
- **标识性元素**（名称、Logo、角色名、术语） → 商标/不正当竞争风险（不可蹭）

推论：**能抄"怎么玩"，不能抄"长什么样、写了什么、叫什么"。**

---

## 二、三档清单

### ✅ 可学（可直接复刻，标 M）

- 核心循环结构（输入→反馈→奖励→成长→挑战）
- 规则逻辑：结算顺序、胜负条件、行动点、回合/实时节奏
- 系统框架：属性维度、技能分类、科技树层级、任务类型
- 数值**结构**：公式族、曲线形状、概率量级、经济闭环形态
- 操作方式与输入映射（点击/拖拽/摇杆/键位分区）
- 品类惯例（三消的交换规则、塔防的路径与波次、肉鸽的房间结构）
- **信息层级**（先看什么、后看什么、什么时候给反馈）
- 节奏参数：单局时长、反馈密度、难度峰值位置

### ⚠️ 需改写（学目标，不学具体解，标 S）

| 元素 | 可以学 | 必须重做 |
|---|---|---|
| UI 界面 | 信息优先级、分区逻辑、层级数量 | 具体排版、图标、配色、字体、动效 |
| 关卡 | 节奏曲线（压力/喘息交替）、机制引入顺序 | 地图布局、具体地形、机关位置 |
| 教程 | 教学顺序、隐性教学 vs 弹窗 | 文案、图示、镜头、步骤细节 |
| 叙事 | 结构（线性/碎片/环境叙事）、信息释放节奏 | 剧情文本、角色设定、世界观专名 |
| 美术 | 风格坐标系（色相/明度/线宽/比例/镜头） | 具体角色设计、场景、UI 视觉稿、素材 |
| 音频 | 触发点与时长、音量层级、氛围类型 | 具体旋律、音色、音效素材 |
| 商业化 | 付费点位置、活动节奏类型 | 具体档位设计、价格、礼包内容 |

### ⛔ 禁止（必须原创替代，标 X）

- 任何美术素材：立绘、精灵图、图标、UI 贴图、字体文件、动画帧
- 任何音频：BGM、音效、配音
- 任何代码：反编译产物、脚本、着色器
- 商标与标识：游戏名、Logo、图标、标语
- 角色与专名：角色名、地名、术语、技能名（独创性越强风险越高）
- 文本：剧情、对白、道具描述、教程文案
- **具体关卡地图的逐格/逐区复制**
- 具体 UI 视觉稿的整体照搬（即便换了颜色）
- 数值表中的"整表搬运"（尤其商业化与抽卡概率表）

## 三、换皮混淆自检（命中 ≥2 条 = 高风险）

1. 同题材 + 同美术风格（同色系同构图）
2. 同 UI 布局（同位置同结构同交互）
3. 同角色名 / 同术语 / 同技能名
4. 同关卡顺序 + 同关卡结构
5. 同图标语义（同形状同位置的功能图标）

任意 2 条命中：视为"易造成来源混淆"，必须改到 ≤1 条。**改颜色不算改**。

## 四、合法替代手法（X 项的落地做法）

| 受保护元素 | 替代手法 | 示例 |
|---|---|---|
| 角色立绘 | 重设剪影语言（体型/轮廓/配色三要素全换），保留"职能定位" | 原作"火法师"→ 你做"焊枪工"，职能同、形象全异 |
| UI 视觉 | 保信息层级，重做视觉系统（网格/圆角/层级块） | 原作卡片式 → 你做扫描线仪表盘 |
| 关卡地图 | 保节奏曲线，重排空间（动线方向、掩体密度、视野开合） | 原作"左窄右宽"→ 你做"环形容器" |
| 剧情文本 | 保情绪曲线，重写事件与人物关系 | 原作"救妹"→ 你做"赎旧债" |
| 专有名词 | 重造术语体系（同一机制换一套命名逻辑） | "灵石"→"废料芯" |
| 音乐音效 | 重录/重生成，保触发点与时长 | 同"命中瞬间 80ms 短促音"，素材全新 |
| 图标 | 重画语义隐喻（换隐喻不换功能） | "背包"→ 工具箱造型 |
| 商业化档位 | 按自身成本结构重定锚点 | 原作 6/30/98 → 你做 8/28/88 并改权益组合 |

**原则**：**保"功能与节奏"，换"符号与表达"。** 替代后必须能通过"换皮混淆自检 ≤1 条"。

## 五、UI 与关卡的"正确抄法"

**UI**：抄的是「信息优先级 + 反馈时机」，不是「长什么样」。
- ✅ 主界面第一屏必须看到：当前目标、资源、主操作按钮
- ❌ 按钮在右下角、卡片圆角 12px、图标同款描边

**关卡**：抄的是「节奏曲线」，不是「地图」。
- ✅ 0~30s 教学、30~90s 首次压力、90s 后给奖励喘息
- ❌ 敌人放在坐标 (x,y)、掩体这几个位置、Boss 在第三区

## 六、联机 / 手游额外合规项

| 项 | 要求 |
|---|---|
| 隐私 | 收集个人信息须明示与同意；隐私政策可访问；最小必要 |
| 支付 | 明示价格与概率（抽卡概率公示）；退款路径；不得诱导消费 |
| 未成年人 | 实名与防沉迷（中国大陆强制）；未成年人消费限额；广告投放限制 |
| 广告 | 激励视频需明示奖励；不得伪装成内容；频次不得骚扰 |
| UGC / 社交 | 内容审核机制、举报入口、封禁规则 |
| 数据 | 数据出境、日志留存、账号注销 |

## 七、发布前 checklist

- [ ] X 清单全部有 `replacement`，无一条直接沿用
- [ ] 素材来源可追溯（自产 / 已授权 / 开源许可），许可证文件留档
- [ ] 换皮混淆自检 ≤1 条命中
- [ ] 名称/Logo 已做商标检索（目标市场 + 类别）
- [ ] 数值表未整表搬运；商业化概率已按自身设计重定并公示
- [ ] 隐私政策、用户协议、概率公示、未成年人保护齐备（如适用）
- [ ] 第三方 SDK（广告/统计/支付）清单与合规声明齐备
- [ ] 法务确认项已列清单并完成（发布前，不是发布后）
- [ ] 保留拆解过程记录（用于证明独立创作：设计稿、迭代版本、素材源文件）

**留痕建议**：拆解报告 + 设计稿时间线 + 素材源文件，是"独立创作"最实用的证据链。别只留最终产物。
