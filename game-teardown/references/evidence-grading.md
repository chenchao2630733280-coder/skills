# 证据分级细则（结论类型 / 覆盖矩阵 / 陈述分离 / 置信度拆分）

> 本文件从 `game-teardown/SKILL.md` §8.2 抽离。SKILL 保留 E0–E3 等级定义与 §8.3 硬规则，
> 本文是判定细则。写拆解报告、填 `TEARDOWN_MATRIX.json` 时读本文件。
>
> 一句话：**AI 做逆向拆解最大的失败不是拆不全，而是把推断写成事实。** 下面四条都是防这一件事。

### 8.2 结论类型 → 证据形态（错配即降级）

| 结论类型 | 需要的证据形态 | 单帧够吗 |
|---|---|---|
| 存在性（有没有这个对象/这行 UI） | 清晰单帧 | ✅ |
| 顺序/因果（先发生什么、由什么触发） | 连续帧 / 多段录屏 | ❌ |
| 频率/概率 | ≥30 次同类事件采样 | ❌ |
| 规则（判定条件、优先级） | 对照实验（只改一个变量） | ❌ |
| 数值公式 | ≥3 点拟合 + 未参与拟合点回测 | ❌ |
| 隐藏关系（归属、层级、遮挡） | "移除上层后露出"的对照帧 | ❌ |

**规则**：证据形态与结论类型不匹配 → 该结论降为 E0/E1，进待验证清单。**单帧只能证明"此刻"，证明不了"顺序"。**

### 8.3 样本覆盖矩阵（缺格即盲区）

| | 初始态 | 中途态 | 满/临界态 | 失败态 | 重开态 |
|---|---|---|---|---|---|
| 新手关卡（前 3 关） | | | | | |
| 中期关卡 | | | | | |
| 后期关卡 | | | | | |

报告 §0 写"覆盖了哪几格、缺哪几格"。**只看过前 2 关就断言后期难度曲线，是本 skill 最常见的越界。**

### 8.4 三类陈述必须分离（报告写作纪律）

| 前缀 | 含义 | 要求 |
|---|---|---|
| `【观察】` | 我直接看到的 | 必须能指到帧号/样本数/截图 |
| `【推断】` | 我根据观察推的 | 写明依据 + 至少 1 个替代解释 + 如何证伪 |
| `【设计】` | 我建议怎么做（**不是原作**） | 明确标"原创方案"，不得混进结论区 |

禁止把【设计】写成陈述句混在【观察】里——读者会误以为原著如此，下游会照着"假原作"实现。
矩阵 `kind` 字段（observed / inferred / design）与此一一对应。

### 8.5 标注置信度按属性拆分

一个对象可以"形状=高、归属=中、层级=低"。**禁止给一个对象一个笼统的置信度**，必须拆到属性级：
`B12 | 形状:高 | 颜色:高 | 归属:中 | 层级:低 | 是否有独立螺丝:待确认`

粒度失控的统一写法：`S019/S020 坐标极近，是否两颗独立螺丝待逐帧确认`——**可疑处要留痕，不要凑数。**
