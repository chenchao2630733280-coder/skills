## 一、设计原则

| 原则 | 说明 |
|---|---|
| 高效 | 管理后台以完成任务为核心，信息密度优先于装饰性，减少用户操作路径 |
| 一致 | 全站统一色彩、字号、间距、圆角、交互模式，同类操作在任何页面表现一致 |
| 清晰 | 层级分明，主次有序；重要操作突出，危险操作有明确警示和二次确认 |
| 反馈 | 任何操作都有及时反馈（加载中、成功、失败），反馈文案准确可执行 |
| 可控 | 布局、主题、标签页等均可通过 `src/config/theme.config.js` 集中配置，业务代码不硬编码 |

## 二、色彩体系

所有颜色均以 SCSS 变量定义于 `library/styles/variables/variables.module.scss`，**禁止在业务代码中写死色值**。

### 2.1 品牌主色

框架内置三套主题色，通过配置文件一键切换（详见第十三章）：

| 主题 | 主色 | 色值 | 适用场景 |
|---|---|---|---|
| blue（默认） | `$base-color-primary` | `#1890ff` | 通用企业系统，默认推荐 |
| green | `$base-color-primary` | `#41b584` | 生态、健康、农业类产品 |
| purple | `$base-color-primary` | `#6954f0` | 科技、数据类产品 |

主色衍生态由框架自动生成：`primary-light-1` ~ `primary-light-9`（主色与白色按 10%~90% 混合），用于 hover（light-1）、禁用（light-5）、浅色背景填充（light-8/9）等场景。

### 2.2 功能色

| 语义 | 变量 | 色值 | 用途 |
|---|---|---|---|
| 成功 | `$base-color-success` | `#13ce66` | 操作成功、正向状态、启用状态 |
| 警告 | `$base-color-warning` | `#ffba00` | 需注意但不阻断的提示、待处理状态 |
| 危险 | `$base-color-danger` | `#ff6700` | 删除、停用等破坏性操作按钮 |
| 错误 | `$base-color-error` | `#ff4d4f` | 表单校验失败、接口报错、严重异常 |

功能色使用规则：
- 功能色仅用于语义表达，不作装饰用途。
- 同一语义全站同色，不得用 success 表示警告等错位用法。
- 删除、清空、禁用等破坏性操作统一使用 danger，并配合二次确认（见第十章）。

### 2.3 文本色

| 层级 | 变量 | 色值 | 用途 |
|---|---|---|---|
| 主要文字 | `$base-color-text-primary` | `#303133` | 标题、正文核心内容、表格主字段 |
| 常规文字 | `$base-color-text-regular` | `#606266` | 正文、表单项内容 |
| 次要文字 | `$base-color-text-secondary` | `#909399` | 辅助说明、时间、描述信息 |
| 占位文字 | `$base-color-text-placeholder` | `#c0c4cc` | 输入框 placeholder、禁用态文字 |

正文基准色另约定 `$base-color-black: #515a6e`，纯白 `#ffffff` 用于深色菜单上的文字。

### 2.4 边框与分割线

| 层级 | 变量 | 色值 | 用途 |
|---|---|---|---|
| 基础边框 | `$base-border-color-base` | `#dcdfe6` | 输入框、按钮默认边框 |
| 浅边框 | `$base-border-color-light` | `#e4e7ed` | 卡片、表格外框 |
| 更浅边框 | `$base-border-color-lighter` | `#ebeef5` | 表格内部分割线 |
| 超浅边框 | `$base-border-color-extra-light` | `#f2f6fc` | 弱分割、hover 区域描边 |

规则：分割优先用浅色层级；同一容器内最多出现两级边框色，避免视觉嘈杂。

### 2.5 背景色

| 用途 | 变量 | 色值 |
|---|---|---|
| 页面背景 | `$base-color-background` | `#f6f8f9` |
| 基础填充背景（表头、斑马纹） | `$base-background-color-base` | `#f5f7fa` |
| 深色菜单背景 | `$base-menu-background` | `#282c34` |
| 卡片/面板 | — | `#ffffff` |

### 2.6 配色规则

1. 页面由「页面背景 `#f6f8f9` + 白色卡片」构成基本层次，内容一律置于白色卡片内，不直接放在灰色背景上。
2. 单屏内主色占比不超过 10%，主色只出现在：主按钮、选中态、链接、进度条、关键数据。
3. 深色菜单下文字统一使用 `hsla(0,0%,100%,0.95)`，选中态背景为主色。
4. 暗色主题（`vab-theme-black`）由框架自动映射背景与文字，业务组件只引用 CSS 变量，不写死黑白。

## 三、字体与排版

### 3.1 字号梯度

| 变量 | 大小 | 用途 |
|---|---|---|
| `$base-font-size-small` | 12px | 辅助说明、标签、表格次要列 |
| `$base-font-size-default` | 14px | **全局基准字号**：正文、表单、表格、按钮 |
| `$base-font-size-big` | 16px | 卡片标题、弹窗标题、区块标题 |
| `$base-font-size-bigger` | 18px | 页面主标题 |
| `$base-font-size-max` | 22px | 数据看板核心数字、空状态插画标题 |

### 3.2 排版规则

- **字重**：正文 400，强调/标题 500~600，禁止使用 700 以上。
- **行高**：正文 1.5 倍（14px → 21px），标题 1.3 倍；多行文本行高不低于 1.5。
- **字体族**：系统默认栈 `-apple-system, "PingFang SC", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif`，数字建议 `font-variant-numeric: tabular-nums` 保证表格数字对齐。
- **行长**：表单页正文每行不超过 60 字符；说明文字不超过两行，超出用 Tooltip 承接。
- **标题层级**：页面主标题（18px）→ 卡片/区块标题（16px）→ 正文（14px）→ 辅助（12px），一个页面最多 3 层。

## 四、布局规范

### 4.1 布局模式

框架内置 6 种布局，通过 `src/config/theme.config.js` 的 `layout` 字段切换：

| 布局 | 值 | 适用场景 |
|---|---|---|
| 纵向布局 | `vertical`（默认） | **通用首选**，左侧菜单 + 顶部导航，适合菜单层级深的系统 |
| 横向布局 | `horizontal` | 菜单少而扁平（一级 ≤ 6 项）的工具型系统 |
| 分栏布局 | `column` | 一级菜单极多，需"图标栏 + 二级菜单"双栏导航 |
| 综合布局 | `comprehensive` | 一级菜单置顶、二级菜单在左的混合结构 |
| 常规布局 | `common` | 无顶部 Logo 区的简洁结构 |
| 浮动布局 | `float` | 内容沉浸式、菜单悬浮的特殊场景 |

**项目内布局一旦确定，全站统一，不混用。**

### 4.2 全局框架尺寸

| 区域 | 变量 | 高度/宽度 |
|---|---|---|
| 顶部导航栏 NavBar | `$base-nav-height` | 60px |
| 头部 / Logo 区 | `$base-header-height` / `$base-logo-height` | 60px |
| 标签页栏 TabsBar | `$base-tabs-height` | 50px |
| 单个标签页 | `$base-tag-item-height` | 34px |
| 侧边菜单（展开） | `$base-left-menu-width` | 266px（允许 266/277/288 三档） |
| 侧边菜单（折叠） | `$base-left-menu-width-min` | 64px |
| 菜单项 | `$base-menu-item-height` | 50px |
| 内容区最大宽度 | `$base-main-width` | 1279px |
| 全局层级基准 | `$base-z-index` | 1999 |

结构自上而下：`NavBar（60px）→ TabsBar（50px）→ AppMain（内容区）`，内容区高度由框架按 `calc(100vh - 60px - 50px - 40px - 55px)` 自动计算。

### 4.3 布局配置项约定

| 配置 | 默认值 | 规范建议 |
|---|---|---|
| `fixedHeader` | true | 始终固定头部，长页面滚动不丢失导航 |
| `showTabs` | true | 开启多标签页，符合后台多任务并行的工作方式 |
| `tabsBarStyle` | smooth | card / smart / smooth 三选一，全站统一 |
| `showTabsIcon` | true | 标签页带图标，与菜单图标一致 |
| `showRefresh` / `showFullScreen` | true | 保留刷新与全屏工具 |
| `showProgressBar` | true | 开启顶部路由进度条（NProgress，主色） |
| `uniqueOpened` | false | 菜单层级 ≥ 3 级时建议改 true，只展开一个子菜单 |
| `foldSidebar` | false | 内容密度高的页面可默认收起侧边栏 |

### 4.4 内容区栅格与宽度

- 内容区采用 Element Plus 24 栅格（`el-row` / `el-col`）。
- 查询表单：`el-col` 常用 `:span="6"`（一行 4 项）或 `:span="8"`（一行 3 项）。
- 表单页：单列布局，表单容器宽度 480~720px，超长表单分卡片分组。
- 列表页：表格通栏，占满卡片宽度。
- 内容区上下留白 20px（`$base-padding`），卡片间距 20px。

### 4.5 响应式断点

PC 后台以桌面为主，最低适配宽度 **1280px**；当视口小于 992px 时侧边栏自动折叠为 64px 图标模式。不为手机端做适配，如需移动访问另建 H5 端。

## 五、间距、圆角与阴影

### 5.1 间距体系

以 **4px 为基数**，基准间距 **20px**：

| 变量 | 值 | 用途 |
|---|---|---|
| `$base-margin` / `$base-padding` | 20px | 卡片内边距、卡片间距、页面留白 |
| — | 16px | 表单项间距、区块间距 |
| — | 12px | 按钮间距、图标与文字间距 |
| — | 8px | 紧凑列表、标签间距 |
| — | 4px | 最小间隔单位 |

规则：
- 同级元素间距一致，嵌套层级越深间距越小（20 → 16 → 12 → 8）。
- 卡片 `padding` 统一 20px；卡片之间 `margin-bottom` 统一 20px。
- 禁止使用 20px 以上的空白做分隔，层级分不开时用卡片而非加大留白。

### 5.2 圆角

全局圆角 `$base-border-radius: 2.5px`（同步映射为 Element Plus `--el-border-radius-base`）。

- 输入框、按钮、卡片、弹窗：统一 2.5px，不单独覆盖。
- 标签页 smooth 风格的圆角由框架主题样式控制，业务不干预。
- 头像可用圆形（50%），其余元素禁止大圆角。

### 5.3 阴影

| 变量 | 值 | 用途 |
|---|---|---|
| `$base-box-shadow` | `0 1px 4px rgba(0,21,41,0.08)` | 卡片、下拉面板、悬浮层 |

规则：全站只此一级阴影；弹窗、抽屉用 Element Plus 默认遮罩，不额外加阴影；禁止多层阴影叠加。

### 5.4 控件高度

输入框、选择器、按钮默认高度 `$base-input-height: 32px`（对应 Element Plus `default` 尺寸）。全站统一使用 default 尺寸，表格内操作按钮允许 `small`，禁止同页混用 large。

## 六、导航规范

### 6.1 侧边菜单

- 一级菜单项高 50px，图标 + 文字横向排列，图标尺寸 16~18px，与文字间距 8px。
- 深色菜单背景 `#282c34`，文字 `hsla(0,0%,100%,0.95)`，选中项背景为主色、文字纯白。
- 菜单最多支持 **3 级**，超过 3 级须改用分栏布局或扁平化信息架构。
- 折叠态（64px）只显示图标，hover 弹出文字菜单。
- 当前路由对应的菜单项必须高亮并自动展开父级。

### 6.2 标签页（TabsBar）

- 开启 `showTabs` 后，访问过的页面以标签形式驻留，标签缓存上限 `keepAliveMaxNum: 20`。
- 标签支持：关闭当前、关闭其他、关闭全部；固定标签（`meta.affix`）不可关闭。
- 标签文字与菜单标题（`meta.title`）保持一致，带 `meta.icon` 图标。

### 6.3 面包屑

- 使用框架 `VabBreadcrumb` 组件，位置在内容区顶部。
- 路径格式：`一级菜单 / 二级菜单 / 当前页`，当前页不可点击。
- 单层级页面（路由 `meta.breadcrumbHidden: true`）隐藏面包屑，避免"首页 / 首页"式冗余。

### 6.4 页头工具区

右侧工具区顺序固定：搜索 → 刷新 → 通知 → 全屏 → 语言 → 主题设置 → 用户头像。头像下拉包含：个人中心、修改密码、退出登录。

## 七、组件规范

### 7.1 总则

- 优先使用 Element Plus 原生组件与框架 `library/components` 下封装组件（`VabQueryForm`、`VabDialog`、`VabCard`、`VabColorfulCard` 等），**禁止引入第二套 UI 库**。
- 所有组件默认尺寸统一（default / 32px），状态颜色取自功能色变量。

### 7.2 按钮

| 类型 | 用法 |
|---|---|
| primary | 页面/表单唯一主操作（保存、查询、新建），一个视图区最多 1 个 |
| default | 次操作（取消、重置、导出） |
| danger | 删除、停用等破坏性操作，必须配 `ElMessageBox` 二次确认 |
| text / link | 表格行内操作（编辑、详情），行内操作超过 3 个时折叠进"更多"下拉 |

规则：按钮文字为 2~4 字动词短语（"新增用户"优于"新增"时可带宾语）；提交类按钮在请求期间进入 loading 态并禁用，防止重复提交（框架 `debounce` 配置可全局拦截）。

### 7.3 查询表单（筛选区）

- 使用 `VabQueryForm`，置于列表页顶部白色卡片内。
- 筛选项一行排 3~4 个，超过 4 个时默认收起，提供"展开/收起"。
- 操作按钮固定在末位：查询（primary）、重置（default）。
- 重置必须同时清空查询条件并恢复第一页。

### 7.4 表格

- 表头底色 `#f5f7fa`，行内分割线 `#ebeef5`。
- 表格默认显示边框（`border`），数据密集时开启斑马纹二选一，不同时开。
- 数字右对齐、文本左对齐、状态与操作列居中。
- 状态用 `el-tag` 表达：成功 success / 警告 warning / 危险 danger / 信息 info，颜色与语义严格对应。
- 时间格式统一 `YYYY-MM-DD HH:mm:ss`（dayjs 处理）；空数据统一显示 `-`。
- 空状态：无数据时展示插画 + "暂无数据"，有筛选条件时提示"未找到相关结果，请调整筛选条件"。
- 操作列固定在右侧（`fixed="right"`），宽度按按钮数量给 120~220px。
- 批量操作：勾选后在表格左上方出现批量操作条（批量删除/导出），并显示已选数量。

### 7.5 分页

- 分页器置于表格卡片右下角，要素完整：总数、每页条数、页码、跳转。
- 每页条数选项固定 `[10, 20, 50, 100]`，默认 20。
- 切换筛选条件、重新查询后必须重置到第 1 页。

### 7.6 表单

- 布局：label 右对齐置顶（`label-position="right"`），label 宽度统一（如 100px/120px），同页一致。
- 必填项红星由 `rules` 自动生成，不手写 `*`。
- 校验时机：输入类 `blur`，选择类 `change`；错误信息红字（`#ff4d4f`）显示在控件下方。
- 输入控件宽度：短输入（数字、编码）220px，常规输入 320px，长文本/文本域通栏。
- 提交按钮组：主操作（保存）在左、取消在右，与表单左对齐。
- 表单提交成功后给出成功提示并按场景返回列表页或停留当前页（新增停留、编辑返回）。

### 7.7 弹窗与抽屉

- 表单字段 ≤ 6 个用 `VabDialog` 弹窗，宽度 520~640px；字段多或含富文本/表格用抽屉（`el-drawer`，宽 600~800px）。
- 弹窗标题 16px，底部按钮右对齐（取消 / 确定）。
- 弹窗内内容超出时内部滚动，按钮区固定不随内容滚动。
- 禁止弹窗套弹窗；深层确认用 `ElMessageBox`。

### 7.8 卡片

- 页面内容由白色卡片承载，卡片标题 16px/600，标题与内容之间无额外分割线时用 16px 间距。
- 数据概览使用 `VabCard` / `VabColorfulCard`：核心数字 22px 主色或深色，指标名 12~14px 次要文字色。
- 统计卡片一行 4 个（`span="6"`），不超过 5 个。

### 7.9 反馈组件

| 场景 | 组件 | 规范 |
|---|---|---|
| 轻提示 | `ElMessage` | 操作成功/失败结果，时长 3000ms（`messageDuration`），位置顶部居中 |
| 强提醒 | `ElNotification` | 系统通知、异步任务完成，右上角 |
| 二次确认 | `ElMessageBox.confirm` | 删除/停用/提交审核，标题"操作确认"，文案说明后果 |
| 加载 | `v-loading` | 请求超过 300ms 显示，按钮级 loading 优先于全屏 loading |
| 骨架屏 | `el-skeleton` | 首屏/卡片加载使用，避免白屏闪烁 |

## 八、图标规范

1. 图标三来源，优先级：**框架 svg 雪碧图（`src/icon`）→ Element Plus Icons（`@element-plus/icons-vue`）→ vab-icons**。
2. 菜单图标使用 `meta.icon` 配置，风格全站统一（同一套图标库），不混用线性/面性两种风格。
3. 图标尺寸：菜单 16~18px，按钮内 14px，空状态插画不限但风格统一。
4. 图标颜色跟随文字色，不单独着色；状态图标（√/×/!）可使用功能色。
5. Logo 通过 `setting.config.js` 的 `logo` 字段配置（指向 `src/icon` 下图标名），Logo 区高度 60px，替换时保持正方形比例。

## 九、动效规范

| 项 | 值 |
|---|---|
| 全局过渡 | `all 0.3s cubic-bezier(0.645, 0.045, 0.355, 1)`（`$base-transition`） |
| 页面切换 | `showPageTransition: true`，使用框架内置 fade/slide 过渡，全站一种 |
| 菜单折叠/展开 | 0.3s 宽度过渡 |
| hover 反馈 | 0.1~0.2s 颜色过渡 |

规则：动效时长不超过 0.3s；列表项不做逐个延迟入场动画；数据刷新不做闪烁强调；大屏/看板之外的场景不使用循环动画。

## 十、反馈与文案规范

### 10.1 操作反馈闭环

任何写操作必须走完三态：**触发（按钮 loading）→ 结果（成功/失败提示）→ 界面更新（刷新列表/关闭弹窗）**，缺一不可。

### 10.2 文案规范

| 场景 | 模板 | 示例 |
|---|---|---|
| 成功 | 动作 + 结果 | 「保存成功」「用户删除成功」 |
| 失败 | 原因 + 建议 | 「保存失败，请检查网络后重试」 |
| 删除确认 | 后果说明 + 不可逆提示 | 「删除后数据将无法恢复，确定删除该用户吗？」 |
| 空输入提示 | 请 + 动作 + 对象 | 「请输入用户名」「请选择所属部门」 |
| 占位符 | 与校验提示一致 | placeholder = 「请输入×××」 |

- 语气：陈述、客观，不用"亲""哦"等口语，不用感叹号。
- 按钮与提示中的名词与菜单名一致（菜单叫"用户管理"，按钮就叫"新增用户"）。

### 10.3 异常页面

- `403`：无权限访问，提供"返回首页"；`404`：页面不存在，提供"返回首页"。
- 接口 401 自动跳转登录页，并按 `recordRoute: true` 记录当前路由，登录后还原。
- 请求错误统一由 axios 拦截器处理并提示，业务代码不重复弹错。

## 十一、页面模板规范

### 11.1 列表页（占比最高，必须统一）

结构自上而下：

```
[查询卡片]  筛选项 + 查询/重置
[表格卡片]  工具栏（新增/批量操作/刷新） + 表格 + 右下分页
```

- 查询卡片与表格卡片间距 20px。
- 新增/编辑优先用弹窗或抽屉，不跳新页（流程长的表单除外）。

### 11.2 表单页

- 页面主标题（18px）+ 表单卡片；超长表单按业务分组为多卡片，每组有 16px 组标题。
- 底部操作栏：保存（primary）+ 取消，吸底时背景纯白并带上边框。

### 11.3 详情页

- 使用 `el-descriptions` 展示基础信息，label 宽统一，一行 2~3 列。
- 关联数据（日志、子表）用 Tabs 组织在详情下方。

### 11.4 看板页

- 顶部统计卡片行（VabCard）→ 图表区（一行 2 个图表卡片）→ 明细表格。
- 图表配色以主色为起点取色，同页图表色系一致。

### 11.5 登录页

- 居中卡片（宽 400px），Logo + 系统名 + 账号密码 + 登录按钮（通栏 primary）。
- 开启 `loginRSA` 时密码加密传输；登录失败提示统一「用户名或密码错误」，不区分具体原因。

## 十二、路由与权限规范

### 12.1 路由 meta 字段约定

| 字段 | 类型 | 说明 |
|---|---|---|
| `title` | string | 必填，菜单名/标签页名/面包屑名三者同源 |
| `icon` | string | 菜单图标 |
| `hidden` | boolean | true 时不在菜单显示（登录页、错误页、详情页） |
| `breadcrumbHidden` | boolean | 隐藏面包屑 |
| `affix` | boolean | 固定标签页，不可关闭 |
| `permissions` | string[] | 按钮/路由级权限标识 |
| `roles` | string[] | 角色控制（`rolesControl: true` 时生效） |

### 12.2 权限模式

- `authentication: 'intelligence'`：前端导出全部路由，按角色过滤（前后端分离演示/小项目）。
- `authentication: 'all'`：后端动态下发路由（生产推荐）。
- 按钮级权限：使用权限指令/函数判断 `permissions`，无权限按钮**隐藏而非禁用**。
- 白名单路由（登录、403、404）配置在 `routesWhiteList`，与 login 同级。

### 12.3 命名约定

- 路由 `name` 与组件名一致，采用大驼峰（如 `UserManagement`）。
- path 小写中划线（`/system-manage/operation-logs`），目录与 path 对应。
- 页面组件统一命名 `Index.vue`，置于以路由名命名的文件夹下。

## 十三、主题定制指南

### 13.1 配置入口

| 文件 | 职责 |
|---|---|
| `src/config/theme.config.js` | 布局、主题名、标签页、功能开关（改后需清浏览器缓存） |
| `src/config/setting.config.js` | 标题、Logo、权限模式、存储、路由行为 |
| `library/styles/variables/variables.module.scss` | 全局样式变量（颜色、尺寸、间距） |
| `library/styles/variables/vab-{blue\|green\|purple}-variables.module.scss` | 各主题色变量及 light 梯度 |

### 13.2 换肤机制

框架根据 `themeName`（如 `blue-white`）动态加载对应变量文件，将 `vab-*` 变量通过 CSS 变量覆盖 Element Plus 的 `--el-*`（如 `--el-color-primary`）；后缀（black/white/ocean）映射为 body class 控制明暗。

**定制新主题色的步骤：**
1. 复制 `vab-blue-variables.module.scss` 为 `vab-xxx-variables.module.scss`，修改 `vab-color-primary` 及 light 梯度。
2. 在设置 store 的主题映射中注册 `xxx` 前缀。
3. 业务组件一律使用 `--el-color-primary` 等 CSS 变量或 SCSS 变量，不写死色值——这是换肤生效的前提。

### 13.3 暗色模式

- 通过 body class `vab-theme-black` 切换；业务自定义组件必须消费 CSS 变量，保证暗色下可读。
- 暗色下避免纯黑 `#000` 背景与纯白 `#fff` 文字的直接对比，文字透明度 0.85~0.95。

## 十四、国际化规范

- 框架集成 vue-i18n，`setting.config.js` 的 `i18n` 字段设置默认语言（`zh` / `en`），`showLanguage` 控制语言切换入口。
- 所有界面文案（菜单、按钮、提示、占位符）必须走 `$t()` 语言包，禁止硬编码中文。
- 语言包 key 按"模块.页面.元素"分层（如 `user.list.addButton`）。
- 英文环境下注意按钮/标签宽度余量（英文约为中文 1.5~2 倍长）。

## 十五、工程与命名规范

### 15.1 代码风格

- 遵循仓库内置 ESLint + Prettier + Stylelint 配置，提交前自动 lint-staged 校验，不关闭、不绕过。
- CSS 类名遵循 BEM 风格小写中划线（如 `user-list__header`）；组件样式必须使用 `scoped` 或 CSS Module。
- 样式只写 SCSS，颜色/间距/圆角一律引用变量，不写魔法数字。

### 15.2 目录约定

```
src/
├── api/        # 接口层，按模块分文件，方法名动词开头（getUserList）
├── views/      # 页面，与路由结构一一对应
├── components/ # 业务公共组件（大驼峰目录 + Index.vue）
├── store/      # Pinia，按模块分文件
├── utils/      # 工具函数，纯函数、有单测
├── config/     # 全局配置入口
└── router/     # 路由与权限守卫
```

### 15.3 接口与数据

- 统一走 axios 封装实例，业务页面不直接 `import axios`。
- 时间处理统一用 dayjs；金额、数字格式化统一走 utils，不在模板里写逻辑。
- 导出 Excel 使用框架内置 xlsx 方案，大文件上传使用 vue-simple-uploader 分片。

### 15.4 性能红线

- 路由全部懒加载；路由缓存上限 20 页（`keepAliveMaxNum`）。
- 单接口列表页首屏请求 ≤ 2 个；表格单页渲染不超过 100 行（超出用分页）。
- 图片走 CDN/压缩，图标用 svg 雪碧图而非大图。
