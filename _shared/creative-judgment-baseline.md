# 创作判断基线 —— 叙事 / 美术 / 表演三层检查清单

> 本文件是 `short-drama-spec`（叙事层）与 `short-drama-storyboard`（美术/表演层）共用的**判断标准**，不产出任何文件，只用于"自检时逐条过"。
>
> **来源**：2XLabs 导演课核心论点 —— *AI 缩小了技术水平的差距，却放大了认知水平的差距*。传统影视里服化道/灯光/美术/场记都有专人把关，AI 时代这些底层判断全归创作者自己完成。故本清单检的不是"提示词写没写对"，而是**判断本身对不对**。
>
> **为什么放在流水线里**：AI 天然擅长生成"抽象的平均值"（平均的美、平均的悲伤）。创作者的增量价值恰恰在于**用具体打破平均值**。本清单就是把这个"具体化"动作变成可执行、可复核的条目。

---

## 零、总纲：把不可控的抽象，翻译成可控的具体

| 抽象（AI 无法直接生成） | 翻译为 | 落到哪个阶段 |
|---|---|---|
| 世界观 / 奇观 | **具体的人** | 叙事层（阶段 2 spec） |
| 好看 / 高级感 | **考据 + 光影逻辑** | 美术层（阶段 4 storyboard） |
| 情绪 / 内心的戏 | **动作 + 动机** | 表演层（阶段 4 storyboard + 阶段 5 视频） |

**两条检查公式**（可直接套用）：
```
可信度 = 现实底座 × 细节密度     # 奇幻/奇观靠考据撑，不靠堆特效
感染力 = 克制动作 × 明确动机     # 情绪靠有来由的行为，不靠形容词
```

**执行顺序铁律**：先定「这个故事要成立什么」→ 再定「让观众相信什么」→ 最后定「让人物做什么」。顺序颠倒 = 想法太多、人物很空。

## 一、叙事层检查清单（阶段 2 · short-drama-spec）

### 1.1 反向陷阱：世界观膨胀

- [ ] **故事一句话能说清吗**？若必须用"宏大世界观 + 多方势力 + 复杂设定"才能讲明白，即为膨胀信号
- [ ] **人物是不是世界的附属品**？若把角色换成任意同类设定的人、故事照样成立 → 说明人物没有不可替代性
- [ ] **每个设定是否回答了"有没有帮这个故事成立"**？答不上的设定应删除或降级为背景

### 1.2 具体化检验

- [ ] 主角的**目标**是否具体到可以"看见"（不是"想要变强"，而是"要在三个月内赢回那间铺子"）
- [ ] 主角的**困境**是否是具体的、有对象的事件（不是"命运不公"）
- [ ] 世界观信息是否**通过人物行为透露**，而非靠旁白/字幕直接说明

### 1.3 情绪→行为 翻译（本层最关键）

拿到剧本里的每一处情绪描写，逐条反问：

| 情绪（抽象） | 必须翻译为可指认的行为（具体） |
|---|---|
| 舍不得 | 放慢的脚步、攥紧的手、临别的一次回头 |
| 愤怒 | 摔东西？不 —— 更克制：手停在半空又放下 |
| 害怕 | 后退半步、手不自觉抓住衣角 |
| 犹豫 | 欲言又止、抬脚又收回 |

- [ ] 剧本中**没有"他心里很悲伤"这类不可拍摄的句子**（导演/演员/AI 都无法执行）
- [ ] 每一处关键情绪，至少配 1 个**可拍摄的行为动作**
- [ ] **动机和情绪不是戏，行为才是戏** —— 若只有动机陈述没有行为落点，判为不合格

### 1.4 与 spec §十 评分系统的关系

本清单是评分维度「情绪价值」「主角目标清晰度」「人物关系张力」的**判断依据**：
- 「主角目标清晰度」→ 用 1.2 检验
- 「情绪价值」→ 用 1.3 检验
- 膨胀的世界观会让「故事发动机强度」「剧情升级能力」虚高但实空，须交叉复核

## 二、美术层检查清单（阶段 4 · short-drama-storyboard）

### 2.1 反向陷阱：一眼 AI

"一眼 AI"的病因通常**不在模型，而在没真正理解这个世界**。逐条自检：

- [ ] 画面元素是否有**时代 / 地域 / 身份**依据，而非"好看的通用元素"堆砌
- [ ] 是否存在**时代错位**（不该出现的材质、器物、服饰、建筑形制）
- [ ] 是否存在**地域错位**（南方水乡配了北方的建筑/植被）
- [ ] 是否存在**身份错位**（角色衣着/用品与其社会身份、经济条件不符）

### 2.2 考据清单（具体性来源）

参考案例：*江边的孩子不穿鞋、渡船老人的头饰藏着船桨元素* —— 细节里藏着世界观的可信度。

- [ ] 每个主要角色是否有 **≥1 个"从生活推出来"的细节**（职业痕迹、生活习惯、身体印记）
- [ ] 每个常驻场景是否有 **≥1 个"只有这个时空才有"的记号**
- [ ] 这些细节是否**来自角色处境推导**，而非随意添加的装饰

### 2.3 光影清单：不是选最美的，是选最对的

- [ ] 每场戏的光影是否**服务于情绪**，而非服务于"好看"
  - 参考：黄昏的明暗里藏着人物的孤独与希望
  - 参考：蜡烛的忽明忽暗里藏着时代的真实感
- [ ] 光源是否有**合理来源**（自然光/烛火/油灯/霓虹），而非无来源的"氛围打光"
- [ ] 光影变化是否**与剧情同步**（情绪转折点是否有光影呼应）

### 2.4 奇幻/奇观的处理

- [ ] **现实的底座越扎实，奇幻的部分反而越动人** —— 奇幻元素是否建立在可信的现实基础上
- [ ] 奇观镜头前后是否有**现实镜头做锚**，避免全片悬浮
- [ ] 视觉风格的统一是否由 `styleBaseline`（资产层）锁定，而非每个镜头各自发挥

## 三、表演层检查清单（阶段 4 声明 + 阶段 5 实现）

### 3.1 反向陷阱：人物一动就假

- [ ] 分镜/视频 prompt 里是否**塞满了形容词**（"悲伤地""深情地""复杂地"）→ 形容词是"假"的直接来源
- [ ] 是否给的是**具体动作**：低头、侧身、欲言又止、沉默驻足

### 3.2 动作合法性检查（两个必答）

对每一个设计出的动作，逐条过：

| 检查 | 不合格表现 | 修正方向 |
|---|---|---|
| **动作有没有原因？** | 无缘无故的回头、莫名其妙的停顿 | 找到触发点；找不到就删掉这个动作 |
| **反应有没有对象？** | 对着空气表演情绪 | 明确他在看谁/听什么/被什么触发 |

- [ ] 每个关键动作都能回答"**为什么是这一秒**"
- [ ] 每个反应都指向**具体的对象**（人/物/声音/记忆）

### 3.3 克制原则

- [ ] **克制的表演永远比夸张的表情更有力量** —— 是否存在"用力过猛"的设计（嚎哭、大动作、面部扭曲）
- [ ] 高情绪场景是否**反而用了更小的动作**（真正的痛是沉默）
- [ ] 动作幅度是否与镜头景别匹配（特写配微小动作，远景配大幅动作）

### 3.4 与资产层的衔接

- [ ] 同一角色的**表演习惯**是否稳定（如"习惯性攥手"应跨集一致，可作为角色资产的一部分）
- [ ] 变体（年龄/战伤/换装）是否**同步调整了表演方式**（老年变体的动作幅度、节奏应不同）

## 四、三层联合复核（阶段 4 产出后一次）

将三层串起来问同一个问题：**"这场戏有没有帮这个故事成立？"**

- [ ] 叙事层的行为动作（§1.3）→ 是否在美术层有**物质支撑**（道具/服饰/环境）
- [ ] 美术层的细节考据（§2.2）→ 是否在叙事层有**来历**（不能是凭空装饰）
- [ ] 表演层的动作（§3.2）→ 是否由**叙事层的动机**驱动（不能是孤立动作）

**不合格信号**：三层各自看起来都对，但拼在一起"不像一个世界" —— 说明缺了这层联合复核。

## 五、速查卡（打印/贴墙用）

```
【叙事】世界观再大，也要落到具体的人
        "有没有帮这个故事成立？"
        舍不得 = 放慢脚步 + 攥紧手 + 临别回头

【美术】好看的图 ≠ 可信的世界
        时代 / 地域 / 身份 → 考据
        光影：选最对的，不是最美的
        现实底座越扎实，奇幻越动人

【表演】别给形容词，给动作
        低头 / 侧身 / 欲言又止 / 沉默驻足
        动作要有原因，反应要有对象
        克制 > 夸张

【联合】先定成立什么 → 再定相信什么 → 最后定做什么
        可信度 = 现实底座 × 细节密度
        感染力 = 克制动作 × 明确动机
```

## 六、反向用法：本清单不做的事

- **不替代** `short-drama-spec` §十 的评分系统（那是**结构完整性**评分，本清单是**判断质量**检查，二者互补）
- **不替代** Gate 0~4 的契约校验（那是**机读契约合规**，本清单是**创作判断自检**）
- **不作为硬阻断项**：本清单未通过不直接 FAIL 流水线，而是标记为创作质量问题，由用户决定是否回退修改
- **不放进 ASSET_MANIFEST**：这是方法论参考，不产生机读产物
