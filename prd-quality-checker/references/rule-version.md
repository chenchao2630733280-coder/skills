# Rule Version

当前规则版本：`1.1.0`

## 版本规则

- 主版本：门禁含义、评分体系或核心输出协议发生不兼容变化。
- 次版本：新增检查维度、画像、可选规则包或结构化字段。
- 修订版本：措辞、示例或不改变结论的规则澄清。

每份正式报告和 JSON 都记录：

- `rule_version`
- 审核日期
- 审核范围
- 输入材料版本或可定位标识

历史报告不因规则升级自动改写。需要使用新规则重新判断时，执行 Incremental 或 Full 复审，并说明版本变化影响。
