## 5. 优先级矩阵

> 横轴:改造成本(低→高);纵轴:收益(低→高)。

```
高收益 │ ②快速赢(优先做)    │ ①重大改造(计划做)
       │                      │
       │──────────────────────│──────────────────────
       │                      │
低收益 │ ④低优先(有空做)    │ ③暂缓(不建议做)
       │──────────────────────│──────────────────────
       低成本                 高成本
```

| 象限 | 策略 | 关联建议 |
|---|---|---|
| ① 高收益高成本 | 列入计划,分阶段实施 | {Top N} |
| ② 高收益低成本 | 立即执行 | {Top N} |
| ③ 低收益高成本 | 暂缓 | {Top N} |
| ④ 低收益低成本 | 有空再做 | {Top N} |
