# 秘密与真相系统（四层秘密）——懒加载参考

> 本文件由 `short-drama-spec` 的 SKILL.md §六 懒加载引用。使用时全文替换为具体故事内容。

## 一、四层秘密总览

| 层 | 负责什么 | 揭露节奏 | 揭露后改变什么 |
|---|---|---|---|
| 即时秘密 | 前几集追更 | 前 5 集内揭 | 主角处境改变，产生第一个阶段性目标 |
| 关系秘密 | 改变信任与人物立场 | 中段（约 1/3-1/2 处）揭 | 关系阵营重组，盟友/对手易位 |
| 主线秘密 | 改变主角目标与调查方向 | 中后段（约 1/2-3/4 处）揭 | 原目标作废，新目标/新对手出现 |
| 终极真相 | 重新解释前文、回应主题 | 终局（最后 1/4）揭 | 全剧被重新解释，导向最终选择 |

> 层级可嵌套：一个"终极真相"由多个"主线秘密"支撑；每个"主线秘密"由多个"即时秘密"牵引。

## 二、每层秘密填写模板

对每一层秘密逐项填写：

```
秘密内容：
谁知道：                # 具体到人（含主角/对手/秘密持有者/观众）
谁不知道：              # 具体到人
谁误解：                # 谁以为的版本是什么
首次暗示集数：          # 至少一个不可见的伏笔
部分揭露集数：          # 观众知道但角色不知道 / 角色知道但观众不知道
完全揭露集数：
揭露后改变什么：        # 目标/关系/风险/规则理解至少一项
是否产生新问题：        # 揭露必须引出新问题，不允许"揭完就平"
```

## 三、埋伏笔技巧清单（终极真相必用）

提前埋下至少 3 类以下信号，最终真相揭晓时观众能回想到"原来早就有提示"：

- **行为异常**：某人物在无关场景做了一件"不合时宜"的事
- **道具线索**：一件道具多次出现，每次出现情境略有不同
- **时间矛盾**：某事件的时间线对不上，早期被忽略
- **语言漏洞**：某人说漏嘴 / 用词与身份不符
- **人物回避**：某话题一提就被转移
- **重复细节**：同一细节在不同集数重复出现，最后一次才解释

## 四、终极真相自检

- [ ] 终极真相能**重新解释前文**（至少 3 个早期细节被重新定义）
- [ ] 终极真相回应**主题**（与主角缺陷/最终选择挂钩）
- [ ] 终极真相有 ≥3 类伏笔铺垫（§三），不是突然出现的新设定
- [ ] 终极真相揭露后主角面临**最终选择**，而不是只剩"打败反派"
- [ ] 每层秘密揭露都制造新问题，不稀释悬念
- [ ] 秘密掌握者数量合理（太多人知道=观众早猜到；太少=信息断层）
