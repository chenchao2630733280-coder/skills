## 一、人物功能表

| 功能 | 责任 | 硬性要求 |
|---|---|---|
| 主角 | 推动剧情 | 每阶段有主动行动；不长期依赖被救/被陷害/等真相 |
| 核心对手 | 制造阻碍 | 有目标/行动逻辑/资源优势/合理动机；不是纯恶 |
| 情感关系人物 | 制造拉扯 | 与主角互相有欲望；关系至少经历三次变化 |
| 利益盟友 | 阶段性帮助 | 帮助必须附代价或期限；可倒戈 |
| 潜在背叛者 | 中段反转 | 背叛前铺垫 ≥2 次征兆（行为/台词/回避），不允许突然变脸 |
| 秘密持有者 | 控制信息 | 知道的比说的多；有自己的隐瞒理由 |
| 镜像人物 | 映照主角 | 与主角走另一条路的"另一个我"，终局提供选择对照 |

**合并规则**：功能可合并（如"情感关系人物"兼"秘密持有者"），但合并后必须同时满足两项责任；任何人物不能只剩工具属性（只有功能、没有欲望）。

## 二、重要关系 7 问（每段关键关系必答）

对每一对关键关系（主角×对手、主角×情感人物、主角×盟友、盟友×背叛者…）逐一回答：

```
1. A 想从 B 身上得到什么？
2. B 想从 A 身上得到什么？
3. A 为什么不能直接说出真实目的？
4. B 误解了 A 什么？
5. 双方共同利益是什么？
6. 双方最终冲突是什么？
7. 关系会经历哪三次变化？（列出变化点所在集数/阶段）
```

> 7 问中第 1-2 问答不出 = 这段关系是单向工具关系，需重做。
> 第 7 问必须写出三次变化的具体内容与时机，写不出 = 关系无弧光，需重做。

## 三.5 人物深度工坊（8 项深层画像，AI 塑料感过滤器）

> 表面卡（§三 3.1/3.2）回答"你是谁"；本工坊回答"你像不像活人"。深度工坊能逼出**可演、可拍、不塑料**的行为细节，避免形容词堆砌（"性格冷静""内心善良"这类标签一律不算落地）。

**每人（至少主角与核心对手）填 8 项中的 ≥5 项，其中 ④⑤⑥⑧ 必填。**

```
① 一个公开的欲望：        # 所有人都知道他想要什么
② 一个隐藏的恐惧：        # 只有他自己/终局才暴露的死穴
③ 一个与欲望冲突的价值观：# 想得到X，但相信"不该那样得到"
④ 一个反复出现的习惯动作：# 具体到可拍：玩打火机、把碗洗两遍、拽袖口
⑤ 一段不愿提起的记忆：    # 一提就停顿/转移话题（给"回避"行为埋点）
⑥ 一句常说的谎话：        # 小而具体，不是弥天大谎
⑦ 一个对自己残忍的时刻：  # 对别人好、却亏待自己的具体场景
⑧ 一个让观众又爱又气的缺点：# 越共情越来气的性格缺陷，不是扁平恶
```

> 判定标准：凡某项只写得出形容词（冷静/温柔/固执），一律不算过，必须补一个**具体行为或物件**落地。第 ④⑤⑥ 直接喂给 short-drama-script 做"人物口吻表"与"动作/OS"素材。

## 五、人物一致性提示（供阶段 3 剧本引用）

- 每个人物固定 1-2 个口头禅/说话习惯，写进人物卡"表面性格/谎言"附近，供 short-drama-script 保持口吻一致
- 人物立场变化必须有剧情触发点，禁止"为反转让人物突然变性格"
- 对手至少一次真正帮助主角、至少一次做出可理解的选择、终局迫使主角面对自身缺陷
