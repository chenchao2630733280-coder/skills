# 故事发动机（八部件 + 7 问）——懒加载参考

> 本文件由 `short-drama-spec` 的 SKILL.md §三 懒加载引用。使用时全文替换为具体故事内容。
> 铁律：**先做发动机，再做分集**；八部件任一项空着，禁止写分集大纲。

## 一、八部件填写模板

### 部件 1：主角

```
主角是谁：
表面身份：              # 别人眼中的他
真实处境：              # 实际处境（含隐藏的难处）
最大性格缺陷：          # 缺陷必须与"最终选择"有关
最擅长的能力：          # 能力必须能推动剧情，不悬空
最害怕面对的事情：      # 后期必须逼他面对
最想保护的人：          # 常与"为什么不能退出"绑定
```

### 部件 2：主角欲望

```
表层目标：              # 前几集观众能看懂的目标
深层需求：              # 主角自己都没意识到的需求（中段才浮现）
隐藏欲望：              # 不敢承认的欲望（终极真相揭开时才面对）
```

> 三层欲望的差距 = 人物弧光的空间。三层完全一致 → 没有成长弧光。

### 部件 3：启动事件

必须同时满足：
- 第一集发生（不允许 5 集以后才启动）
- 不可逆（不能假装没发生）
- 改变主角原有生活
- 迫使主角立刻行动
- 与核心规则相关
- 能产生第一集结尾卡点

```
启动事件：
不可逆性体现在：
与核心规则的关系：
第一集结尾卡点：        # 卡点类型（信息/危机/关系/选择/反转）
```

### 部件 4：主角为什么不能退出（≥2 个）

从以下池子里选 ≥2 个，并说明各自如何升级：

| 原因 | 升级方式示例 |
|---|---|
| 时间压力 | 倒计时每阶段缩短 |
| 身份暴露 | 每次行动暴露一点 |
| 亲人安全 | 威胁对象从 A 变成 A+B |
| 巨大利益 | 利益背后藏着更大的陷阱 |
| 无法解除的契约 | 违约代价递增 |
| 规则反噬 | 用得越多，自身被规则吞掉越多 |
| 社会性死亡 | 证据链越来越实 |
| 道德责任 | 知情即责任，无法装看不见 |

```
原因一：              升级方式：
原因二：              升级方式：
```

### 部件 5：核心阻碍

```
外部阻碍：              # 对手/环境/资源
内部阻碍：              # 缺陷/恐惧/错误信念
关系阻碍：              # 想保护的人变成掣肘
规则阻碍：              # 规则本身的限制与反噬
```

> 四类阻碍必须每类都能单独制造至少 1 个阶段的核心冲突。

### 部件 6：对手

```
对手是谁：
目标：                  # 与主角目标构成零和或价值观冲突
行动逻辑：              # 他为什么这么做（自洽）
资源优势：              # 信息/权力/钱/规则理解
合理动机：              # 动机要让部分观众能共情
主动攻击能力：          # 不能只被动防守，必须主动出手
识别主角弱点的能力：    # 至少一次打中主角内部弱点
镜像关系：              # 与主角的相似/对照点（身份、选择、价值观）
```

> 镜像关系是反派系统的灵魂：对手至少一次真正帮过主角、至少一次做出可理解的选择、终局迫使主角面对自身缺陷。

### 部件 7：升级机制（≥6 种）

| 维度 | 含义 | 例子 |
|---|---|---|
| 对手升级 | 对手更强/更聪明 | 二号对手浮现 |
| 信息升级 | 知道得更多但更不确定 | 真相反转 |
| 代价升级 | 每次行动的代价递增 | 规则反噬加剧 |
| 时间压力升级 | 期限收紧 | 倒计时缩短 |
| 关系破裂 | 信任崩塌 | 盟友倒戈 |
| 规则失控 | 规则超出掌控 | 能力暴走 |
| 身份暴露 | 秘密被部分揭穿 | 众人起疑 |
| 目标改变 | 原目标作废 | 新目标出现 |
| 真相改变 | 已知"真相"被推翻 | 记忆为假 |
| 盟友转敌 / 敌人转盟 | 立场互换 | 背叛者反转 |
| 更大系统出现 | 舞台变大 | 幕后组织现身 |


> 最终高潮不能只靠"打败反派"。终极对决 = 选择 + 规则漏洞利用 + 真相揭晓三合一。

## 二、发动机 7 问（验收）

1. 这个故事为什么能**持续**发生（而不是只发生一次）？
2. 主角在每个阶段**主动做了什么**？
3. 主角为什么不能退出？
4. 对手的目标与主角冲突的本质是什么？
5. 每一次胜利带来了什么新问题？
6. 核心规则如何持续制造剧情？
7. 最终选择发生在哪两个价值之间？

> 7 问全部答得上 → 发动机成立；任何一问答不上 → 回到对应部件补强。

## 三、反套路检查（防止换皮）

常见换皮风险：隐藏身份连续打脸 / 重生按顺序复仇 / 契约婚姻爱上对方 / 真假千金清算 / 赘婿突然暴露身份 / 穿越靠现代知识碾压。

发现相似度过高时，**至少替换两个核心变量**（身份、规则、关系、代价、结局任选两个），并写出替换前后差异。

## 四、最高原则

- 故事发动机高于剧情数量
- 主角行动高于被动遭遇
- 目标冲突高于无意义争吵
- 规则代价高于能力炫技
- 阶段升级高于重复打脸
- 最终选择高于简单胜利
- 完整因果高于强行爽点
