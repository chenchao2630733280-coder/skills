# BGM 情绪匹配与 ducking 规范(懒加载)

> 何时读取:执行音乐/BGM 匹配与电平建议(SKILL.md §四)需要完整情绪匹配表、ducking 参数、生成/选曲流程时。

## 一、BGM 情绪匹配完整表

短剧单集 1-3 分钟,通常含 1-3 个情绪段落。按"情绪场景"匹配 BGM:

| 情绪场景 | BPM | 乐器/织体 | 动态 | 典型用途 | 命名建议 |
|---|---|---|---|---|---|
| 开场悬念(mystery) | 60-80 | 低频 pad、钟琴、心律鼓 | 渐强、留白多 | EP 前 10s 钩子 | bgm_mystery.mp3 |
| 冲突紧张(tension) | 120-140 | 鼓点、弦乐 staccato、合成器 | 强、急促 | 冲突、追逃、对峙 | bgm_tension.mp3 |
| 甜宠温馨(sweet) | 90-110 | 木琴、钢琴、轻吉他 | 轻快、明亮 | 恋爱、日常、互动 | bgm_sweet.mp3 |
| 虐心悲伤(sad) | 60-70 | 钢琴慢板、弦乐长音 | 弱、渐弱 | 分离、误会、回忆 | bgm_sad.mp3 |
| 高潮燃(climax) | 130-150 | 交响/电子鼓、crescendo | 极强、爆发 | 反转、反杀、爽点 | bgm_climax.mp3 |
| 结局释然(release) | 70-90 | 温暖钢琴/吉他 | 弱、渐弱收尾 | EP 结尾、和解 | bgm_release.mp3 |
| 反派主题(villain) | 80-100 | 低音铜管、不协和音 | 阴冷、压迫 | 反派登场、设局 | bgm_villain.mp3 |
| 喜剧/打脸(comedy) | 110-125 | 拨弦、木管、滑稽音效垫 | 跳跃、俏皮 | 打脸、反转搞笑 | bgm_comedy.mp3 |

**每首 BGM 的匹配标注**(写入 docs/AUDIO_SPEC.md):

```markdown
## BGM 匹配表
| BGM | 情绪 | 使用镜头段 | 建议电平 | 来源 |
|---|---|---|---|---|
| bgm_tension.mp3 | 冲突紧张 | EP01:shot_06~09 | 对白-18dB/纯乐-10dB | Suno 生成 |
```

## 二、选曲 vs 生成决策

| 条件 | 决策 |
|---|---|
| 平台版权曲库有匹配情绪曲 | 直接选曲(最快、版权安全) |
| 需要原创 OST(单曲贯穿全剧) | Suno/Udio 生成(总纲 §3.2) |
| 音乐生成失败 | 平台免费曲库 BGM 占位 + 标记(软降级) |
| 图文短剧型 | 卡点 BGM 优先(节奏明快,配合字幕卡点) |

**Suno/Udio 生成 prompt 要素**:情绪词 + 节奏(BPM)+ 乐器 + 时长(30-90s)+ 无人声(重要,避免抢对白)。

## 三、ducking 规则(对白优先)

### 3.1 电平目标

| 场景 | BGM 目标电平 | 说明 |
|---|---|---|
| 对白时 | 约 **-18dB**(范围 -20~-16dB) | 保证对白清晰度,人声约 -6dB 基准 |
| 纯音乐段落 | **-10dB** | 让位画面情绪 |
| 高潮卡点(无对白) | **-6dB** | 最高电平,之后让位对白 |
| EP 片尾 | 渐弱到 -30dB 收尾 | 卡点句后淡出 |

### 3.2 实现方式(供 short-drama-edit 执行)

- **首选 sidechaincompress**(按对白轨自动压缩 BGM,动态 ducking):
  ```
  [bgm][voice] sidechaincompress=threshold=0.03:ratio=8:attack=20:release=500
  ```
- **备选 静态分段衰减**:按镜头段手动 volumebd(-18dB 段 / -10dB 段 / -6dB 段)
- 本 skill 只产出 BGM 文件 + 建议电平标注,混音由 short-drama-edit 的 ffmpeg 完成

### 3.3 电平标注格式

在 AUDIO_SPEC 每首 BGM 标注分段电平:

```json
{ "bgm": "bgm_tension.mp3",
  "segments": [
    {"range": [0, 5],   "level_db": -10},
    {"range": [5, 12],  "level_db": -18, "note": "对白段"},
    {"range": [12, 18], "level_db": -6,  "note": "高潮卡点"}
  ] }
```

## 四、音效(可选)补充

- 按 STORYBOARD 音效提示从平台素材库选(优先)或 AI 音效生成
- 命名 `audio/sfx_{name}.mp3`,<2s
- 电平建议:-12dB 基准(不压对白),惊悚/重击类可到 -6dB
- 缺失不阻塞,标记"音效未配"

## 五、常见坑

1. **BGM 盖过对白**:所有含对白镜头段必须 ducking 到 -18dB 级别,宁可音乐弱不可对白糊
2. **情绪不匹配**:选曲/生成后必须回填"情绪=镜头段"映射,不能只丢一首 BGM 不管段落
3. **卡点 BGM 与字幕卡点不同步**:图文短剧型要求 BGM 重拍对齐字幕卡点句,生成时提示"重拍在第 N 秒"
4. **版权**:禁止直接搬运受版权保护歌曲;平台曲库需确认商用授权(发布前)
