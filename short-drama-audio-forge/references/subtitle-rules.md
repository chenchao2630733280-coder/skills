# 字幕规范(懒加载)

> 何时读取:生成字幕 subtitles/{ep}.srt(SKILL.md §六)需要 srt 细节规范、时间轴公式、卡点字幕实现时。

## 一、SRT 格式规范

标准 SRT,UTF-8 编码,`subtitles/{ep}.srt`:

```
1
00:00:00,500 --> 00:00:03,200
你终于来了。

2
00:00:03,400 --> 00:00:06,000
我等了你整整三年。
```

- 序号从 1 递增;时间轴 `HH:MM:SS,mmm`(毫秒 3 位)
- 正文每行 ≤20 字(含标点);多句可同屏多行(每行一句,行间换行)
- 竖屏适配:正文不加空行(避免安全区外被裁),标点保留

## 二、时间轴推算公式

### 2.1 基准数据

- 对白时长:由 TTS 生成 mp3 实测时长决定(ffprobe)
- 镜头时长:来自 STORYBOARD(镜头 N 开始时间 = 前 N-1 镜头时长累计)

### 2.2 公式

```
镜头 K 开始时间 T_k   = Σ(镜头 1..K-1 时长)
字幕条目(台词 j,镜头 K):
  开始 = T_k + 镜头内对白偏移(通常 0.2s 口播起步)
  结束 = max(镜头 K 结束时间, 该镜头最后一句对白结束 + 0.3s 余量)
```

- 无对白镜头:若 STORYBOARD 有音效/音乐提示,生成说明性字幕(如"【雨声】");否则留空(不生成空条目)
- 相邻条目间隔 ≥0.1s,不允许重叠;重叠时以后者为准前推

### 2.3 字幕覆盖要求

- 首条字幕开始 ≤ 片头 1s;末条字幕结束 ≥ 片尾(镜头结束)
- 全片时间轴连续覆盖(允许无对白段无字幕,但段落间不得出现"字幕卡死残留")

## 三、断句规则(与 TTS 共用,禁止各自断句)

- 语义节奏优先:主谓宾完整 + 语气停顿处断
- 单句 ≤20 字;超长拆句(拆句点:句号/叹号/问号 > 逗号/省略号 > 语气词)
- 断句结果 = 配音断句 = 字幕分行,三处必须一致

## 四、卡点句(结尾悬念字幕)

### 4.1 定义

每集结尾的"钩子/悬念"字幕(如"可他不是已经死了吗?"),用于卡点留存。

### 4.2 醒目标注实现

SRT 中追加注释行标记(标准 SRT 解析器会忽略,转 ASS 时读取):

```
3
00:01:39,800 --> 00:01:42,500
可他……不是已经死了吗？
<!-- CLIMAX:EP01:3 -->
```

- 注释格式:`<!-- CLIMAX:{ep}:{序号} -->`,序号 = SRT 条目序号
- 同时在 `docs/AUDIO_SPEC.md` 记录"卡点字幕:EP01 第 3 条"
- 转 ASS 时对该条用高亮样式(见 §五),short-drama-edit 烧录时保留

### 4.3 卡点节奏

- 卡点句后画面保持 ≥0.5s(留白给观众反应)
- 卡点句与高潮 BGM 重拍对齐(图文短剧型必须)

## 五、SRT → ASS 转换要点(供 short-drama-edit)

- 竖屏 1080x1920:字幕位于底部安全区(下沿约 88%-92% 高度,即 y≈1720-1760)
- 白字 + 黑色描边(Outline=2, Shadow=1),字号 48-56px
- 卡点句(CLIMAX 注释):换高亮色(如金色 #FFD700)+ 加粗 + 放大 1.2 倍
- 每行显示时长 1.5-5s;长行拆分避免超时残留

```
[V4+ Styles]
Format: Name, Fontname, Fontsize, PrimaryColour, OutlineColour, BackColour, Bold, Italic, Outline, Shadow, Alignment, MarginV
Style: Default,Noto Sans CJK SC,52,&H00FFFFFF,&H00000000,&H00000000,0,0,2,0,1,2,180
Style: Climax,Noto Sans CJK SC,62,&H0000D7FF,&H00000000,&H00000000,1,0,2,0,1,2,180
```

## 六、字幕完整性自检

- [ ] 行数与台词句数一致(每句台词一条,无遗漏)
- [ ] 每行 ≤20 字
- [ ] 时间轴首尾闭合、无重叠、无跳变
- [ ] 卡点句带 CLIMAX 注释且已记录
- [ ] 时间轴由"对白实测时长 + 镜头时长"推算(非拍脑袋)
- [ ] 估算时间轴(降级)已标注"估算时间轴"

## 七、常见坑

1. **字幕时间轴与镜头错位**:对白字幕必须落在对应镜头区间内,禁止一句台词横跨两个镜头
2. **超长行**:一行 >20 字必拆,否则竖屏阅读困难且易被安全区裁剪
3. **卡点句被切**:卡点句所在镜头必须完整呈现,禁止在句中被转场打断(这是 Gate 5 卡点完整性检查项)
4. **编码**:SRT 必须 UTF-8 无 BOM(剪映/ffmpeg 兼容),避免中文乱码
