# 创意多样性引擎

## 必须保存的历史特征

工具应为每个选题保存：

- 主人公身份
- 主人公欲望
- 规则来源
- 核心规则
- 规则代价
- 关系结构
- 核心观看动力
- 第一集异常
- 最大反转
- 终局选择
- 创意坐标

下一轮生成时，将最近50—200条历史选题特征传入 Skill。

## 多样性策略

### 配额多样性
确保整批候选在类型、人物、规则、动力、结局上分散。

### 距离多样性
同批选题之间也要计算相似度，而不仅是与历史比较。

### 反向补样
识别集中倾向后，主动生成相反方向。

### 随机种子
小工具可以生成一个字符串种子，例如：
`2026-07-22-comedy-elderly-urban-47`
并保存到生成任务，便于复现。

### 冷却变量
高频变量进入冷却列表，未来3—5轮降低出现概率。

示例：

```json
{
  "cooldown_variables": [
    {"value": "记忆交易", "rounds": 4},
    {"value": "婚姻背叛", "rounds": 3},
    {"value": "女调查员", "rounds": 5}
  ]
}
```

## 推荐的小工具参数

- 创意距离：0—100
- 商业熟悉度：0—100
- 现实度：0—100
- 情感浓度：0—100
- 悬疑浓度：0—100
- 喜剧浓度：0—100
- 奇观度：0—100
- 趋势依赖度：0—100
