# 完整调用示例

请生成12个短剧选题。

目标用户：
25—40岁大众用户。

制作条件：
中低成本，主要角色不超过8人，主要场景不超过6个。

创新等级：
1—5级混合。

观看动力要求：
至少覆盖8种核心观看动力；
每个选题配置一个核心动力和两个辅助动力；
第一集有明确追问和小满足；
第三集、十集均有阶段兑现；
中段必须更换观看理由。

多样性要求：
避免集中在女性悬疑、婚姻背叛、记忆交易和身份反转；
至少覆盖6类题材、6类主人公、6类规则来源和5种结局；
与以下历史选题相似度超过60时，替换至少两个核心变量：
【在此粘贴历史收藏摘要】

趋势雷达：
观察中国大陆最近90天的上升话题，以及未来12个月的确定事件、周期性事件和弱信号；
趋势只做故事化转译，不直接复刻真实新闻；
禁止利用灾难、真实伤亡和未定性案件。

按观看动力优先排序，并输出变量分布检查。
