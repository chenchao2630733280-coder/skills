# AI短剧高概念选题策划师 v2.1

## 版本定位

本 Skill 用于生成、筛选、收录前评估和继续发散短剧选题。

本版本包含三套核心引擎：

1. **观看动力引擎**：判断观众为什么点开、追更和等待结局；
2. **创意多样性引擎**：通过变量池、组合配额和相似度惩罚，避免每轮输出同一倾向；
3. **趋势雷达引擎**：探查当前热点、上升信号和未来可预期事件，为选题增加现实热度。

最高目标不是生成“看起来新奇”的选题，而是生成：

> 具有差异化、持续观看动力、现实共鸣和可开发空间的短剧故事种子。

- 合规与侵权风险识别；

1. 这个选题与上一批相比真正改变了什么？

6. 趋势信号是否可靠、是否已经过热、是否可能迅速过期？

# 四、创意多样性引擎

## 4.2 生成配额

当输出12个选题时，默认配额：

```text
题材类别：至少6类
主人公职业或社会位置：至少6类
核心观看动力：至少8类
核心规则来源：至少6类
人物关系结构：至少6类
结局方向：至少5类
制作难度：低、中低、中至少各有
创新等级：1—2级不少于3个，3级不少于3个，4—5级不少于4个
```

不得让超过30%的选题共享同一核心变量。

例如：

- 不得超过3个选题都使用记忆；
- 不得超过3个选题都以婚姻为核心；
- 不得超过3个选题都以女调查员为主角；
- 不得超过3个选题都以悬念为核心观看动力；
- 不得超过3个选题都以身份反转为最大反转。

## 4.4 历史相似度惩罚

如果用户提供历史选题、收藏库或上一轮结果，逐一计算概念相似性。

比较维度：

```text
主人公身份
人物欲望
核心规则
规则代价
人物关系
核心观看动力
第一集异常
最大反转

```

相似度规则：

```text
0—39：明显不同
40—59：存在局部相似
60—74：需要替换至少两个核心变量
75以上：直接淘汰并重新生成
```

以下变化不算真正创新：

- 只更换姓名；
- 只更换职业名称；
- 只更换城市或时代；
- 只更换人物性别；
- 只把丈夫改成男友；
- 只把记忆换成梦境；
- 只把豪门换成科技公司；
- 只把反派身份换掉但目标和结构不变。

## 4.5 反倾向机制

生成前先识别本轮可能出现的模型默认倾向。

常见倾向：

```text
过度女性向
过度悬疑
过度记忆设定
过度婚姻关系
过度身份反转
过度悲剧代价
过度都市中产人物
过度依赖死亡和失踪
过度以调查真相为主线
过度使用系统或算法
```

发现倾向后，主动补足反方向样本：

```text
悬疑过多 → 增加喜剧、治愈、成长、能力解题
女性向过多 → 增加银发、家庭群像、男性成长、无爱情主线
记忆过多 → 使用语言、社会信用、好运、选择次数、注意力等
都市过多 → 增加社区、小城、乡镇、封闭机构、移动空间
悲剧代价过多 → 增加荒诞代价、关系代价、身份代价、机会代价
调查主线过多 → 增加经营、照顾、比赛、修复、逃离、谈判、守护
```

# 六、趋势雷达引擎

## 6.1 目标

趋势雷达不是照搬热搜，而是识别：

1. 当前正在上升的话题；
2. 持续增长的社会情绪；
3. 未来可以提前准备的事件窗口；
4. 适合故事化转译的制度、科技、生活方式变化；
5. 已经过热、容易撞题或迅速过期的热点。

趋势只能作为“故事增温器”，不能替代人物和观看动力。

---

## 6.2 趋势信号分层

### A级：已确认未来事件

具有明确时间或周期的事件：

```text
节日与节气
毕业季、开学季、求职季
婚恋与返乡周期
大型体育赛事
重大文化纪念节点
公开发布的政策执行节点
已公布的科技产品或行业会议
影视、游戏、文化IP的重要发行窗口
```

标记：

```text
event_type: confirmed
confidence: 80—100
```

### B级：周期性高概率事件

基于历史周期和社会节奏推断：

```text
春节返乡与家庭关系
毕业与就业
暑期旅游与亲子
婚礼季
年终裁员、绩效和消费
高温、极端天气与城市生活
考试、租房、搬家、养老、医疗等周期
```

标记：

```text
event_type: seasonal
confidence: 60—85
```

### C级：上升趋势信号

来自多来源的搜索、内容、新闻或创作趋势：

```text
搜索兴趣持续增长
多个平台出现相同关键词
新闻报道量快速上升
新职业或新消费行为出现
科技能力进入普通人生活
社会讨论从专业圈层扩散到大众
```

标记：

```text
event_type: emerging
confidence: 40—75
```

### D级：弱信号与趋势假设

尚未形成热点，但具备成为议题的可能：

```text
小众职业快速被关注
新型家庭关系
新技术带来的伦理问题
新的平台使用习惯
代际观念变化
城市生活的新矛盾
```

标记：

```text
event_type: weak_signal
confidence: 20—55
```

不得把C级或D级写成确定事实。

### 第一步：提取当前信号

```text

家庭和代际矛盾

```

### 第二步：建立未来事件窗口

检索未来3—12个月：

```text
确定日期事件

行业发布窗口
毕业、就业、返乡、婚恋、养老等周期
可能形成大众讨论的政策或技术落地节点
```

### 第三步：故事化转译

将事件转译为：

```text

```


## 6.5 趋势热度评分

趋势热度分100分：

```text

```

另设风险扣分：

```text

高度依赖单一新闻：-5至-20
可能快速过期：-5至-15
真实悲剧消费风险：-10至-40
政策与事实不确定：-5至-20
与选题结合生硬：-5至-20
```

## 6.6 热点伦理规则

禁止：

- 利用正在发生的灾难、伤亡和真实受害者进行娱乐化改编；
- 直接影射未定性的真实案件；
- 编造政策、灾害、战争或公共卫生预测；
- 将趋势假设写成确定事件；
- 使用真实普通人的私人信息；
- 为蹭热点破坏人物逻辑；
- 将敏感群体作为猎奇素材。

遇到敏感热点时，应提取更抽象的社会主题，例如：

```text
灾害新闻 → 城市互助、失联关系、公共系统脆弱性
裁员新闻 → 身份价值、职业替代、家庭权力变化
养老讨论 → 照护责任、记忆、代际选择
AI焦虑 → 身份复制、情感替代、工作意义
```

# 七、热点与创意融合矩阵

每个选题最多绑定：

- 一个主要趋势；
- 一个辅助社会情绪；
- 一个未来事件窗口。

不得堆叠多个热点。

融合方式：

```text

产生新的角色入口。

趋势作为规则：
把现实变化高概念化。

趋势作为关系压力：
改变家庭、婚恋、职场关系。

趋势作为观看动力：
观众想知道现实问题在极端规则下会怎样。

趋势作为发行窗口：

```


# 八、完整执行流程

```text
1. 读取用户要求与历史选题；
2. 识别历史倾向与重复变量；
3. 建立本轮创意坐标和生成配额；
4. 如启用趋势雷达，探查当前信号和未来事件窗口；
5. 将趋势转译为社会情绪、人物关系和规则，不直接照搬新闻；
6. 生成不少于30个反事实问题；
7. 使用人物、规则、关系、欲望、代价、观看动力和趋势组合；
8. 对候选执行历史相似度检查；
9. 对集中倾向执行反向补样；
10. 为每个候选建立多引擎观看动力；
11. 进行第一集、前十集、中段和终局压力测试；
12. 进行六阶段续航测试；
13. 进行趋势适配、过热和过期风险检查；
14. 进行制作、合规与侵权判断；
15. 按观看动力优先、趋势热度辅助排序；
16. 输出候选、变量分布、趋势说明、对比和冠军选题。
```

# 十三、失败回退与降级

短剧选题生成是创意型任务，可能因相似度过高、趋势数据缺失或用户不满意而失败。以下回退策略与 `runtime.yaml` 的 `degrade` 配置对应。

## 13.1 选题与历史相似度过高

**触发**：§4.4 历史相似度惩罚检查命中，生成选题与已收录选题相似度超过阈值。

**回退层级**：
- **L1 重生成**：触发相似度惩罚，调整变量池配额后重新生成，最多 3 轮。
- **L2 降级**：3 轮后仍不通过，降级为人工推荐池——从预设的题材变量组合中挑选低相似度方向，标注"人工推荐"后输出。
- **L3 暂停**：人工推荐池也无法满足时，暂停生成，输出相似度报告和冲突选题清单交用户决策。

## 13.2 趋势数据获取失败

**触发**：§6 趋势雷达引擎无法获取热点、上升信号或未来事件数据。

**回退层级**：
- **L1 跳过趋势**：跳过趋势雷达模块，仅基于内置变量池生成选题，在输出中标注"无趋势增强"。
- **L2 降级趋势**：使用最近一次成功获取的趋势快照（若有），标注"趋势数据可能过期"。
- **不阻断**：趋势缺失不阻断选题生成，仅影响选题的现实共鸣维度评分。

## 13.3 用户对全部候选均不满意

**触发**：用户在查看候选选题后明确否定全部选项。

**回退层级**：
- **L1 收集反馈重生成**：收集用户的否定反馈（哪些维度不对），调整变量池配额后重新生成 1 轮。
- **L2 再次重生成**：若第 1 轮仍不满意，缩小题材范围，基于用户反馈中最具体的否定点重新生成 1 轮。
- **L3 暂停交人工**：超过 2 轮仍不满意，暂停生成，输出当前候选 + 否定原因清单 + 建议人工提供更具体方向。

## 13.4 生成质量不达标

**触发**：§十二最终自检中关键项未通过（如题材覆盖不足、观看动力单一、趋势写成确定事实）。

**回退层级**：
- **L1 局部重做**：仅重做未通过的关键项对应部分，不重新生成全部选题。
- **L2 全量重做**：若关键项连续 2 轮未通过，清空当前轮次，调整变量池后全量重新生成。
- **L3 降级输出**：全量重做后仍有非关键项未通过，标注"部分自检未通过"后输出，关键项未通过则不输出。

## 13.5 失败记录

每次触发回退时，记录：
- 失败类型（相似度过高 / 趋势缺失 / 用户不满意 / 自检未通过）
- 触发的回退层级（L1/L2/L3）
- 最终处理结果（重生成成功 / 降级输出 / 暂停）

供后续优化变量池配额和相似度阈值参考。
