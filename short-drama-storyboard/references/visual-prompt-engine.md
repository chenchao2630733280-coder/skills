# 视觉 Prompt 引擎(文生图 / 图生视频 / 角色一致性)

> 本文件从 short-drama-storyboard SKILL.md §3.3 展开,写 prompt 时读取。

---

## 1. 文生图 Prompt 模板(六要素)

```
[画幅] {aspect} 9:16,
[主体] {character|object}(reference:{refPath}, seed:{seed}, {styleKeywords}),
[动作] {action},
[环境] {environment},
[光线] {lighting},
[风格] {style}, {styleKeywords}, cinematic, 8k, detailed
```

示例:

```
portrait 9:16, 林晚(reference:char/linwan.png, seed:20241, 都市悬疑,冷色调,电影感),
缓缓回头,侧脸,眼神锐利,
雨夜巷口,地面水洼倒映霓虹,
冷蓝侧光,雨丝可见,
都市悬疑,电影感,cinematic lighting
```

**要素检查**(缺一不可):主体 / 动作 / 环境 / 光线 / 风格 / 画幅(9:16)。

---

## 2. 图生视频 Prompt 模板(四要素)

```
{画面主体与当前状态}, {运动描述}, 镜头{镜头运动}, {时长}秒
```

示例:

```
林晚缓缓回头,眼神从平静转锐利,镜头缓慢推近,5s
```

**要素检查**:画面主体 / 运动描述 / 镜头运动 / 时长(3-10s)。运动描述要具体(谁动、怎么动、多快),避免"有动态感"这类模糊词。

---

## 3. 光线与情绪映射

| 情绪基调 | 光线建议 | 色调 |
|---|---|---|
| 紧张/悬疑 | 冷蓝侧光、硬光、阴影 | 蓝灰 |
| 温暖/治愈 | 暖黄昏光、柔光 | 橙黄 |
| 悲伤 | 低反差、冷色、逆光 | 蓝紫 |
| 愤怒/冲突 | 高反差、红光、顶光 | 红黑 |
| 惊悚 | 低照度、局部光、绿光 | 墨绿 |

---

## 4. 角色一致性控制(全剧强制)

1. **三件套**:同一参考图(reference 图)+ 固定 seed + 同一组风格关键词,注入每个角色镜头
2. 首帧定稿:角色首次出场生成后确认,后续镜头一律以其为 reference
3. 双人同框:主视角角色带 reference,次视角角色完整文字描述(服装/发型/色系)
4. 同角色不同情绪:改光线/动作/表情描述,**不改**服装/发型/seed
5. 漂移检测:对比参考图(发型/服装/肤色/脸型);漂移 → 用参考图重生成(≤2 次),仍漂移标记 `[漂移]`

---

## 5. 负面词建议(可附加)

```
模糊, 变形, 多余肢体, 文字水印, 低分辨率, 风格不统一, 服装改变, 双人融合
```

---

## 6. 场景一致性

- 同场景固定 seed;光线按情绪基调微调(暖/冷/明/暗)
- 场景变化(日夜/天气)在 prompt 中显式声明,保持布局与道具一致

---

## 7. 画幅与安全区

- 固定 9:16 / 1080x1920
- 主体放在中央偏上,底部 15%(0-162px)留给字幕,顶部 10% 留信息区
- prompt 中加 `vertical composition, subject centered upper-third` 类词
