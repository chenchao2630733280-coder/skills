# 镜头语言规则(景别 / 运镜 / 时长 / 正反打 / 卡点)

> 本文件从 short-drama-storyboard SKILL.md §五 展开,拆镜头时读取。

---

## 1. 景别定义与用途

| 景别 | 取景范围 | 用途 | 情绪效果 |
|---|---|---|---|
| 远景 | 人物全身+大环境 | 开场/空间交代/时代感 | 孤寂、渺小 |
| 全景 | 全身或大半身+环境 | 动作戏、场景建立 | 客观、信息量大 |
| 中景 | 膝盖以上 | 对话/日常动作(竖屏主力) | 自然、叙事 |
| 近景 | 胸部以上 | 情绪对话、反应 | 代入、共情 |
| 特写 | 面部/局部(眼/手/物) | 情绪高潮、关键道具、卡点 | 压迫、悬念 |

**竖屏注意**:竖幅(9:16)视野窄,远景/全景多用于纵向纵深(巷道/高楼/天井);横向多人同框改用中近景轮流切。

---

## 2. 运镜定义与用途

| 运镜 | 方式 | 用途 |
|---|---|---|
| 固定 | 机位不动 | 对话、客观记录 |
| 推 | 镜头向前(主体放大) | 强调情绪/发现关键信息 |
| 拉 | 镜头向后(主体缩小) | 揭示环境/孤立感 |
| 摇 | 机位原地转动 | 扫视环境、跟随视线 |
| 移 | 镜头平行移动 | 跟随行走、空间展示 |
| 跟 | 跟随主体移动 | 追逐、压迫感 |
| 升降 | 机位高低变化 | 俯视压迫/仰视威严 |

### 图文短剧降级运镜(无视频能力时,静态图+后期模拟)

| 原运镜 | 模拟方式 |
|---|---|
| 推 | 缩放放大(1.0→1.15,3-5s) |
| 拉 | 缩放缩小(1.15→1.0) |
| 移/跟 | 平移(上下/左右,幅度 ≤15%,避免出画) |
| 摇 | 缓慢平移+轻微旋转 |
| 固定 | 静态图+轻微呼吸抖动(±2% 缩放) |

---

## 3. 时长节奏

- 单镜头 3-10s;信息量大 3-5s,情绪镜头 6-10s
- 对白镜头:时长 ≥ 对白朗读时间 + 0.5s 缓冲;读不完 → 拆对白或加镜
- 卡点镜头(结尾悬念):建议 6-10s,给足铺垫

---

## 4. 对话正反打规则

- 双人对话:过肩(over-shoulder)或单侧(single)交替,沿视线轴保持方向一致
- 同一人连续对白 ≤2 镜,第 3 镜必须切对方反应或换角度
- 情绪激烈时插入近景/特写反应镜头
- 竖屏对话:优先单侧近景,减少双人同框(空间窄)

---

## 5. 卡点镜头(每集结尾)

- 必须特写或大反差(空场景骤变/声音先出画面后到/信息反转)
- 只给"钩子"不给答案:如刀尖、眼神、纸条、背影
- 卡点前 1-2 镜节奏收紧(镜头变短、景别变近)

---

## 6. 常见坑

- 同景别连续 3 镜以上 → 视觉疲劳,强制换景别
- 动作戏全是全景 → 缺节奏,插入近景细节
- 竖屏中远景人物过小 → 看不清表情,以中景/近景为主
- 卡点镜头用全景 → 悬念感弱,必须特写或大反差
