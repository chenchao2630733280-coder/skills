# 实战案例与排错（2026-09 苏州新生礼包演出票）

工作目录：`D:\work\AIPM\dalibao`，共 146 条卡券（coupon0 批次 1035-1043 + coupon1 批次 1044-1185）。

## 数据规模

- coupon1：142 条（Excel 序号 21-58），唯一封面 32 张
- coupon0（早期批次）：1035-1043，其中 1035 后台封面为空
- 最终核验：139 条（重名去重后）封面正确 + note 7 段 + state=2

## 排错记录

### 1. 创建后 state=0 异常
现象：列表状态列显示"0"，无启用/停用按钮。
原因：POST payload 未带 `state`。
解决：payload 必须带 `state: 2`；改状态走 `/coupon-info/state`（ids 逗号串，可一次 50 条）。

### 2. 自造 uploadId 报"uploadId已经失效"
原因：uploadId 由服务端托管。
解决：`GET /file/uploadid?isPublic=1&isPart=2&suffix=png&fileSize=<字节>` 取 `data.uploadId`，再 POST `/file/upload`。

### 3. 使用须知 note 没有换行
现象：API 写入后 `<p>` 被过滤成纯文本。
原因：服务端对 note 做 XSS 过滤。
解决：
- 写入/重写 → 走 UI（`fix_notes.js`，UEditor `setContent` + 保存，~7s/条，142 条约 18 分钟）
- 只改其他字段 → PUT payload **剔除 note**，原值完整保留（实测 7 个 `<p>` 不动）

### 4. UI 上传必弹裁剪窗
前端 `isNeedCrop=true` 恒成立。改为纯 API 上传（32/32 成功）。

### 5. 封面匹配命中 0（海报被移到子目录）
现象：保利 9 条缺封面。
原因：海报挪进 `cover/保利大剧院/海报/`，匹配只扫一层。
解决：`all_images(base)` 递归收集（`os.walk`），日期前缀/序号/关键词匹配全部改用递归列表。

### 6. COVER_OVERRIDE 路径失效
现象：`cover/狮山大剧院/乐园音乐会.jpg` 报 FileNotFound（实际是 .png）。
解决：override 值**不写扩展名**，加 `resolve_override()` 运行时解析（试 .jpg/.png/.jpeg，再按 basename 在目录内匹配）。

### 7. 重裁后线上没变
现象：`api_upload.js` 提示"完成 32/32"，但 18 张复用了旧 URL。
原因：脚本对已有 URL 跳过。
解决：先删 `cover-urls-api.json` 里对应 key 再上传（见 SKILL.md 路径 B）。

### 8. 老批次不在 id-map
1035-1043 无 name→dbId 映射。
解决：`replace_extra.js` 直接按 dbId 定向替换（TARGETS 常量里写死 id 与封面路径）。

### 9. note 段数不一致
1036/1040/1042（园林实景版《游园惊梦》）note 为 8 段，coupon1 标准为 7 段——属于该批原就有差异，未被操作破坏，需与用户确认是否统一。
