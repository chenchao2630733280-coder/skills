# 02｜评估机制：指标、口径、诊断与实验

## 1. 评估分层

| 层级 | 关键问题 | 指标示例 |
|---|---|---|
| 结果 | 玩家是否完成？ | 首次通关率、最终通关率 |
| 过程 | 玩家如何完成/失败？ | 尝试次数、耗时、失败进度 |
| 资源 | 玩家付出多少？ | 道具、续关、生命/能量消耗 |
| 体验 | 玩家感受如何？ | 主观难度、挫败、清晰度、成就感 |
| 业务 | 是否影响后续行为？ | 下一关继续率、会话继续率、留存 |

不要用单一指标替代完整判断。

## 2. 推荐指标定义

### 通关类
- **首次通关率** = 首次进入该关的玩家中，在第一次尝试成功的人数 / 首次进入该关的玩家数。
- **最终通关率** = 观察窗口内完成该关的玩家数 / 首次进入该关的玩家数。
- **尝试通关率** = 成功尝试次数 / 总尝试次数。注意它与玩家级通关率不同。
- **失败次数/玩家** = 观察窗口内失败尝试总数 / 进入关卡玩家数。

### 过程类
- **单次尝试时长**：从开始操作到胜负结算，排除后台挂起和异常中断。
- **失败进度**：失败时已完成目标量 / 总目标量；多目标关卡应分别计算。
- **操作效率**：有效操作数 / 总操作数，定义必须与玩法匹配。
- **剩余资源**：成功时剩余步数/时间/能量的分布，不只看均值。

### 资源类
- **道具使用率** = 使用指定道具的玩家数 / 进入关卡玩家数。
- **续关率** = 使用续关次数 / 触发续关机会次数。
- **额外资源消耗**：每位进入玩家在该关消耗的额外生命、能量或资源。
- 必须区分免费赠送、广告获得、付费获得的资源。

### 体验类
- 关后主观难度（例如1–5分）；
- “我知道为什么失败”认同度；
- 规则清晰度；
- 挫败感/公平感；
- 完成后的成就感。
- 问卷可能有响应偏差，需与行为数据交叉验证。

### 业务类
- 下一关继续率；
- 关卡后会话继续率；
- 次日/七日留存；
- 付费/广告指标。
- 业务指标受活动、渠道、版本、经济系统影响，不能轻易归因于单关难度。

## 3. 必须分群

最少按以下维度看：
- 新玩家/老玩家；
- 首次到达/重复尝试；
- 低/中/高能力估计；
- 是否使用道具；
- 是否续关；
- 设备性能/网络（玩法相关时）；
- 来源渠道/版本（有必要时）。

汇总平均值可能掩盖：新手卡住、高手轻松、整体均值看似正常的情况。

## 4. 诊断树

### A. 通关率低
依次排查：
1. 关卡是否可解？使用求解器/种子模拟验证。
2. 规则是否理解？看首次机制使用、误操作、提示触发和问卷。
3. 资源是否不足？看失败时目标剩余量和资源耗尽点。
4. 随机性是否过强？比较多随机种子通关率方差。
5. 策略空间是否过大？看决策时长、关键节点错误率。
6. 是否只有某一玩家分群受影响？

### B. 通关率正常，但道具/续关异常高
可能原因：
- 关卡接近可过但容错极低；
- 目标差一点完成，造成资源缺口；
- 道具价值过高或免费资源不足；
- 玩家主动为效率使用道具。
需结合历史基线和玩家分层，不可直接判定“关卡太难”。

### C. 通关率高，但下一关继续率低
可能原因：
- 关卡过长、疲劳；
- 胜利过程缺少成就感；
- 难度骤升预期；
- 奖励、剧情或目标吸引力不足。
不能只靠增加难度解决。

### D. 同一关玩家表现方差很大
检查：
- 随机种子敏感性；
- 不同策略路径；
- 机制理解差异；
- 操作设备差异；
- 关卡是否对熟练度有较强区分度。

## 5. 统计与样本注意事项

- 报告分子、分母和置信区间。
- 小样本不要做精细权重校准。
- 首次通关率与最终通关率要分开。
- 观察窗口要固定，例如首次进入后24小时/7天，避免口径漂移。
- 右删失：观察期结束仍未完成的玩家不能简单当作永久失败。
- 版本、活动、经济参数变化时要标记。
- 避免辛普森悖论：总体趋势可能与各玩家分群趋势相反。

## 6. A/B测试模板

### 实验设计
- 假设：修改X参数会改善Y体验指标；
- 实验单位：玩家或账号，避免同一玩家跨组；
- 分组：控制组/实验组；
- 唯一主变量：优先只改一个关键参数；
- 主要指标：例如首次通关率；
- 护栏指标：下一关继续率、道具消耗、主观公平感、崩溃率；
- 观察窗口：预先定义；
- 样本量：根据基线、最小可检测效应、显著性水平和统计功效估算；
- 停止规则：预先设定，不随结果临时改变。

### 判读
- 主指标改善且护栏稳定：可扩大验证；
- 主指标改善但体验护栏恶化：不应直接上线；
- 无显著差异：检查统计功效和执行质量，不等于完全无效果；
- 分群效果相反：考虑目标玩家和适用范围，不盲目全量。

## 7. 建议的关卡健康度看板

每关至少展示：
- 首次通关率、最终通关率；
- 每玩家失败次数P50/P90；
- 单次时长P50/P90；
- 成功剩余资源P50/P10；
- 道具/续关使用率；
- 失败时目标进度；
- 下一关继续率；
- 玩家分层差异；
- 版本和随机种子差异。
