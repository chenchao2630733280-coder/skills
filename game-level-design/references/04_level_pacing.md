# 04｜关卡节奏与难度曲线

## 1. 推荐的机制教学周期

`引入 → 示范 → 单机制练习 → 变化练习 → 机制组合 → 综合考核 → 释放`

每个新机制至少明确：
- 首次出现；
- 视觉/文字提示；
- 玩家第一次成功使用；
- 单机制巩固；
- 与旧机制组合；
- 高压场景下的精通验证。

## 2. 常见曲线形态

| 曲线 | 特征 | 优点 | 风险 |
|---|---|---|---|
| 线性递增 | 每关略升 | 简单可控 | 容易疲劳 |
| 阶梯式 | 若干关维持后升级 | 易于分段教学 | 阶梯边界突兀 |
| 波浪式 | 挑战与缓冲交替 | 节奏舒适 | 波峰安排不当会失去张力 |
| 学习-挑战-释放 | 新机制后考核再放松 | 适合机制驱动 | 需要清晰的教学目标 |

默认推荐波浪式递增 + 学习—挑战—释放。

## 3. 曲线设计规则

1. 难度曲线是目标体验曲线，不只是一个总分曲线。
2. 先规划每阶段玩家能力，再规划挑战。
3. 一次主要提升一个难度维度。
4. 新机制关降低其他维度的压力。
5. 困难关后安排释放或奖励体验。
6. 不要机械固定每N关一个超难关；结合玩家数据和内容节奏。
7. 关卡难度评分相邻差值需要审查，但差值不是唯一质量指标。

## 4. 关卡标签体系建议

- TUTORIAL：教学
- PRACTICE：练习
- STANDARD：普通
- CHALLENGE：挑战
- HARD：困难
- VERY_HARD：超难
- BOSS：阶段考核
- RELIEF：释放/缓冲
- MASTERY：精通

标签应表达设计意图，不必然等于通关率档位。

## 5. 关卡设计评审问题

- 本关唯一主要挑战是什么？
- 玩家失败后是否知道原因？
- 失败是否可通过学习改善？
- 新机制是否得到充分教学？
- 是否存在多维度同时突增？
- 是否有合理的恢复/补救路径？
- 随机性是否掩盖策略？
- 熟练玩家是否仍有优化空间？
- 新手是否有可理解的成功路径？
