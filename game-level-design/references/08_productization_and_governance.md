# 08｜上线治理、版本管理与风险控制

## 版本记录
每次模型发布保存：
- model_id / version；
- 特征定义与版本；
- 权重、阈值、交互项；
- 训练数据窗口；
- 适用游戏模式/玩家分群；
- 评估结果；
- 审批人和回滚版本。

## 上线阶段
1. 离线回放；
2. Shadow mode（只记录建议，不改变玩家体验）；
3. 小流量实验；
4. 扩量；
5. 长期监控。

## 护栏
- 玩家公平感；
- 关卡后继续率；
- 付费/广告资源消耗；
- 不同玩家群体的差异影响；
- 竞技一致性；
- 软锁/不可解率；
- 崩溃与性能。

## 回滚条件
提前约定指标阈值、观察窗口和责任人。出现不可解、明显不公平、异常资源消耗或核心体验恶化时，优先回滚。
