# 周报模板（复制骨架后填充，删除未使用的行）

## 通用写法

- 日期行独立成行：`YYYY年M月D日：`（每个项目只写一次）
- 有交付排期：`（交付时间：YYYY-MM-DD）` —— **必须带「交付时间」+ 全角冒号**
- 无交付排期：**括号整体省略**
- 源数据的 `2026/09/29` 需转成 `2026-09-29`

## 类型 A — 单一系统整体描述

```
项目A
2026年9月30日：
方案阶段：动作 + 产出物/量化
开发中（交付时间：2026-10-14）：动作 + 产出物/量化
延期（原定 2026-09-20，现 2026-10-04）：阻塞原因 + 新排期
```

## 类型 B — 拆分多子功能分别描述

```
项目B
2026年9月30日：
功能a：方案阶段：动作 + 产出物/量化
功能b：开发中（交付时间：2026-10-14）：动作 + 产出物/量化
功能c：测试中（交付时间：2026-10-09）：用例通过数 + 剩余问题
功能d：延期（原定 2026-09-28，现 2026-10-09）：阻塞原因 + 新排期
```

## 待补充清单（正文后附加，正文内不编造）

```
⚠️ 待补充
- <项目/功能>：缺交付排期，请确认预计交付时间
- <项目/功能>：本周无素材，未纳入本周进展
```
