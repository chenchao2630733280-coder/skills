# 质量检查表

## 概念

- [ ] 一句话可讲清
- [ ] 存在独特变量
- [ ] 不是旧套路换皮
- [ ] 第一集即可启动
- [ ] 适合短剧形式

## 故事发动机

- [ ] 主角目标具体
- [ ] 主角主动行动
- [ ] 主角无法轻易退出
- [ ] 对手有明确目标
- [ ] 双方目标真正冲突
- [ ] 最终选择明确

## 核心规则

- [ ] 触发方式明确
- [ ] 收益明确
- [ ] 代价明确
- [ ] 限制明确
- [ ] 漏洞明确
- [ ] 对手能够反制
- [ ] 与结局相关

## 人物

- [ ] 主要人物都有欲望
- [ ] 人物不是纯功能角色
- [ ] 至少三段关系发生变化
- [ ] 反派不是纯恶
- [ ] 终局关系有回收
- [ ] 主角来自可核实的"私货"素材，而非纯 AI 想当然
- [ ] 主要人物达到深度工坊 8 项中 ≥5 项，含 ④⑤⑥⑧（见 SKILL.md"深度工坊（8 项深层画像）"）
- [ ] 初稿后做过"冷血观众 / 哪场最像 AI 写的"审查并修改

## 长线结构

- [ ] 至少六个阶段
- [ ] 中点发生根本变化
- [ ] 后半段不是前半段重复
- [ ] 至少两次真相级反转
- [ ] 至少一次不可逆损失
- [ ] 结局回应开端

## 分集

- [ ] 每集有具体目标
- [ ] 每集有主角行动
- [ ] 每集有信息或关系变化
- [ ] 每集结尾有卡点
- [ ] 卡点类型不重复
- [ ] 不依赖长篇解释

## 制作

- [ ] 核心场景数量可控
- [ ] 主要演员数量可控
- [ ] 群演需求可控
- [ ] 特效需求可实现
- [ ] 外景和夜戏比例合理
- [ ] 适配AI短剧制作

## 风险

- [ ] 无明显抄袭
- [ ] 无核心设定撞题风险
- [ ] 无明显内容合规风险
- [ ] 不依赖违法行为美化
- [ ] 不存在严重逻辑漏洞
