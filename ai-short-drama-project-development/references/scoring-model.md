# 评分模型

| 维度 | 分值 |
|---|---:|
| 选题钩子 | 8 |
| 主角目标清晰度 | 8 |
| 故事发动机强度 | 12 |
| 对手系统 | 8 |
| 核心规则完整度 | 10 |
| 人物关系张力 | 10 |
| 剧情升级能力 | 10 |
| 长线续航能力 | 10 |
| 悬念与反转能力 | 8 |
| 情绪价值 | 6 |
| 单集卡点能力 | 5 |
| 制作可行性 | 3 |
| 商业传播性 | 2 |
| **总分** | **100** |

## 评分解释

- 90—100：可直接进入详细分集开发
- 80—89：整体成熟，局部需要调整
- 70—79：概念可用，但发动机或人物不足
- 60—69：适合作为选题储备
- 60以下：应重构核心规则或人物目标

合规与侵权风险为独立否决项，不纳入总分。
