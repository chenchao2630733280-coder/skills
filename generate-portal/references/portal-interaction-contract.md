# 门户（index.html）交互契约

> 本文件是 `output/site/index.html` 的**布局与交互权威口径**，优先级高于 `SKILL.md` 第五节。每次改动门户前先读它。

## 1. 当前形态

```
┌─ 工具栏：当前页标题 · 路径 · 计数说明 · [端切换 × N] ───────────────┐
├────────────────┬──────────────────────────────┬──────────────────┤
│ 本端页面列表     │  画幕（iframe）                │ 开发标注面板       │
│ **仅移动端显示** │  移动端 375×812 / PC 端 100%   │ 340px            │
│ 常驻展开、可滚动 │                               │ 随页跟随          │
└────────────────┴──────────────────────────────┴──────────────────┘
```

* **端切换**：按钮来自 `projectMap` 的模块（`data-end="<moduleId>"`）。切端 = 加载该端**第一个非隐藏页**（入口页），并按该页 `device` 切换画幕框。
* **本端页面列表**：数据取当前端（`moduleId` 匹配）的非隐藏页；标题显示模块名、右上角显示「N 页」；当前页高亮。
  * 该端**全部为 PC 页时不渲染**该列表（PC 原型自带左侧菜单，画幕占满整宽）。
* **计数说明**位于工具栏，由 `projectMap` 派生（总页数 / 可见页数 / 标注数），不得写死。

## 2. 页面切换的三个来源

| 来源 | 适用 | 说明 |
|------|------|------|
| 端切换 | 全端 | 加载该端入口页 |
| 画幕外本端列表 | 移动端 | 点任意页加载 |
| **画幕内导航** | 全端 | PC 原型左侧菜单 / 移动页内跳转 —— 由下方上报通道感知 |

## 3. 标注跟随契约（核心）

父窗口（门户）只认**一个入口**：

```js
function syncFromFile(file) {           // file = 页面文件名（如 P31-grants.html）
  // 反查 projectMap → 命中后同步：标题 / 路径 / 本端列表高亮 / 右侧开发标注
  // 若命中的页属于别的端，顺带把顶部「端」也切过去
}
```

两条通道都喂给它：

```js
iframe.addEventListener('load', …)      // 通道 1：http 下读 contentWindow.location.pathname
window.addEventListener('message', …)   // 通道 2：子页面自报（file:// 下唯一可用）
```

子页面侧（`pc/sidebar.js` 与 `mobile/navbar.js` **顶部**）各插一段：

```js
window.parent.postMessage({ __whNav: true, href: String(location.href) }, '*');
```

## 4. 三条硬约束（均为已踩过的坑）

1. **不得依赖父窗口读 `iframe.contentWindow.location`**：以 `file://` 直接打开时本地文件是不透明源，读取抛 `SecurityError`。必须保留 postMessage 通道。
2. **兜底不得回退去读 `iframe.getAttribute('src')`**：画幕内导航**不改该属性**，拿到的是入口页旧值，会把刚同步好的状态**回滚**。
3. **上报代码必须插在共享派生块（`派生视图 WELFARE`）之前**：该块由一致性校验按「标记 → 文件尾」逐字节比对两个文件，插在其后会直接破坏校验。

另有一条监听器纪律：**换语义时不得复用旧类名却不删旧监听**。曾把「设备切换」改成「端切换」而复用 `.device-btn`，遗留 handler 读到 `dataset.device === undefined`，把画幕框覆盖回 PC。
