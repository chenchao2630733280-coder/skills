# L3 · 自身可达性体检：我能不能真的做成

> 本文件回答：「市场再好，我够得着吗」。这是整套方法论中**最容易被跳过、却最能决定成败**的一环。
>
> 核心命题：**市场价值与个人可达性是两个独立的判断，两者经常背离。** 一个机会可以市场价值极高而对你可达性为零，此时它的正确评分是「不做」。

---

## 一、三项必查（缺一项结论即不成立）

### 1. 人脉盘

不是「有没有认识的人」，而是**能否触达决策层或采购方**。

| 层级 | 判断 |
|---|---|
| 能直接触达决策者/采购负责人，且对方认可你的专业度 | 人脉路线可行 |
| 有行业联系人，但不具备决策影响力 | 只能作为**信息渠道**，不能作为**成交渠道** |
| 只有同行和技术圈联系人 | 人脉路线不可行，必须走作品/内容路线 |

**自检问题**：如果现在要你推荐一个方案给某企业的采购负责人，你能在 3 天内促成一次面谈吗？答否 → 视为无人脉。

### 2. 获客机制

获客机制只有四种，**独立个人可用的是后三种**：

| 机制 | 是否依赖身份 | 个人可用 |
|---|---|---|
| 人脉引荐 | 是（依赖既有关系网） | ✗ 大多数人不可用 |
| 内容 | 否 | ✓ 但需要持续产出与时间 |
| 作品 | 否 | ✓ **一次投入、长期复用** |
| 平台流量 | 否 | ✓ 依赖平台规则，有波动 |

**关键判断**：你的获客是靠「去找人」还是「让人找到你」？只有后者才能规模化，也只有后者不依赖你每天出门社交。

### 3. 时间与资金约束

| 约束项 | 需要明确的问题 |
|---|---|
| 可否全职 | 决定能承受多长的无收入周期 |
| 每周可投入时长 | 决定 4 周时间盒的可行性（低于每周 10 小时应把时间盒延到 8 周，而不是压缩作品质量） |
| 可否垫资 | 垫资型业务直接排除 |
| 可承受的验证预算 | 决定能否选择需要花钱才能展示价值的形态（如视频生成） |

## 二、三条换法：把不可达变成可达

当四项关键约束中有人脉缺失时，必须通过「换」来补偿。三条路径可组合使用：

### 换法一：换信任载体（作品替代人脉）

**原理**：信任成本有两条支付路径——人脉，或时间。你没有前者，但后者对你成本极低。

公开作品的价值在于：**一次投入，永久复用**。它是一张自动化的信任凭证，不需要你去维系关系，也不会因为你不在场而失效。

**作品的三种形态**：

- 可体验的产品（demo / 工具 / 游戏）—— 客户自己上手就是最好的说服
- 公开的成品（上架的作品、真实用户、真实数据）—— 证明能力而非声称能力
- 过程拆解（我是怎么做的）—— 兼具内容与证据的双重功能

### 换法二：换客户层级

从大企业下沉到**技术小团队 / 独立开发者 / 个体经营者**：

| 对比项 | 大企业 | 小团队/个人 |
|---|---|---|
| 决策链 | 5–10 人，6–12 个月 | 1 人，即时 |
| 需要资质吗 | 通常需要 | 不需要 |
| 需要案例背书吗 | 必须有 | 作品即可 |
| 触达方式 | 人脉、招投标 | 社区、内容、平台 |
| 客单价 | 高 | 中低 |
| 成交成本 | 极高 | 极低 |

**换算逻辑**：客单价降低的损失，往往**小于**获客成本降低带来的收益，尤其是当你的时间本身也是成本时。

### 换法三：换市场

从国内换到海外市场。三个理由：

1. **付费习惯更成熟** —— 数字商品、模板、工具包在海外是既有交易品类，不需要教育客户「为什么要为这个付钱」。
2. **获客不依赖圈层** —— 通过内容、SEO、产品社区、发布平台触达，完全绕开人脉。
3. **定价更高** —— 同类数字产品的定价水平通常显著高于国内。

**代价**：语言、时区、支付结算、文化差异。但这些都是**可学习**的障碍，而人脉是**不可获得**的障碍。

## 三、个人资产盘点清单

评估可达性前，先盘点手上真实存在的东西。**关键区分：技能不是资产，能脱离你本人重复售卖的才是。**

| 类别 | 自检问题 | 是否算资产 |
|---|---|---|
| 技能 | 必须由我本人投入时间才能产出吗？ | ✗ 通常不算 |
| 流程 / 方法论 | 是否能被他人按步骤复现？ | ✓ 算 |
| 数据 / 内容库 | 是否已结构化、可交付？ | ✓ 算 |
| 行业认知 | 是否来自真实交付经历、含非公开信息？ | ✓ 高价值 |
| 已有产品 | 是否已上线、有真实用户？ | ✓ 算 |
| 可复用模板 | 是否已从项目中抽出、脱敏？ | ✓ 算 |

**盘点结论的用法**：优先选择「资产复用度高」的方向——即作品可以基于已有资产快速产出，边际投入极低。用 4 周做出一个需要从零开始的东西，通常来不及。

---

## 四、脱敏检查（发布前的强制项）

若资产来自真实项目交付，对外发布前必须逐项清理：

- [ ] 客户名称、项目名称、组织架构
- [ ] 真实业务规则、定价、数据结构
- [ ] 未公开的行业信息与商业条款
- [ ] 能反推出客户身份的细节组合

**做法**：把具体业务场景替换为通用场景，只保留方法论骨架与可复用结构。

**为什么必须做**：这既是合规问题，也决定了作品能否跨客户复用——**带真实业务细节的作品只能卖给一个客户，脱敏后的作品可以卖给所有客户。**

---

## 五、可达性结论的表述方式

体检完成后，结论应当明确区分三件事，不要混为一谈：

| 结论 | 含义 | 处理方式 |
|---|---|---|
| 市场有价值 + 我可达成 | 真机会 | 进入 L4 验证 |
| 市场有价值 + 我不可达成 | **机会不是我的** | 排除，但记录（未来可换人脉或换身份后重启） |
| 市场无价值 + 我可达成 | 舒适区陷阱 | 排除（熟悉不等于有市场） |
| 市场无价值 + 我不可达成 | 无关项 | 忽略 |

**最常见的错误是把第二行误当成第一行**——因为「市场有价值」这个判断本身是令人兴奋的，而「我不可达成」是令人沮丧的，人会本能地低估后者。
