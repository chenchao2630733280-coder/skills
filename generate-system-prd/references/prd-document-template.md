# PRD 文档结构模板（13章 + 附录）

本文件承接 SKILL.md §三的完整章节模板，作为**生成参考**。SKILL.md 仅保留章节索引和端专属约束摘要，逐章生成时读取本文件对应章节。所有端类型（admin_web / native_app / mobile_web / mini_program / hybrid / multi_end）共用此模板，端专属内容在章节内以条件标注区分。

---

## 第1章：产品总体设计

### 1.1 产品定位与核心价值
- **系统本质**：一句话定义系统是什么
- **核心逻辑**：提炼3-5个核心概念及其关系
- **核算口径**（如涉及财务/成本）：明确系统采用的核算口径，并列出多套指标体系对照表
- **目标用户**：按角色列出，每个角色描述核心诉求；移动端还需说明使用地点、使用频率、单手/双手操作、注意力持续时间及设备熟练度

### 1.2 核心设计原则
- 提炼5-6条设计原则，每条包含：**原则名称 + 一句话定义 + 简要说明**
- 原则应覆盖：顶层实体锚定、口径统一、特殊业务制度化、全量可追溯、关键约束、迭代策略等维度

### 1.3 术语表
- 表格形式：术语 | 英文 | 定义
- 覆盖系统所有专业术语，每个术语必须给出精确定义

### 1.4 开发阶段规划
- **MVP阶段（一期）**：列出3-5个核心目标
- **二期规划**：列出扩展功能方向

### 1.5 终端与使用场景（移动端/多端必填）
- 表格形式：终端 | 用户角色 | 使用场景 | 网络环境 | 高频任务 | 关键限制
- 明确支持的 OS、设备类型、屏幕方向、最低版本和是否需要平板适配
- 描述用户是在走动、排队、现场作业还是稳定办公环境中使用
- 明确移动端与 PC 后台的职责边界，禁止简单复制全部后台功能

## 第2章：产品架构设计

### 2.1 业务架构图
- 使用ASCII字符画绘制分层架构图
- 层次根据业务域和终端类型划分。
- 后台系统常见分层：展示层、业务层、归集/计算层、主数据层、基础设施层。
- 移动端常见分层：页面/组件层、导航与状态层、领域服务层、网络与本地存储层、端能力适配层、服务端 API 层。
- 多端产品必须标注公共服务、后台管理端、移动用户端之间的调用和数据归属。
- 每层标注具体模块名称和页面编号

### 2.2 功能模块清单
- 表格形式：一级模块 | 二级模块 | 页面 | MVP优先级
- 优先级标注：P0（必须）/ P1（暂缓）

### 2.3 页面清单与路由
- 后台模式表格：编号 | 页面名称 | 文件名 | ACTIVE_MENU | 状态
- 移动端模式表格：编号 | 页面名称 | 所属端 | 导航层级 | Route/Deep Link | 登录要求 | 状态
- 每个页面必须有唯一编号（如P01、P02b等）；双端同名页面共用同一编号，通过"所属端"字段区分，不使用独立的 MXX 编号
- 移动端需区分独立页面、Tab 根页面、全屏流程页、半屏浮层和系统页面

### 2.4 导航与信息架构（移动端/多端必填）
- 使用 ASCII 图描述启动页、登录、首页/Tab、二级页、详情页和任务闭环之间的层级
- 明确返回规则、跨 Tab 跳转、Deep Link、推送落地页和未登录拦截
- 高频主任务应在 1-3 次关键点击内到达；低频配置能力不应占据一级导航

### 2.5 多端职责矩阵（multi_end 必填）
- 表格形式：能力 | 移动端 | PC 后台 | 服务端 | 数据主责 | 同步规则
- 明确录入、审批、配置、统计、批量处理和现场操作分别由哪个端承担

## 第3章：核心领域与数据设计

### 3.1 领域模型总览
- 使用ASCII字符画绘制业务域、核心实体和值对象之间的关系。
- **核心关系一览表**：关系 | 类型 | 说明。
- **核心原则**：列出5-6条领域与数据设计原则。
- 先定义业务概念，再决定数据库表、API DTO 和移动端本地模型，禁止三者不加区分地共用一套字段。

### 3.2 ~ 3.N 模型定义（按范围选择）

**A. 包含服务端/后台建设时：数据表定义**
- 表名、用途和数据主责。
- 字段定义：字段名 | 类型 | 必填 | 说明。
- 编号规则、状态机、关闭/变更条件、关键业务规则和场景示例。
- 服务端业务表可按需包含主键、创建/更新时间、逻辑删除和乐观锁字段，但不得对所有表机械套用。

**B. 仅设计移动客户端或单一功能时：客户端数据契约**
- 领域实体：实体/对象 | 关键属性 | 状态 | 来源 | 生命周期。
- API 契约：接口 | 方法 | 请求字段 | 响应字段 | 分页 | 错误码 | 幂等要求。
- 本地数据：缓存内容 | 存储方式 | 有效期 | 敏感等级 | 清理时机。
- 页面状态：初始、加载、成功、空、局部失败、全局失败、离线、权限受限、提交中、提交成功。
- 离线同步（如适用）：本地临时 ID、sync_status、重试次数、冲突解决、最终一致性策略。

**通用字段与金额规范：**
- 枚举值必须列出全部取值与含义。
- 自动计算字段标注"自动计算"并给出公式。
- 条件必填字段说明触发条件。
- 服务端金额可使用 decimal；客户端与 API 不得依赖浮点数直接计算金额，应明确使用字符串、小数库或最小货币单位。
- 只有在需求包含服务端持久化设计时，才要求精确到数据库字段长度和索引。

## 第4章：关键业务流程设计

按业务域组织，每个流程**必须包含**：
- **流程图**：使用ASCII箭头绘制步骤链。
- **步骤说明**：每个步骤的详细操作描述。
- **关键规则**：编号列表（BR-XXX），覆盖校验规则、互斥规则、约束条件。
- **场景对比表**（如适用）：不同模式的差异对照。
- 移动端流程额外描述：入口来源、前后台切换、来电/锁屏/页面销毁后的恢复点、重复点击保护、弱网重试、取消与返回规则、提交成功后的反馈。
- 涉及相机、定位、通知等能力时，必须包含首次授权、拒绝、永久拒绝、系统设置后返回四条路径。

流程域根据实际业务确定，常见流程域包括但不限于：
- 主数据创建与关联流程
- 业务单据录入与审批流程
- 资金/物资流转跟踪流程
- 核算与确认流程
- 变更与冲销流程

## 第5章：特殊业务场景设计

识别并详细描述系统中的特殊业务场景，每个场景**必须包含**：
- **核心规则表**：规则项 | 说明
- **业务流程图**：ASCII箭头流程
- **与标准模式的差异对照表**（如适用）
- **场景示例**：用数据表格展示计算过程

特殊场景由业务决定，常见类型包括但不限于：
- 简化流程模式（如免审批、免核销）
- 跨组织协作模式（如双算/拆分、共享分摊）
- 多实体共用模式（如多项目共用采购、多部门共享资源）
- 关联约束模式（如背靠背付款、联动控制）
- 特殊核算模式（如佣金模式、阶梯计价）
- 移动端特殊场景：无网络/弱网、权限拒绝、推送跳转、Deep Link 失效、登录过期、应用升级、低存储空间、低电量、横竖屏切换、系统中断、媒体上传失败
- 多端冲突场景：同一数据被 PC 与移动端同时修改、审批状态延迟、草稿跨端恢复、重复提交与幂等处理

## 第6章：报表与统计体系设计

> 本章结构根据业务需要灵活组织，不固定具体报表类型。

### 6.1 指标口径统一
- 按业务线分类，表格形式：序号 | 指标名称 | 计算公式 | 统计口径
- **统计口径说明表**：指标类别 | 统计口径 | 说明
- 所有核心指标必须统一定义计算公式，确保全系统数据口径一致

### 6.2 ~ 6.N 各报表/看板规格
根据业务需要定义报表/看板，每个报表**必须包含**：
- **报表定位**：面向谁、解决什么问题
- **筛选条件**：字段名 | 类型 | 说明/选项
- **指标/卡片定义**：指标名 | 计算方式 | 展示形式
- **图表规格**（如适用）：图表类型 | 展示内容
- **表格列定义**（如适用）：列名 | 说明
- **明细/下钻规格**（如适用）：点击后展示的明细内容
- **导出规格**（如适用）：支持格式、单位切换等

**移动端展示约束：**
- 优先使用摘要卡片、趋势图、分组列表和逐级下钻，不直接缩放 PC 宽表格。
- 表格确有必要时，明确固定列、横向滚动、列裁剪、详情替代方案和导出入口。
- 图表需定义点击热区、Tooltip 替代、横屏策略、空数据及加载骨架。

常见报表类型参考（按需选用）：
- 全局驾驶舱/总览看板
- 周期性经营看板（月度/季度）
- 维度分析表（部门/区域/产品线）
- 预测分析（现金流/趋势）
- 风险预警面板

## 第7章：权限体系设计

### 7.1 功能权限（RBAC）
- 预置角色表：角色 | 权限范围
- **角色-页面权限映射矩阵**：页面/操作 | 各角色（✅/❌/只读/本部门/本项目等）
- 关键操作角色限制清单
- 权限条目统一编号：PERM-XXX（功能权限与系统权限共用序列）

### 7.2 数据权限
- 数据隔离维度说明
- 数据权限实现方式

### 7.3 系统权限与隐私授权（移动端必填）
- 表格形式：系统权限 | 使用目的 | 触发时机 | 拒绝后的降级方案 | 是否再次引导
- 区分业务权限、操作系统权限和隐私同意，三者不得混写
- 非必要权限不得在启动时批量申请，应在用户触发相关功能时按需申请

### 7.4 权限数据结构
- 包含服务端时，引用第3章权限相关表定义
- 仅客户端范围时，定义权限状态、授权结果缓存及服务端权限错误的处理方式

## 第8章：页面设计规格

**每个页面必须包含以下规格，并根据终端选择适用项：**

> **admin_web 设计规范约束**：当 `client_type` 为 `admin_web`（或 `multi_end` 中的后台端）时，第8章涉及的后台端布局、色彩、字号、间距、圆角、阴影、组件（按钮/查询表单/表格/分页/表单/弹窗/抽屉/卡片/反馈）与页面模板（列表页/表单页/详情页/看板页/登录页）必须遵循 `../_shared/references/pc_admin_ui_spec.md`。以下为关键约束摘要，详细条目以 spec 原文为准：
> - **布局**：纵向布局（`vertical`）为默认；侧边栏 `266px`（允许 266/277/288 三档，折叠 `64px`）、顶栏 `60px`、标签页栏 `50px`、菜单项高 `50px`、内容区上下留白 `20px`、卡片间距 `20px`。
> - **色彩**：主色 `#1890ff`（blue 主题，另有 green `#41b584` / purple `#6954f0` 可选）；功能色 成功 `#13ce66` / 警告 `#ffba00` / 危险 `#ff6700` / 错误 `#ff4d4f`；页面背景 `#f6f8f9`、卡片 `#ffffff`、深色菜单 `#282c34`；正文 `#303133` / 常规 `#606266` / 次要 `#909399` / 占位 `#c0c4cc`。
> - **字号**：基准 14px；页面主标题 18px、卡片标题 16px、辅助 12px、看板核心数字 22px。
> - **间距/圆角/阴影**：4px 为基数，基准间距 20px；全局圆角 `2.5px`；阴影 `0 1px 4px rgba(0,21,41,0.08)`；控件高度 `32px`。
> - **组件规则**：按钮主操作每视图区最多 1 个 primary；查询表单一行 3~4 项，超过 4 项收起；表格表头 `#f5f7fa`、行分割线 `#ebeef5`、操作列 `fixed="right"`；分页默认每页 20，可选 10/20/50/100；表单 label 右对齐置顶、宽度同页一致；弹窗 ≤6 字段用 `VabDialog`（520~640px），字段多或含富文本用抽屉（600~800px）。
> - **反馈与文案**：写操作走完"触发 loading → 结果提示 → 界面更新"三态；删除/停用等破坏性操作必须 `ElMessageBox` 二次确认；按钮文案为 2~4 字动宾短语（"新增用户"），与菜单名一致。
> - **页面模板**：列表页"查询卡片 + 表格卡片"两段式；表单页主标题 + 表单卡片 + 吸底操作栏；详情页 `el-descriptions` + Tabs 关联数据；看板页统计卡片行 + 图表区 + 明细表格。
>
> PRD 阶段不重复展开逐页控件细节，但页面规格中的尺寸、色值、组件类型选择须与 spec 一致；详细原型由 `generate-prototype` 阶段按 `_shared/references/pc_admin_ui_spec.md` 落地。

- **基础信息**：页面编号、所属端、页面类型、Route/Deep Link、登录要求、入口和退出去向。
- **后台页面类型**：表单页/列表页/详情页/仪表盘/报表页/向导页/预览页。
- **移动页面类型**：启动页/登录页/引导页/Tab首页/信息流/卡片列表/搜索页/详情页/编辑页/任务流程页/地图页/媒体页/WebView/系统权限页。
- **布局结构**：导航栏、内容区、底部操作区、Bottom Tab、安全区、吸顶/悬浮区域。
- **内容定义**：区块、卡片、字段、文案、图标、图片比例和信息优先级。
- **页面状态**：加载骨架、成功、空数据、局部失败、全局失败、离线、权限受限、登录失效、提交中、提交成功。
- **列表行为**：下拉刷新、上拉加载、游标/页码分页、缓存回显、滚动位置恢复和重复数据去重。
- **输入行为**：键盘类型、焦点顺序、键盘遮挡、自动填充、扫码/语音/相机输入、字符限制和实时校验。
- **交互与手势**：点击、长按、滑动、返回手势、二次确认、触觉反馈；关键操作必须有防重复提交。
- **浮层规格**：后台可使用 modal；移动端优先使用 Bottom Sheet、Action Sheet、全屏选择页或系统弹窗，并定义关闭方式与返回结果。
- **端能力与权限**：相机、相册、定位、通知、生物识别等能力的触发和降级。
- **适配要求**：安全区、字号缩放、深色模式、横竖屏、刘海/挖孔屏、低端设备及无障碍。
- **参数与埋点**：路由参数、来源参数、曝光事件、点击事件、提交结果和错误事件。
- **后台专用项**：筛选字段、工具栏、表格列、操作列、分页、批量操作、ACTIVE_MENU。
- **移动端禁止默认套用项**：宽表格、鼠标悬浮、右键菜单、固定像素大弹窗和依赖 hover 的提示。

## 第9章：非功能性需求设计
