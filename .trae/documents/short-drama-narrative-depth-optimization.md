# 优化计划：为短剧叙事类 skill 深度注入"反 AI 塑料感 + 人机协作保真"方法

## Summary（摘要）

用户提供了一篇关于"AI 时代故事内核/叙事能力更重要"以及一套完整"人机协作写故事工作流"的方法论。经确认，本次优化落在三个 skill 上：`ai-short-drama-project-development`、`short-drama-script`、`short-drama-spec`，侧重**增强现有方法深度**——将来文的深层方法直接深化进现有的人物卡、对白规则、自检清单、评分体系，**不新增独立章节、不新建冗余文件**。

核心增量不是"生产流水线"（现有技能已充分覆盖发动机/卡点/评分），而是三件事：
1. **保真**：素材从"作者私货"出发，AI 当提问者而非写手；
2. **反 AI 塑料感**：用"俗套清单 / 台词医生 / 哪场最像 AI 写的 / 删正确的废话 / 主角失败一次"来剔除模板味；
3. **深度人物**：从表面性格卡升级为 8 项深层画像（习惯动作 / 不愿提起的记忆 / 常说的谎话 / 又爱又气的缺点等）。

## Current State Analysis（现状分析）

| skill | 现有结构 | 缺失的来文增量 |
|---|---|---|
| `short-drama-spec` | 故事发动机八部件、人物系统、秘密系统、整剧结构(仅推荐八阶段)、评分 | 无"私货/提问者"开端；人物卡偏表面；反套路只有换皮清单、无"俗套清单"预判法；结构只有单一八阶段、无环形/多视角等替代 |
| `short-drama-script` | 竖屏格式、对白 7 规则、卡点落地、分批产出、10 项自检 | 对白规则是"短句/口语/"但无"删直接表情绪/打断沉默/动作替代情绪"升级；自检无"哪句像 AI 写的"；流程是批量整篇、非"逐场给目标" |
| `ai-short-drama-project-development` | 13 步项目开发、人物卡、反派系统、6 关卡、评分、自检 | SKILL.md 直接"选题确认后即开发"，无人机协作保真开端；人物卡偏表面；自检无塑料感/真实感维度 |

**说明**：`ai-short-drama-project-development` 与 `short-drama-spec` 功能高度重叠。为避免重复，本次只做**方法深度增强**（同样的"私货/工坊 8 项/俗套清单"各写各的、与各自结构对齐），**不做合并重构**（超出本次范围）。

## Goal（目标）

把来文的 10 项方法，深度嵌入三个 skill 的**现有**模板/规则/清单，让产物从"结构正确但塑料"升级为"结构正确且保真、不套路"。

## Proposed Changes（具体改动：按文件列出 做什么/为什么/怎么做）

### A. `short-drama-spec`

**A1. `references/character-system.md` — §三 人物卡 深化为"表面卡 + 深度工坊 8 项"**
- 在现有"主角人物卡""其他人物卡"之后，新增一个"### 3.3 人物深度工坊（8 项深层画像，AI 塑料感过滤器）"小节
- 内容 = 来文第 3 步 8 项：① 一个公开的欲望 ② 一个隐藏的恐惧 ③ 一个与欲望冲突的价值观 ④ 一个反复出现的习惯动作 ⑤ 一段不愿提起的记忆 ⑥ 一句常说的谎话 ⑦ 一个对自己残忍的时刻 ⑧ 一个让观众又爱又气的缺点
- 用法：每人卡至少填 8 项中的 ≥5 项，且第 ④⑤⑥⑧ 必填（小而具体，避免形容词堆砌）。凡"性格冷静 = 形容词堆砌"提示需用具体行为/物件落地
- 为什么：现有卡只有"表面性格/真实欲望/恐惧/秘密"，是性格标签；8 项逼出"可演、可拍、不塑料"的行为细节

**A2. `references/story-engine.md` — §三 反套路检查 升级为"俗套清单 → 替换核心变量 → 替代结构"**
- 在现有"常见换皮风险 + 至少替换两个核心变量"后追加两步：
  - **俗套清单预判法**（来文第 4 步）：先列本类型观众最易预测的 10 个情节走向/人物反应，作为"必须绕开"清单
  - **替代叙事结构**：若题材适合，提供环形 / 多视角拼图 / 时间倒流 / 章节体 / 伪纪录片 5 种替代，每种须说明如何强化主题（不炫技）
- 为什么：现有只列风险、缺"先列俗套再绕开"的可操作方法，也缺非三幕结构选项

**A3. `SKILL.md` — §三.0 选题复核 前端增加"私货与提问者"第一步**
- 在 "3.0 选题复核" 之前加一个 "2.9 私货采集（人机协作保真开端）"步骤：先请人类作者写下——最想表达的主题 / 亲身经历的一个情感瞬间 / 最讨厌的套路 / 最近一次愤怒羞愧心碎荒诞的具体场景 / 相信的一句话
- 让 AI 先扮演"提问者"连问问题逼出更私人、矛盾的部分（来文第 0、1 步），**再**进选题复核
- 交互约定：这是唯一允许"问作者问题"的节点；读取蓝图后其余仍不提问
- 为什么：来文核心是"私货 = 不可替代性，AI 只放大不拥有"。现有流程直接读蓝图开发，缺这一前置保真层

### B. `short-drama-script`

**B1. `references/dialogue-rules.md` — 升级对白规则，新增"台词医生 5 刀"**
- 在现状 7 规则后，新增一节"**八、台词医生（AI 塑料味过滤）**"：
  1. 删掉所有直接表达情绪和主题的句子（"我很痛苦""人生就是这样"）
  2. 每句话都要有说话者当下的目的（无目的即删）
  3. 至少加入一个打断或沉默
  4. 用具体动作/物件代替情绪描述（递遥控器 ≠ 说"我爱你"）
  5. 让两个人听起来像真实生活中会说的话，而非编剧写的"工整句"
- 补 2 条坏例对照表：工整/说教句 → 口语生活句
- 为什么：现有"口语化"规则只挡书面语，不挡"聪明/工整/像在说主题"的 AI 塑料感

**B2. `SKILL.md` — §六 产出流程改为"逐场写作 + 后置冷血检查 + 人工润色"，§七 自检清单补充 3 项**
- §六 步骤中，在"先摘表后动笔 / 分批产出"之间强调**逐场给目标**（来文第 5 步：每场写清场景/人物/目标，写一场再定下一场方向），防整篇灌水
- §七 自检清单新增 3 项（勾选）：
  - [ ] 无直接表达情绪/主题的"说教句"（台词医生第 1-5 刀已过）
  - [ ] 无"AI 塑料感"对白——删掉所有听起来比角色聪明/过于工整的句子
  - [ ] 主角色至少经历一次过程性失败（来文第 8 步：真实、难堪、不可挽回，而非大团圆式）
- 为什么：把来文第 6/7/8 步（台词医生/冷血反馈/人工润色）落进可勾选的硬门

### C. `ai-short-drama-project-development`

**C1. `SKILL.md` — 开端新增"第 0 步 私货采集"，并更新核心原则**
- 在"阶段一：选题复核"前新增"第 0 步 用户私货采集 + AI 提问者"小节（同 A3 内容，措辞贴合本项目开发语境）
- 在"核心开发原则"补充一条："**先有私货，再谈选题**——选题必须挂在作者可站得住的情感/价值观之上，否则易成换皮套路"
- 为什么：本项目 SKILL.md 直接"选题确认后即开发"，需先回收保真起点

**C2. `SKILL.md` — 人物系统设计新增"深度工坊 8 项"**
- 在现有"人物卡"模板后，新增"**深度工坊 8 项（AI 塑料感过滤器）**"小节（同 A1，8 项内容）
- 加一句提示：填人物卡时，凡表面性格用形容词堆砌的，必须补 8 项中的具体行为/物件落地
- 为什么：与 short-drama-spec 同源的深度人物要求，落进本项目人物卡

**C3. `references/quality-checklist.md` — 补充"保真/塑料感"维度的勾选项**
- 在"人物"区新增 3 项：
  - [ ] 主角来自可核实的"私货"素材，而非纯 AI 想当然
  - [ ] 主要人物达到深度工坊 8 项中 ≥5 项，含 ④⑤⑥⑧
  - [ ] 初稿后做过"冷血观众/哪场最像 AI 写的"审查并修改
- 为什么：把来文第 7 步（冷血观众/逻辑警察）与第 0 步（私货）固化为可勾质检项
